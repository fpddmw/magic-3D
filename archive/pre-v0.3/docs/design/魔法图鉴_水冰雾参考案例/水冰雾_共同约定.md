# 水、冰与雾：共同约定

2026-11-26 · 水冰雾案例的比较条件与材料归属规则。现象关系见 [构思与变化](水冰雾_构思与变化.md)，在 3D 新引擎中的动作与系统互动见 [04 · 动作底盘、战斗与演出导演](../../04_动作底盘、战斗与演出导演.md)。

本文集中保存本组的数值、材料和载体假设，并引用已采用的材料归属、单一直接操控焦点与持续责任规则。暂定份数、费用和寄存含义保持案例参考范围，具体 3D 平衡留待切片调优。

## 1. 前期比较标尺

| 标尺 | 本批采用的暂定条件 | 用途 |
|---|---|---|
| 法力 | 前期上限按100比较；遭遇推演暂不计战中回蓝 | 比较单次投入、持续支撑与准备 |
| 标准贯刺 | 一发自生普通贯刺消耗10 | 比较不同施法的机会与收益 |
| 一份水 | 一支普通贯刺所需材料量 | 对照同一份材料的分配与回收 |
| 生成水 | 每份暂按4法力比较 | 将造材料与后续组织投入分开 |
| 组织与受力 | 成形、相变、推动、抵抗等按各条目给出 | 借水节省生成，不免除其他投入 |

普通贯刺使用一份水，悬冰连袭的三支细矛合计一份，护流使用三份，回澜四份，门宽冰闸六份。盈水秘壶前期保存六份水。容量分配与消耗会真实影响其他作用。

“水份”是相对量标尺，不是强制科学流体方程的物理量纲。数值是设计者比较用的后台假设，玩家不分配攻击力或攻速数值点。

## 2. 来源、状态与作用对象

本组案例中，借用作用于材料来源时取用已有内容；自生版本在生成段形成内容。同一份水经历液态流动、凝固、破碎或融化后，后文承接实际状态。雾由水滴弥散形成，视觉覆盖很大也不意味着它具有厚重冰墙的材料量。

- 冻住飞行水团，保留其当前运动；凝固本身不让它停在空中。
- 薄水膜能形成薄冰壳，实际连接和厚度决定束缚效果。
- 冰闸被打碎后成为碎冰，重新获得可流动的水需要融化等作用。
- 停止法术不抹掉已完成的材料与环境改变；自然后果依支撑、温度、损伤继续。
- 回收材料减少之后的生成需求；已消耗的组织、推进和受力投入不会随材料自动回蓝。

## 3. 同一份材料与法术交接

交接要指出从哪个当前对象取走多少，原有作用怎样变化：

| 交接 | 原作用发生什么 | 新作用继承什么 |
|---|---|---|
| 从护流抽水成矛 | 水带变短、变薄，覆盖出现缺口 | 实际分出的水及其状态 |
| 凝固一段回澜 | 凝成冰的部分脱离液态回旋，余浪组织随之改变 | 被冻结部分的形体与当前运动 |
| 将水索冻成连接 | 液态操控让位于固体结构及其支撑 | 当前路径、两端接触与水量 |
| 炸掉冰闸 | 掩体和阻挡撤去或残缺 | 被选中的冰体与已有损伤 |
| 回收冰轨 | 承重结构退去，物体可能跌落 | 实际熔解、可牵回的材料 |

这些关系供满足同类条件的魔法使用，不按法术名称配对增加固定倍率。

## 4. 控制、专注与更换

已有法术保存施放时的含义，核心调整不追溯重释场上的对象。

- **同一时刻只有一个直接操控焦点**，接收连续指向、塑形或牵拉。其他作用执行已成立关系，例如悬冰追随角色。切走焦点不自动解除全部维持，也不赋予新自主能力。
- 普通移动和有限即时指令分别处理。发射一支预备悬冰可以配合已成立的行进关系，但仍有动作窗口；同时精细驾驭水索和回澜必须交接焦点。
- 玩家主动离开吟唱的组织操作时，依据术式提前释放、转交或中止。
- 中断需要有可读的触发。造成失衡的受击可打断相应吟唱，轻微擦伤是否影响仍需在 3D 动作手感中校准。

## 5. 载体与元素寄存

本组载体构思的解释是：**以太与封存在承载职责、对象关系及整体构造中共同使有限内容或待发作用得到寄存；释放交出相应内容。**

| 载体能力 | 内容与责任 |
|---|---|
| 伏霜印 | 保存一支待发冰矛和预付作用，受压后释放；发射后须重新补充 |
| 冰闸印 | 储备完整造闸所需内容，继承回应关系；完整载体规格仍待展开 |
| 盈水秘壶 | 保存有限水量，收纳和交出时付出少量法力；无附赠高压喷射 |
| 涌泉锚 | 联系实际水源，消耗预付力量持续导流；水与驱动储备分别耗用 |

载体破坏、储量耗尽、来源断开与主动停止分别处理。已经流出的水和形成的冰继续存在，不随载体被破坏一并删除。

## 6. 场景、战斗与持续运行

水需要具有真实冲击与潮湿导电交互，雾的分布影响 3D 视线遮蔽，冰的形体与连接影响碰撞阻挡和承载。伤害、失衡与位移分别结算；装饰性视觉细节不额外另造伤害。持久环境改变的继承规则见 [03 · 世界结构与废城探索](../../03_世界结构与废城探索.md)。
