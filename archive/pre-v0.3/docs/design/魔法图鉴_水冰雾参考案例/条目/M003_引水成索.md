# M003 · 引水成索

**牵起一条连续水带，靠实际接触拉动、甩击和搬移事物。**

状态：主体设计提案，待验证。基础符文：水、借用、延展、牵引。组织：瞬发／维持。[图鉴](../README.md)

## 构造与完整动作

`元素：水；生成：借用；形态：延展；运动：牵引`

水的连续流通、延展与牵引共同形成能够传力的水带；该解释包含一条实际接触路径。维持保持这条可调整的受力关系。玩家先确定水源，牵起长带，再用指向控制前端。若牵引改为作用于来源供给，或延展改为限定作用范围，需要重新解释完整构造，不自动得到同样的水索。

水带扫中普通敌人的腰腿，能拖动或拉得失衡；抵住墙面继续牵引，产生挤压与撞击。遇到能够绕行的柱边，水带沿其弯折；实体阻挡限制实际路径。瞬发完成一次有方向的牵拉或甩击后散落，维持版继续保留整条可驾驭的水带。

## 前期标尺与版本

两份水，约6米控制距离。借水维持版起手6法力、每秒2；一次牵拉的瞬发版约8法力。自生版本以生成水替换借用来源，多付造水投入，其他主要行为保持相同。

维持期间可以改变接触位置、方向和作用对象。停止或失去支撑后，水按当前运动与地形落散。牵引通过水的实际接触受力，不因目标身上有湿润状态就远程抓住整个目标。

## 组合、冒险与成长

接住浮动物品、托起轻物、从水中取物使用同一条连续受力关系。水带与栏杆、地面或另一端接触时，[覆水急冻](M006_覆水急冻.md)可以把当前路径留成固体连接。冻结后是否能承重，取决于水量、连接与支撑，原液态操控不继续凭空成立。

它可配合[回澜](M004_回澜.md)改变敌人位置，也可以独立作为搬移与近距控制的核心。更远、更重、更精细的操控是可继续展开的成长方向，尚未给出其后期参数。

待核对：不同负荷的力、路径绕行与接触反馈、源与目标的切换操作。曲线外形不能直接当作实际可实现的无限路径规划。
