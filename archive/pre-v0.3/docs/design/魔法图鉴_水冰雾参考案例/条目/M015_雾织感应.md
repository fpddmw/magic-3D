# M015 · 雾织感应

**雾中的扰动沿奥术联结传回来，让施法者在看不清的地方判断运动和流向。**

状态：主体设计提案，待验证。基础符文：水、气、弥散、铺展、以太、联结、回应。组织：维持。[图鉴](../README.md)

## 构造与反馈

水、气、弥散、铺展与以太、联结、回应共同把雾组织为可反馈扰动的介质。与[普通雾幕](M014_雾幕.md)相比，新增关系改变施法者与这片空间的联系，遮蔽与感应需要一起解释：

`以太建立施法者与该片雾的联结 → 回应雾的扰动，将反馈传回施法者`

前期建立约10法力，维持每秒约1.5，沿用前期雾幕的区域作为比较起点。某一方向的雾纹受到挤压，起伏沿联结传来；玩家判断那里有较大物体移动、动作是否突然、流动朝哪边变化。

反馈提供扰动信息，不直接得到精细轮廓与身份。静止藏匿者不会一直显示轮廓，同伴、投物和开门气流都会产生反馈；敌人的投物试探可以干扰判断。

## 实际使用

战斗中，它帮助判断接近方向，再用[折冲](M013_水幕折冲.md)变位、[冰砂](M016_冰砂喷袭.md)应对近处，或抓住视线缺口发射[悬冰](M002_悬冰连袭.md)。普通雾幕仍有更简单、较低投入的价值。

调查遗址时，雾沿墙缝被吸走或从某处被持续吹开，使用同一反馈帮助辨认通风与相邻空间的线索。它不直接推断墙后内容或给出解谜答案。

停止维持后联结反馈结束，现有雾依环境散开；雾被局部消耗、吹离时，当前反馈区域相应改变。

## 成长与待核对

后期可覆盖街巷，识别几处主要扰动，分别深化范围、精度和干扰处理。波纹和反馈要让玩家理解来源、方向与强弱，同时保留判断空间。

待核对：有效感应区域、信号分辨率、遮挡与断开的雾、友方和自身扰动、多处反馈的表达，以及持续感知的操控负担。
