# M004 · 回澜

**头部厚重的水浪沿弧线扫出去，再卷回可以继续驾驭的位置。** 纯水本身承担强力作战。

状态：主体设计提案，待验证。基础符文：水、凝聚、延展、回旋。组织：瞬发／维持。借水版本增补：借用。[图鉴](../README.md)

## 构造与驾驭

`水 → 形态：凝聚＋延展 → 运动：回旋`

凝聚与延展共同形成头部厚重、后方连贯的浪身，回旋组织它沿弧线卷动。维持引用这一水体与运动关系；瞬发则预先组织一次有限回卷。

玩家以当前直接操控焦点控制回旋中心，浪身沿实际可达路径运动。中心移到敌人侧后方，可以从背侧卷回；抬高中心，可以沿台阶扫上低台。阻挡会使浪头压缩、偏转、流失或停滞，不能因移动中心直接穿墙。有限水量铺开时接触面变薄，集中时局部推压更强。切走焦点后失去新的中心调整，既有回卷能否持续及持续多久按维系与控制范围核对，不附赠自主追敌。

## 前期力量与结束

四份水形成约半人至一人高的浪头，在玩家周围约8米内作用。能扫倒聚集的两三个轻装敌人，把目标拍向墙面或推离平台；厚重敌人可以抵住正面，侧面与失去支撑的脚下更易受影响。

已有水的一次回卷约12法力；维持起手10、每秒2。自生版本另支付材料生成。一次回卷结束或维持停止后，水按已有运动落回场地，不自动回收或再次攻击。

## 组合、冒险与成长

角色真实站上浪面时能被带向高处，其他接触者同样受流动影响。水浪可以搬移松动物件，改变接近、离开与运输路线。[水索](M003_引水成索.md)可把局部材料继续牵出；[急冻](M006_覆水急冻.md)能把选中浪段凝成保留当前运动的冰，余下水浪随之变化。

后期目标是驾驭横跨十几米、数人高的厚浪，连同松动物件卷过街面，再回卷、抬升、换侧压下。纯水可以持续深化，不把转冰预定为终点。

浪的接触分别产生伤害、失衡和位移，沿浪身多个结构段的同次接触需要归并；散落水从浪体扣除后进入环境。待核对：中心移动速度、转弯重量感、焦点交接后的维系行为、负荷、友方接触，以及反复扫中目标的结算节奏。当前未确定具体命中间隔或多段倍率。
