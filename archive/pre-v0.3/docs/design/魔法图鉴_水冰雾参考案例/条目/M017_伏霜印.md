# M017 · 伏霜印

**把一支待发冰矛留为器物的能力，承载表面受压或受击时沿预定方向反刺。**

状态：主体设计提案，待验证。基础符文：水、凝固、凝聚、以太、封存、回应、释放、穿透。组织：仪式／附魔。[图鉴](../README.md)

## 构造与建立

`水 → 凝固 → 凝聚；承载：以太＋封存，保存待发冰矛`

`外支：回应承载表面的挤压或冲击 → 释放 → 穿透`

这段构造使载体成为具有条件反刺能力的对象：封存保护待发作用，回应把承载表面的受力联系到释放，穿透限定释放后的贯入方式。受压是本例依载体性质选定的条件，不是回应在所有魔法中的固定含义。采用[共同约定](../水冰雾_共同约定.md)中有限元素与作用寄存的提案。触碰盾、门框、踏板等合适载体，约两秒建立一枚印记。完整自生投入约16法力及一次建立附魔的绘制耗材，保存一发普通[贯刺](M001_凝水贯刺.md)，发射投入已经预付。

## 触发与使用

射击方向相对载体固定。盾面受正面冲击后沿盾面朝向反刺；踏板受踩压可以向上发射；可搬板件允许调整朝向再布置。石块、友方或玩家误触也可满足同样挤压条件，不自动识别敌我或追踪攻击者。

发射后须补回实际材料与作用投入。载体破坏会破坏封存，使未发内容泄出或碎落，不自动补发一次完整攻击。核心可以带走，载体凭已保存的内容和预付作用承担这项能力。

## 组合、冒险与表现

准备使玩家在交战中腾出一次动作，可与主动攻击或吟唱并用。将印记留在搬运必经的门侧也能保护行程；重访需要辨认它是否已经触发或损坏。

[冰闸印](M018_冰闸印.md)继承承载与回应，但外支改为造闸，作用与储量分别记录。更强预备攻击和更合适载体可深化本方向，具体多发、循环、遥控或敌我辨识不在当前基础能力内。

待核对：合适载体、挤压阈值、储备状态的显示、补充过程、绘制耗材及寄存内容与载体体积的关系。
