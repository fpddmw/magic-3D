# M018 · 冰闸印

**让载体在受压后沿预定方向长出冰闸，将准备转化为现场的阻挡与分隔。**

状态：附魔分支提案，待展开。基础符文：水、凝固、铺展、延展、以太、封存、回应、释放。组织：仪式／附魔。[图鉴](../README.md)

## 已经明确的构造

承接[伏霜印](M017_伏霜印.md)的载体寄存与回应关系，将外支从集中贯刺改为[冰闸](M007_冰闸.md)的铺展、延展。

`承载：以太＋封存，保存造闸所需内容与作用`

`回应挤压或冲击 → 释放所存内容 → 凝固；形态：铺展＋延展`

载体在建立时确定出闸位置与方向。受压触发后，冰闸按真实生长、阻挡和受力形成，不能在被占据空间中直接完成无条件重叠。触发也可能来自友方、投物或误触。

## 与已有条目的关系

它将即时造闸变成载体所拥有的条件能力，单独计为一个作用条目。当前完整规模若采用普通门宽冰闸，就必须准备该冰闸对应的六份水，不能沿用伏霜印一支冰矛的材料预算。

可在[组合场景](../水冰雾_组合与冒险.md)中提前经营分隔、堵住追击路线；闸形成之后可以保留、爆散或回收，与普通冰闸遵循相同材料关系。

## 尚未展开

当前只明确分支含义，尚未设计建立时长、完整法力、载体适配与储量承载形式、补充方式、触发到生长的时序，以及载体被毁时未完成作用的结局。这些缺项继续保留，不套用伏霜印的16法力或两秒建立当作确定参数。

当前计入21个条目中的1项待展开分支，不声称已经达到其余主体提案的描述程度，也不把它计作已可实施能力。
