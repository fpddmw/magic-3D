# M021 · 融霜回流

**让选定残冰退成水，沿实际通路牵回容器或指定汇入处。** 回收会同时撤去原来的材料结构。

状态：主体设计提案，待验证。基础符文：水、借用、融化、牵引。组织：连续组织，按吟唱候选记录；模板细节待核对。[图鉴](../README.md)

## 构造与操作

`水＋借用已有冰水 → 融化 → 运动：牵引至指定容器或汇入处`

前期在约六米内，连续引回选定区域中的材料；完整操作约两秒，最多六份。玩家看见冰从指定位置退去，水沿真实通路汇回。已有水直接承接牵引，不需要另造一份再返回。

当前已提出连续处理动作，尚未完整比较专注塑造与持续维系各自带来的操作区别。因此暂列吟唱候选；施放时间达到两秒本身不足以决定模板归属。

## 投入与后果

回收普通水约消耗1加每份1法力；需要融冰时，每份再加约1。节省的是之后生成材料的投入，不恢复此前已经消耗的组织、推动或受力法力。

熔掉承重部分可能让物体先落下；回收[冰闸](M007_冰闸.md)重新暴露射线；撤去[冰轨](M011_霜径滑行.md)会改变道路。[裂冰](M008_裂冰爆散.md)后的残片只有真正被熔解并引回的部分成为库存。

停止时，已完成的融化与搬移保留；尚未牵回的水按当前状态留下。被打断时的具体动作与供给衔接仍需细化。

## 选择与冒险

缺水、准备撤离、需要清出被冰堵住的道路时，它很有价值。[秘壶](M019_盈水秘壶.md)可接收回来的材料，带往下一处环境。水源充足或需要迅速追击时，玩家也有理由留下残局前进，回收不是每一轮攻击的强制步骤。

更大范围与处理规模可以继续展开，后期参数尚未制定。表现需让结构退去、材料流回与容器实际接收一一对应。

待核对：模板与专注、选取区域、碎片统计、通路遮挡、容器容量不足，以及两秒时长与实际材料量的对应。
