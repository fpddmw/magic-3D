# M005 · 旋流卸力环

**几道相互错开的水弧转向来袭一侧，用斜向回旋偏开冲击。**

状态：主体设计提案，待验证。基础符文：水、借用、环绕、交织、回旋、守护。组织：维持。[图鉴](../README.md)

## 构造与行为

`水＋借用；形态：环绕＋交织；运动：回旋；全术：守护`

维系承接针对施法者的保护关系。水形成围绕角色、相互错开的弧带，来袭危险改变时，水带转到相应一侧，以已有流动偏转来物。守护组织已有水的分布与动作，保护能力仍来自这些水带的实际力量。

前期三份水，建立约8法力，维持每秒1，承受一次普通箭矢冲击再消耗约3。能够可靠偏开单方向接连射来的普通箭矢、缓和一次近身斩击；重弩、沉重冲撞或两侧同时攻击能够穿过或打散部分水带。

## 并用、损耗与结束

已经建立的守护关系自行工作，玩家可转去操控[水索](M003_引水成索.md)或吟唱[重贯刺](M001_凝水贯刺.md)。从护流借走一份水发射冰矛后，保护立即只剩两份，弧带变短、变薄、出现缺口。

水源充足不自动补回被取走或打散的内容。补充与修复支路尚未展开。停止维持后水带不再主动保护，现有水和运动留下自然后果。

## 体验与成长

穿过射线、碎物或间歇危险时，这项保护也能创造搬运和通行机会；具体能挡住何种环境冲击沿同一强度规则判断。

画面必须呈现威胁侧的水弧转动、偏转方向与材料损失，使玩家看出为什么挡下、为什么漏过。可以继续深化力和覆盖，后期阈值、对多人的保护构造尚未设计，不因材料多就推定全方位无敌。

关键语义缺口：当前构思需要水带朝来袭一侧调整，但尚未明确守护依据何种局部感应或可观察信息判断威胁。需把这种信息与反应关系落实后，才能将主动转向写成完整能力；它不自动获得穿墙预知或敌我识别。反应速度、交叉攻击分配、消耗与损水关系也待验证。
