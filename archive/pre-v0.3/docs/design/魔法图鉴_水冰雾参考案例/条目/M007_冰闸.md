# M007 · 冰闸

**从选定支点延伸一块厚冰片，真实地挡住、顶开或承托事物。**

状态：主体设计提案，待验证。基础符文：水、凝固、铺展、延展。组织：瞬发。借水版本增补：借用。[图鉴](../README.md)

## 构造与完整过程

`水 → 凝固；形态：铺展＋延展`

玩家确定建立位置和伸展方向，冰从该处长成厚片。前期约半秒成形，完整规模为门宽、约两米高，使用六份水。借水时塑造约12法力，自生完整约36。

它挡住箭矢、隔断狭路，承受一次普通重击后出现明显裂损。敌人站在生长路径上会被顶开、抬起或挤压；无法推动的阻挡会限制生长并造成形体缺损，不在实体重叠处自动完成整面墙。

## 场地作用与组合

地面冰闸承担掩体；合适支点之间的斜片可以形成通路；从上方伸出的冰片在根部破坏后会落下。这些用法承接同一项从支点延伸厚片的能力。

施法结束后，冰继续依支撑、温度和损伤存在。[裂冰爆散](M008_裂冰爆散.md)可将它变成定向碎块攻击，并同时撤去掩体；[融霜回流](M021_融霜回流.md)回收材料时也会打开原射线或撤去承重。

[冰闸印](M018_冰闸印.md)进一步把造闸变成载体在受压后发动的能力，另记其触发、储备与建立责任。

## 表现与缺口

画面需要读出根部、厚度、生长方向、受阻和裂损，倾斜结构也要让承重与可行走关系清楚。成长可以深化尺度与承载，具体后期规格未展开。

待核对：建立距离、合法支点、厚片体积与六份材料的匹配、抬起和挤压的力量、损伤与断裂，以及薄楼板和承重结构的区别。
