# 符文与词义设计

2026-11-26 · 保留原 48 枚候选词库与语境多义设计体系，接入 3D 废城与 `Magic DSL v0.2` 语义编译边界。

> **当前同步提示**：原有 48 枚候选主要围绕土/水/气/火/以太建立。面对重力、光暗、局部时间速率、空间结界与信息感知等抽象规律，究竟依靠现有词的语境多义推导、还是增补少数高阶根符文（例如 `星、重、时、界`），将在后续接入 [02 · Magic DSL v0.2 正式语法与语义规范](../02_Magic_DSL_v0.2_正式语法与语义规范.md) 的 `SemanticIntent` 时校准。

## 1. 词义怎样进入完整魔法

符文承载现实存在、具有稳定定义的词语。其具体含义由要素职责、前文、连接范围与完整构思共同确定。玩家学习词义及其在语境中的用法，逐渐能够理解与改造回路。

每个词有稳定的意义联系，但可以参与不同概念。反转在水的生成、光的显明、引力的吸斥和已经成立的运动中，有相关而不同的解释，并在编译器层面映射为不同的 `Magic DSL v0.2` 空间/操作/通道组织。

数枚符文能够共同解释一个现象。整体解释需要保留每个参与词的依据；增加或移动符文时，可以改变整项魔法的含义和行为。词条不是必须逐个执行的功能积木，也不对应固定动画资源。

## 3. 形态是组织意义（映射到 3D 空间组织与执行载体）

| 词 | 核心表意 | 在 `Magic DSL v0.2` 中的组织倾向 |
|---|---|---|
| 凝聚 | 散开的内容聚为具有内在联系的整体 | 集中分布剖面、`BODY`（`SPHERE_SCULPT / LANCE_PRISM`）或强 `COHESION` 约束 |
| 环绕 | 围绕中心组织 | `CLOSED_RING` 路径图与 `DISTANCE` 约束，或围绕中心的 `SURFACE` / `REGION` |
| 铺展 | 向外展开并占据空间 | `SURFACE`（`BOUNDED_PLANE / SWEPT_STRIP`）或大尺度 `REGION` 扩散分布 |
| 包覆 | 沿对象外部覆盖 | `CONFORMAL_SHELL` 曲面配合 `CONFORM` 约束，附着目标或自身边界 |
| 延展 | 保持自身联系并向远处伸展 | `PATH_GRAPH`（`LINE_SEGMENT / ARC_CURVE`）沿锚点延伸，支撑导电通道或冰桥 |
| 交织 | 不同部分穿插并共同成形 | `PATH_GRAPH`（`BRANCH_WEB`）多节点边图与交叉连结 |

这些是表达方向，具体轮廓由整幅回路、`Operation` 与 `ArtKit` 宏观构图共同确定；多个词可以共同塑造一种结构。球、环、幕、链、网等可命名结果，不列为独立形态符文。

环绕进入形态职责，解释围绕中心的分布；进入运动职责，解释已有主体绕中心行动。六个词不与六套固定美术动画一一对应，而是共同驱动有限空间载体、`ArtKit` 材质与动作变化。

## 4. 语境怎样约束多义性

职责说明本处解释什么，连接说明影响谁，前文提供已经成立的依据。例如：

| 语境 | 完整解释中的贡献 |
|---|---|
| 水的生成接受反转 | 水分退去／抽干，而非改变一段无关运动 |
| 已形成的光接受反转 | 显明转为遮蔽吸光，成为暗域的依据 |
| 引力／汇聚接受反转 | 沉重向心坍缩转为猛烈向外斥力爆发 |
| 已形成的运动接受反转 | 改变本次所指运动方向，不自动改变材料性质 |
| 内容封存于载体 | 载体保存相应内容并限制其对外作用，后续释放须有条件 |

这些案例说明解释规律，不构成全部可能义项的穷举表。遇到不同整体构思，要重新判断相关词义与关系，而非直接套用最显著属性的统一变换。

守护、寻觅、共鸣等意向参与组织整项魔法或局部。保护谁、感知什么、通过什么关系起作用，需要整幅构造说明，并落到 DSL 的契约与关系字段上。

## 5. 引用、前提与省略

同一构筑中的同名符文只投入一次，衍生构成展开核对。后文引用已经成立的元素、性质、主体和来源；不同职责可以重复出现。语义继承和运行循环不要求再次放入同名符文。

空槽保持未参与。现场目标、接触和来源可以按术式约定取得（如锁定目标、周边积水或脚下石地），不要求玩家穷举“人、门、地面”等对象词；实际没有的感知或关系也不凭空补齐。
