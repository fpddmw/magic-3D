# 元素与衍生元素

2026-11-26 · 保留原 5 基本元素与 11 项衍生概念构思，剥离旧 2D 七组细分材质体系，作为上层玩家语言接入 `WorldLaw` 与 `Magic DSL v0.2`。

共同设计见 [01 · 设计哲学与总纲](../01_设计哲学与总纲.md)，词义及候选见 [符文与词义设计](符文与词义设计.md)，回路见 [施法契约与魔法回路](施法契约与魔法回路.md)，正式 DSL 规范见 [02 · Magic DSL v0.2 正式语法与语义规范](../02_Magic_DSL_v0.2_正式语法与语义规范.md)。

## 1. 基本元素提供什么

基本元素提供一组相关的性质与变化倾向。符文进入不同要素职责后，从这组意义中取用相应内容；连接和整体意向决定它怎样与其他概念共同成立。

| 基本元素 | 核心性质 | 能够向外展开的意义 |
|---|---|---|
| **土** | 成体、凝定、承载 | 坚固、重量、边界、组织与形体（含重压/岩壳基础） |
| **水** | 流通、浸润、相合 | 连续、溶合、滋养、渗透、折射与交换 |
| **气** | 通达、弥散、传递 | 传播、压力、振动、轻盈与气息 |
| **火** | 激发、温热、炼变 | 燃烧、显明、释放、成熟与破坏 |
| **以太** | 魔力本身：使意向能够作用于现实的奥术能量 | 魔力凝聚、赋形、感应、时空干涉，以及对魔法自身的约束 |

**以太按本游戏的奥术元素使用。** 法术消耗魔力是施法的共同条件；填入以太符文，则使魔力本身或高阶抽象法则（结界、时间、星辉、感应等）成为本次作用的内容、承载或干涉对象。

生命、雷电、光等由基本元素和表意关系衍生。它们形成后具有自己的性质与法术用途，基本元素的数量因此保持收束。

## 2. 衍生怎样进入魔法语言

### 2.1 元素在职责中形成关系
衍生使用同一套回路、要素与符文规则。主体元素提供内容，其他元素进入生成等适用职责，表意符文限定相关变化；这些部分共同形成一个清楚的概念。
- 例如：土以火性参与生成并由“融化”限定，形成**熔岩**；气承载火的激发力并以“对立”形成两极，导向**雷电**。
- 前面形成的衍生元素继续参与形态、运动、维系或承载。**元素成立之后，还要留出表达一项法术的空间。**

### 2.2 自由槽参与概念的形成
自由槽能够接入元素取用、生成、后续组织和整项法术等不同范围。要素旁的多枚符文共同解释本职责；沿主路接下去的自由符文继续解释前文已成立的整体。具体示例见 [回路规范第 3 节](施法契约与魔法回路.md#instant) 的雷电与暗的推导。

### 2.3 同名符文只投入一次，后文继承已有内容
**同一构筑中的同名符文只使用一次；核对时展开衍生元素的构成。** 前文已经含有水或以太，后文承接其性质和作用，不再追加一枚同名符文。
- 例如：毒从生命的滋养、更新作用上施加“反转”；灵从已经形成的生命上施加“离体”。两者都继承原有组成，不再额外投入水或以太。

## 3. 11 项衍生元素设计基线

| 衍生元素 | 简要成立关系 | 形成后的固有性质与 3D 表现方向 |
|---|---|---|
| **冰** | 水在成形中接受“凝固” | 水固定为坚硬、寒冷的实体（3D 可踩可挡可碎刚体）；保留融化回水的联系 |
| **雾** | 水以气性生成，接受“弥散” | 湿润内容弥散于 3D 空间，具有体积遮蔽、浸润、聚散与渗入性质 |
| **熔岩** | 土以火性生成，接受“融化” | 有重量与体积的灼热流体，亮核暗壳，流动冷却后凝成石块 |
| **晶体** | 土以水性凝结，生成接受“对称” | 形成重复有序结构，支持折光、共鸣及有选择的能量传递 |
| **金属** | 土接受火的“精炼” | 凝聚且可锻塑的实体，强调强度、锐利与高导电性 |
| **光** | 火的显明性由以太承载，以“分离”使显明脱离燃烧 | 照亮废墟阴影、显现隐藏、锐利光束 |
| **暗** | 对已经形成的光，反转其显明作用 | 吸光暗域、吞噬视野与敌方锁定、静谧压迫感 |
| **雷电** | 气承载火的激发力，以“对立”形成两极 | 蓄势电离、极速贯通，沿潮湿水洼与金属导通图连锁暴击 |
| **生命** | 四元素“调和”为体，以太使生成指向自身并“循环” | 能够摄取、成长、更新与修复的活体整体 |
| **毒** | 承接生命的滋养、更新作用，对这一作用施加“反转” | 维护过程转为持续损耗与失调 |
| **灵** | 已形成的生命接受“离体”，由原有以太承载活性 | 脱离肉身的活性及其感应、回响联系 |

## 4. 复杂含义怎样保持简洁

- **雷电不是单纯一条直线特效**：它的核心是两极积蓄与导通——在 3D 废城里，“苍穹劈落天雷 → 顺着雨水积洼和铁甲传遍全场”才是它的大道魅力。
- **性质继承要看得见**：雾保留水的导电/微湿属性，熔岩保留土的重压与火的灼烧。

## 5. 与 `WorldLaw` 及 `Magic DSL v0.2` 的衔接说明

在重构后的 3D 架构中，不再按“七组工业材料配方”建模拟引擎，而是把上述 **5 基本元素 ＋ 11 衍生概念**作为**上层玩家语义语言**，由编译器展开并映射至 `WorldLaw` 材料/作用场（如水、冰、石、熔岩、雷电、光暗）与 `Magic DSL v0.2` 现象原语。

> 后续语义校准：重力、局部时间速率、空间屏障等非传统元素法则如何在“5 元素＋48 符文”或少量新增根词中拥有庄严而清晰的构筑来源，将在接通 [02 · Magic DSL v0.2 正式语法与语义规范](../02_Magic_DSL_v0.2_正式语法与语义规范.md) 的 `SemanticIntent` 时最终敲定。
