# 从同一 Core 到逻辑、艺术与施法体验

三个消费者共同引用主体身份、实际状态和已经发生的世界事件。工程可以选择采样、碰撞代理或声音合成等手段。若手段会引入感知、供给、运动、支撑或时序能力，须回到 Core 给出依据。

| 消费者 | 输入 | 输出与回传 |
|---|---|---|
| 游戏逻辑 | 主体与来源、性质、有效关系、过程、契约 | 降低到执行 DSL、WorldLaw、有限载体和非几何基础设施；回传实际材料、连接、受力、信号与退场事件。 |
| 艺术 | 主导语义、空间组织、阶段、实时状态与有效信号 | Expression 规定构图、主次与留白、独立表现范围、异象、材质光学、速度与强度曲线、静默、冲击、混响和残响消退。ArtKit 与 Director 消费它。 |
| 施法体验 | 控制者、供给者、归属、交付门槛与失败条件 | 转为输入、动作、韧性窗口、焦点占用与交接。Combat/Controller 报告实际松手、失衡或载体损毁。 |

水网可随实际相变传播结晶光和应力声，柱廊回响可大于网体。只有已凝固且有有效支撑的部分承重。雾的默认表现显示实际密度，感应波纹另查活动信息联结和真实扰动。引力的构图重心和环境音张力可随积蓄改变；位移由实际场作用决定，重音跟随交付。导演可压缩短术的四拍，对感应术可用信号首次明确抵达承接第三拍。四层视觉（轮廓、材质、次级运动、环境响应）与四层声音（起势、蓄势、交付、余响）在实机场景验收。[艺术注册表](../../game/data/art/artkit_registry.json) · [三组 Expression 转译样例](../../game/data/art/expression_profiles.json)

逻辑转译的 `projections` 逐项登记空间、锚点、方向、时间剖面与传播。一个连续交织的路径主体可用 `BRANCH_WEB` 表达；其释放过程还须单独指定相变、材料引用、起点及实时连通策略。每步选择都可回到 Core 检查。沿水传播的冰晶与声音在实机消费已经到达的段。引力上下两个变体共用同一套执行映射。[执行投影](../../game/data/lowering/semantic_bindings.json) · [对照结果](阶段A_配对验收.md)

## 状态与失败

| 判定 | 例子 | 行为 |
|---|---|---|
| INVALID_MEANING / AMBIGUOUS | 仅靠穿透发射；火未指明显明或温热 | 给出缺失前提，或返回候选让玩家明确所指。 |
| UNSUPPORTED_LOWERING | 石梁振动感应意义成立，执行层缺结构信号能力 | 保存 Core 并指出映射缺口。 |
| MISSING_BINDING | 合法借水构筑在干廊使用 | 按契约检查来源与代价；已完成的部分继续留存。 |
| IMPLEMENTED_UNVERIFIED | 有运行器和调用证据，尚缺实机证据 | 记录版本和待测场景。 |
| VERIFIED | 同一版本有实机复现、因果与视听记录 | 登记平台、场景、构筑版本及证据。 |

A 阶段映射表中的 CONTRACT、PARTIAL、DEFERRED 表示有执行格式、仅部分覆盖、能力延后。旧矩阵的 SUPPORTED 表示格式准入。它们都不足以填入实机通过状态。预算不足时在创建前反馈，保留场上已有冰桥和材料状态。

阶段 B 直接读取 SemanticGraph。阶段 E 评估法坛／世界暂停时由模型提供 SemanticIntent，再由确定性路径绑定为同一输入图。确定性路径负责语义图、整体解释、Core、能力与预算校验、CompileTrace；退出模型后才进入战斗。执行载体限于 BODY、PATH_GRAPH、SURFACE、REGION，另有 Reference、Relation、Process、Resource。合法产物调用登记的能力，禁止法术名特判、任意脚本、通用 CSG 与任意网格切割。
