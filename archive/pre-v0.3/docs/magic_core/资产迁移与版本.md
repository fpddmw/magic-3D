Schema 约束形状与封闭构件。词、概念、性质或艺术模块的有效登记由相应表负责。B 阶段据表构造版本索引，不另手写一套可变枚举。旧 Schema 内的枚举随旧版本冻结；升级执行格式时再生成投影并用原样例回归。

## 发布决定

[决定登记](../../game/data/core/decisions.json)的 BASELINE 表示当前依据，PROPOSED 等待裁决，DEFERRED 表示暂缓，SUPERSEDED 保留被替代的规定。每条记录关联概念、义项、公理、样例、反例与迁移影响。高层讨论由设计者定案，工程提交具体冲突与可选修订。

例如扩大「反转」的适用面时，先登记决定和能区分新旧解释的反例，再修改对应义项和性质权限。检查 L02、L04 与 S06、S14，记录旧构筑是否需要显式迁移，再检查下游通道和艺术转译。已确定法术保存 Core、推导及 core、semantics、execution、artkit 四个版本；重新解释另存新版本。仅调音色时只提升 artkit。撤销或更名的稳定 ID 保留旧版本解析入口及替代记录。
