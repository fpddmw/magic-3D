# Magic Core · 语义设计入口

玩家能用同一门语言做两件不同的事。法坛上的「凝固」可限定一枚冰矛所用的材料；战斗中的「凝固」可作用于刚绕过石柱的水索。前一种构筑在施法前就知道使用何物，后一种必须等到松手才知道冻住哪里。Core 负责保存这种区别。

**权威顺序。** 设计者裁定世界公理、词义和权限。语义编译使用有类型的引用与规则得到一份确定的 Core。游戏逻辑、艺术和施法体验分别消费它，并以同一主体、事件和实际状态对齐。Godot、WorldLaw、ArtKit 或动作设计发现矛盾时，把最小反例和受影响的规则交回设计者。可以更换载体实现，同时保留法术原有含义。

**活动版本。** Magic Core 0.1.2 已登记研究 02 的以太七公理。首批词义规则为 0.1.1，构造规则为 0.1.1，执行格式为 0.2.2，艺术数据为 0.2.3。历史案例保存人工对照，活动编译器可从原图推得逐过程干预契约。引力改向与水网断边已通过离线回归。[以太七公理](世界公理与概念.md) · [运行与验证边界](阶段B_编译器与验收.md)
