# `F03 开口弧刃` Stage 1 原始素材投放说明

本目录用于存放由 **负责人 + GPT/Gemini + ImageGen** 产出的 `F03 开口弧刃` 原始概念图与 2D 视觉素材（对应 [Pilot 01 任务书](../../../../docs/art_assets/pilot_F03_arc_blade.md) Stage 1）。

## 必备文件清单

请将审核通过的原始图像按以下精确文件名放入本目录：

| 文件名 | 用途 | 推荐比例 / 分辨率 | 底色与画面要求 |
|---|---|---|---|
| `concept_sheet.png` | 主视觉概念定调 | `16:9` 或 `1:1`（≥ 1024px） | 庄严废城石殿光影下的开放弧刃，窄锋厚腹、内弧留白、冷银暗蚀反差 |
| `storyboard_4frames.png` | 四关键帧生命周期 | `2×2` 或 `1×4` 横排分镜 | 依次展现：沿刃展锋 → 完整展开挥扫 → 离体掠行 → 沿锋分段溃散 |
| `energy_flow.png` | 主体能量流动纹理 | `2:1`（如 `2048×1024`） | **纯黑底**；横向长轴流纹层次分明，外锋锐利、内腹渐淡、左右头尾收敛 |
| `erosion_mask.png` | 局部侵蚀断裂 Mask | `1:1`（如 `1024×1024`） | **纯黑白高对比**；有机撕裂/丝状/碎块渐变分布，禁止规则棋盘或均匀小点 |
| `accent_sparks.png` | 锋切光屑与余迹细节 | `1:1`（如 `1024×1024`） | **纯黑底**（或透明 PNG）；方向性细长碎光与火星/冷屑，无杂乱背景光斑 |

## 交付检查清单（交接给 Astra 前）

- [ ] 5 个文件名完全一致；
- [ ] `energy_flow.png` 与 `erosion_mask.png` 无文本水印、无人物背景、无透视角度变形（需为平铺可用的正交 2D 纹理）；
- [ ] 负责人已确认 `concept_sheet.png` 达到预期艺术气质（门禁 G1 通过）。
