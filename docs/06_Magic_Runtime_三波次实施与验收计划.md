# 从语义基线到 Godot 废城切片

## 施工会话可以领的前三项任务

1. **版本索引与语义输入。** 从 concept、aspect、sense 稳定 ID 建索引。首批 24 词为水、气、火、以太、光、重力、空、凝固、凝聚、延展、交织、铺展、弥散、联结、回应、借用、牵引、排斥、穿透、分离、反转、延续、爆发、束缚。M009 的验收另纳入「汇聚」。对照 33 个已形式化义项，先跑 M003、M009、M014、L01–L05。遇到子集外的词返回覆盖缺口。交付版本锁定、重名/悬空引用报错与词表覆盖报告。
2. **解释与对照。** 使用已登记义项，绑定所指和作用范围，合并同一对象的约束。区分构成与事件，保存候选和裁决依据。首先独立重放[引力改向与水网断边](magic_core/阶段A_配对验收.md)，逐字段比较完整产物与预期。再用同一个火构筑切换显明与温热，再用普通雾添加信息联结，逐节点比对 Trace；交付未知构筑的解释与不成立的原因。
3. **执行、表现和控制交接。** 对有限引力域进行首次降低，分开生成可检查的执行数据、Expression 和施法控制契约。未覆盖义项报告缺口。确定性预算、DAG 与句柄验收沿用旧执行边界；传播一期仅挂 TRANSFORM、DRIVE、TRANSFER。让艺术与动作人员用同一份语义输入准备镜头、动作和声部，在 C 阶段接实机。

规划期维持 Option A。生命高阶干预、性质跨本体赋予和人格连续性等未决事项各有决定 ID，不阻塞水、光、热与有限引力子集施工。只有实际通过的证据才更新对应验收状态。
