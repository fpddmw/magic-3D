# 世界公理与概念

八条基础公理使用 AX 系列 ID。研究 02 的七条以太公理使用 E1–E7。其陈述以[世界登记表](../../game/data/core/world.json)为准。本性提供默认行为，性质可以成为作用对象，关系指定端点与通道，组织让整体取得相应能力。变化须有明确所指，以太为获准的异常联系提供媒介，代价由有名的来源承担，因果使已经发生的变化留在世界里。

## 02 · 以太与魔法干预权限

意义说明希望何种现象成立，以太使额外的成立条件成为可能，魔力支付建立、改变与维持这些条件的代价。依意义组织起来并已在世界中起作用的整体称为魔法。事物的实际行为同时受本性、状态、结构、环境和已成立的奥术条件影响。

| 公理 | 设计规定 | 对构筑的约束 |
|---|---|---|
| E1 | 以太承载异常存在、性质与关系，资源始终有限。 | 普通施法隐含媒介。组织以太、建立特殊奥术联系、寄托能力或作用于已有魔法，需要显式媒介依据。 |
| E2 | 意义确定内容，魔力承担代价。 | 记录谁在何时支付。增大余额只能改变已获准干预的可交付量。 |
| E3 | 五种干预分别为具现、调动、重构、赋予、干涉。 | 具现建立有限的新内容或作用，调动运用已有内容，重构改变状态或组织，赋予建立原先缺少的性质或关系，干涉改变局部规律的实际作用。它们描述每个过程，可共存于一个构筑。 |
| E4 | 对规律的干涉限于局部实际作用。 | 引力改向须指定作用域与受力关系。改变一个过程的演化速率须保留既成历史。 |
| E5 | 世界许可、充分意义、实际条件、足够责任须同时成立。 | 编译时查世界许可并追溯词项。施法时核对现场来源、对象、媒介、连接、控制与余额。 |
| E6 | 已成立的具体魔法可以成为另一项魔法的对象。 | 指明实例及其实际内容、空间组织、联结、存续条件或作用。抽象概念、施法者知识与世界公理均超出该权限。 |
| E7 | 同一世界内的作用按实际性质、关系与承担能力共同决定结果。 | 两个反向力可以抵消，施法者仍分别承担维持责任。热作用按热通道结算，结构约束可能因过载失效。切断悬冰的支撑后，冰体继续受力，已经发生的相变保留。 |

持续工作的奥术结构可由施法者主动供给，可支取器物或场所寄托的有限储备，也可通过仍然有效的联系从真实环境取用。蓄力后松手描述付款时序；判断有无寄托，还须查明储备由谁保管。借水取得的是材料，冻结同一份水仍须支付相变的代价。循环、封存和联结只能组织已有来源。原契约可以约定松手、打断或耗尽时撤去自己的支撑；另一项魔法主动切断这份支撑时适用 E6 的实例、方面与媒介要求。

E1–E7 均已作为 D16 定案。阶段 B 已对引力和水网逐过程验证局部许可、词义依据和条件。跨实例干预、多术结算及寄托、外部供能的端到端行为仍属设计基线。研究 03 由设计者另行讨论。[设计决定](../../game/data/core/decisions.json) · [阶段 B 验收](阶段B_编译器与验收.md)

## 概念怎样成立

| 路径 | 例子 | 编译时应保留的依据 |
|---|---|---|
| 状态变化 | 水取固态组织构成冰 | 同一材料的本性、目标相态 |
| 内容与组织 | 气体中弥散着细水滴构成雾 | 水滴仍是液态；厚雾的覆盖体积不能作为实心水量 |
| 性质独立化 | 火的显明可独立承载为光，温热可独立承载为热作用 | 明确选择的性质、许可和承载依据；推导期间无需点燃任何场景物体 |
| 合法转换 | 光学显明转为抑光，热作用可转为抽热 | 作用通道、已登记的对立、实际持续条件、热的去向 |
| 多规律共同成立 | 雷电需要势差及可用通路，晶体需要重复的内部组织 | 验证使整体现象成立的关系；矿物的名称并不授权它导通所有能量 |

直接掌握「光」与从火的显明推得光，是进入同一概念的两条路径。两者可以在当前构筑中拥有不同来源、代价与持续契约。金属可以是现成材料，也可由合适矿料精炼取得。生命、毒、灵保有研究条目。生命类仅登记已有活体与更新过程，活性离体、人格连续性和复活权限均待设计裁决。

## 性质的继承和边界

| 冻结同一条水带时 | 处理 |
|---|---|
| 材料身份、有限材料量 | 本性未变，沿同一主体承接。分出一段时给派生部分单独记账。 |
| 液态流动、固态刚性、实际轮廓和运动 | 按新的相态重新确定流动与承重；相变以当下轮廓和运动为输入。冻结本身没有悬空或停止运动的权限。 |
| 支点、传力、维持束缚 | 检查实际端点、材料连接、供给与支撑。断掉的联系失效，仍连续的材料可保留。几何交叉没有提供结构焊接的依据。 |

每次引用都区分概念的性质、现场实体的当前状态、关系的通道和过程的演化速率。工程可根据已确定的连续性生成有限碰撞体，但部分之间是否可以传力仍由实际连接决定。相同原则适用于水索、冰闸、回收残冰以及后续使用这些材料的其他法术。

## 认识、权限与量级

以太是异常作用的媒介，普通施法隐含以太媒介，主动组织媒介时使用显式以太义项，魔力承担干预的代价。认识热交换可以成为选择温热的依据；独立化需要登记过的转换，现场抽热还需要明确对象、通道和供给。局部时间速率限于指定过程，历史事件保持已发生。一般跨本体赋予、时空改写的权限保留在决定登记中。

魔力限制可支付的干预量，认知限制可解释的性质，掌控影响精度、稳定性与有效转化。构造决定如何分配有限作用，场地决定有多少可借用的水、支点或导通路径。知识成长分概念认识、性质理解、规律发现。实际费用系数归平衡域维护；知识的解锁与传承另待设计。
