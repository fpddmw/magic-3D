## 设定与裁决

八条公理、性质继承、以太与魔力的职责、概念与时序的区别、符文知识可复用及作用独立付费均有基线。54 枚候选采用原 48 加光、电、时、空、生、重力。积蓄是有时长与供给的过程。生的指称已经保留，深层生命干预安排在后续。

待设计者裁决的项目是性质独立化和跨本体赋予权限、认知取得权限的条件、高阶时空与人格连续性、知识发现与高阶构造、积蓄是否独立成词，以及 M009 两种束缚契约的关系。D09–D14 分别记录适用范围和迁移影响。工程可以在已登记的许可子集内开始阶段 B。

## 本次实际验证

- 使用 Draft 2020-12 检查三个 Schema 本身，并验证 13 个 Core 参考构筑、7 个旧执行样例及 1 个旧意图样例。旧执行数据只随附一份实际意图文件，另外六个意图 ID 仍为历史引用。
- 检查 54 枚不同词、63 个唯一义项、六条构造规则、8 条公理与覆盖矩阵 M001–M021。检查全部 52 步 Trace 的节点、词与义项顺序、Core 输出和构造规则，检查语义依赖、过程先后、端点、来源、过程前提和状态变化的登记 ID 及版本。4 个部分映射逐个核对到旧 JSON 中实际存在的执行 ID。
- 检查 21 个新语义向量的基础案例、义项和预期／排除结果。对新 Schema 注入 8 项非法结构，覆盖额外脚本、未知构造或操作、缺少来源或中断契约、非法端点、缺少规则 ID 和未固定版本，均被拒绝。
- 逐字节对照旧 Schema、意图、7 法术、综合表、21 条工程向量及归档的 Wave 计划。逐字段核对提取的执行约束、预算系数和艺术模块。艺术默认值的迁移差异是普通雾的声纳波纹改为「有联结且有扰动」。
- 阶段 A 交付时，上述 Core 与 Trace 是人工参考产物，语义向量是其验收输入。盲测、工程负向向量的完整执行、Godot 画面／手感和硬件性能均须在相应阶段取得证据。
