# Godot 技术美术实验室 · 实机验证方法与质量纪律

研发顺序以[主线演进计划](../v0.3/演进与切片计划.md)与[原子资产体系](../art_assets/README.md)为准。ArtLab 现作为 **Pilot 01（`F03 开口弧刃`）及实验 A–C** 的第三人称交互实机工作台：用同一套薄编排接口与真实世界信号，检验「ImageGen → Blender → Godot」资产的可塑性、真实物理反馈及不改代码的跨魔法迁移能力。

## 从首版带走什么

在 `b06de8c`，石殿与外景、时间条、多视角抓拍器、离线贴图烘焙、骨骼人形、分轨声音都已进入工作台。天体研究用 12 个控制点扫掠光带、解析壳厚并绘制星屑；它在 3.85 s 固定交付，首次扫掠碰地后收束。没有给周围受体提交重力、抽热、世界消光或奥术干涉。负责人退回月体成形、人物动作与交付重量、尺度与整体构图。当前项目保留完整[首样记录](reference_breakdowns/01_celestial_descent.md)、[观测 JSON](evidence/01/observations.json)和[旧计划固定版](https://github.com/fpddmw/magic-3D/blob/b06de8cc0a34d75e99d5ee864df65f902a2a4e47/docs/art_research/技术美术实验室与升级计划.md)。

## T1–T5 · 按构图与作用选择方法

| 研究方法 | 适用条件、技术与失败检查 |
|---|---|
| T1 动态几何与形变 | 连续轮廓可用少量骨架点（首样 12 点）、二阶响应、弧长重采样、平行传输帧与固定拓扑 GPU 扫掠。复核零长、反向、闭缝、法线、UV、截面厚度及 AABB。构图承接需稳定的局部参数与对应；材料分裂须另有实际份额、子键与速度继承。真实几何按需要设置有限代理，装饰光带不占用碰撞体。 |
| T2 材质与光学 | 按目标选不透明写深度、解析光学厚度与消光、软深度交界或受控折射。透明叠层的屏幕取样、快速运动的雾重投影都要在实际机位复查。暗域可以用负空间及疏密变化表现；真实遮光须独立光学合同。 |
| T3 流场与细节 | 区分真实加速度（m/s²）与艺术速度（m/s）。沿共同参照派生方向、密度与局部时相，可用有界曲线采样或 GPU 粒子。真实尾迹读取已提交位姿的有限历史；艺术轨迹另记。真实碎石单独入世界账。 |
| T4 资产、声音与身体 | 保留离线高度/微法线、FBM/Worley、FlowMap、衰减图与分轨管线，标注来源。先看动作静音剪影与正常镜头里的脚、骨盆、肩手、武器，再选制作骨骼片段。按真实输入及回执衔接音轨，室内外切换声场，尾声录全。真实接触发声需接触事件。 |
| T5 更新与预算 | 固定物理步、有限控制点/代理更新、渲染插值分别测量。预分配固定拓扑，细节按质量档削减，实效边界与操作提示保留。产品目标为 M6 Metal 和中端 Vulkan 在真实负载下 1080p P95 ≤ 16.67 ms、战斗显存 ≤ 2.5 GB。首版电影与雨殿基线各有独立证据范围。 |

原质量否决项继续使用：低面占位几何冒充复杂形态、整体缩放冒充局部构形、删旧造新冒充连续继承、均匀透明层冒充光学厚度、均匀散点冒充场运动、同一加法条纹充当所有材质、方块人倾斜充当身体承重、仅凭自动测试宣告审美通过。构图是否需要球、环、披风、浮空或某一音轨，由具体作品决定。

## 实机评议怎样接回资产与语言

1. 从当前切片任务书（首项为 [Pilot 01 · F03 开口弧刃](../art_assets/pilot_F03_arc_blade.md)）与[薄编排契约](../art_assets/thin_contract.md)确定世界只读信号与演出目标；通过门禁 G1（概念与贴图）和 G2（灰模剪影）后再在 ArtLab 中接入实机交互。
2. 工作台记录真实输入、实例代际、实得中心、范围、世界交付和接触回执。时间条用于重放输入与快照。全片保留主机位、声音和余韵；按研究问题加拍侧背、材料、室内外、打断、多术和分层。首版六时点三机位可重放。
3. 在同一镜头比较完整演出、只看动作、关闭候选艺术层及真实对象反馈；用灰阶读剪影与负空间。记录具体秒数、预期与观察。额外的艺术资源、缺失的作用接口、表达缺口和编译知识缺口分别登记。
4. 以换形和换用等正交变奏检查复用。需要新增通用后端时记明输入、输出、限制、失败和依据。艺术品质由独立读谱、实机及人工评议各自留证。
