# Godot 4.5 技术美术实验室与五阶段升级计划

2026-11-28 · 针对当前 `game/art_kit/` 机械拼装与表面同质化问题，确立**“先技术美术逆向攻坚 → 提炼参数化动态构造算子 → 反哺升级并定型 Magic DSL → 机器契约、立体废墟合流与模型/性能闭环”**的整体改造和升级路线。

> **研发主序反转**：不再先定抽象模块再强迫所有奇幻现象迁就；改为先在 Godot 4.5 中把完整高质量奇幻现象做出来、过肉眼审美门禁，再从真实生效的图形学与动态方法里提炼可复用算子，最后反哺 Magic DSL。

---

## 一、问题诊断与当前边界

核查 `208ab19` 的 Godot 实机底座，现有表现单薄并非引擎瓶颈，而是过去规范只写了“实现什么概念”，未规定“在 Godot 4.5 Forward+ 中如何用图形学、动态几何与真实资产实现”：
- `game/art_kit/director.gd` 目前用 `SphereMesh(radial_segments=8, rings=4)`、`TorusMesh`、`CylinderMesh`、`BoxMesh` 按单一 `beat` 做整体缩放；
- `body / region / path / patch.gdshader` 全部采用 `render_mode blend_add, depth_draw_never, cull_disabled, unshaded`，共用同一段正弦条纹计算；
- 音效依赖 20 行实时 FM 正弦波 + 白噪声生成，主角施法依赖方块组合体前倾 `0.23` 弧度持续 8 帧。

**Stage 0–2 期间的纸面语言边界**：
- 暂不继续纸面扩写 `docs/magic_language/`；保留其作为物理因果、所有权与 `D3` 调度的逻辑参考基线，待 Stage 2 实机迁移验证通过后，于 Stage 3 一次性反向升级并定型 Magic DSL。

## 二、五大核心技术路线（Godot 4.5 Forward+ / Metal / Jolt）

### T1 · 参数化动态几何与 GPU 骨架扫掠（`geometry/` & `deformation/`）
- **CPU 控制点 + GPU 扫掠**：CPU 每帧仅更新 **8–16 个带二阶弹簧阻尼的骨架控制点**（同时直接驱动 Jolt 有限胶囊或分段碰撞代理，保证物理与视觉同源），打包为轻量 Uniform 数组或小尺寸数据纹理传入着色器。
- **固定拓扑零重建**：使用预分配高分段 `ArrayMesh`（拓扑不变时零重建；仅确需局部更新顶点时用 `RenderingServer.mesh_surface_update_vertex_region`，仅在分裂/合并等拓扑事件重建局部网格），在 Vertex Shader 中实时求 Catmull-Rom / Bézier 曲线、**平行传输帧（PTF，防止截面在拐弯或过直段突然翻转）**、沿弧长 $s$ 的宽度/扭转变形与根部先动、末梢滞后的波动。
- **空间相位场**：引入统一局部进度
  $$p(s,t) = \operatorname{clamp}\left(\frac{t - \tau(s)}{D}, 0, 1\right)$$
  驱动变化沿曲线、曲面、体积或阵列连续传播（结晶蔓延、电流奔行、阵元错时塌缩），替代整块同步淡入淡出。
- **三类动态形态**：
  1. 连续形变（控制点阻尼滞后 + 截面曲线 + 空间相位波）；
  2. 共参数域构图插值（`MorphForm`，在稳定参数域与采样点间平滑过渡，差异过大则走受控中间构形或分裂接力）；
  3. 拓扑分裂与状态继承（脱离或碎裂瞬间保留同一世界位置、线/角速度、材料份额及纹理流动相位，**严禁销毁蓄力特效再另建投射物**）。

### T2 · 按渲染机制分离的多层材质与光学系统（`materials/`）
- 废除全载体共用 `blend_add, unshaded` 条纹着色器，按光学物理特性分流渲染路径：
  1. **核心主体走不透明深度写入路径**：自带多尺度纹理、法线细节、局部吸光与可控内部明暗组织，彻底消除“半透明穿帮塑料球”感；
  2. **大气与体积包络走解析光学厚度近似**：片元内解析求视线穿过球壳/柱壳的有效路径长度 $L$，结合消光近似 $T = e^{-\sigma L}$ 与视角相关边缘散射，避免昂贵体积光线步进与多层透明排序穿帮；
  3. **水体/雾/光幕接场景深度与背景缓冲**：使用 `hint_depth_texture` 做地形软接触消融，按需使用受控 `hint_screen_texture` 背景折射；
- **显式规避 Godot 4.5 Forward+ 已知限制**：屏幕折射纹理在透明阶段前截取，多层透明折射不能互捕，首波控制透明叠层；全局 `FogVolume` 含时间重投影，高速移动魔法主体不用全局体积雾以免拖影，改为解析包络 + 局部流迹；大量离散微元走 `MultiMeshInstance3D` 或 `GPUParticles3D`。

### T3 · 解析向量场驱动的 GPU 流动细节（`fields/` & `particles/`）
- 使用 `GPUParticles3D` 自定义 `shader_type particles` 采样统一解析向量场 `(radial, tangential, axial)` 与有界旋度扰动，配合 `RibbonTrailMesh` / `TubeTrailMesh` 生成随流场运动的细密流迹与星屑，严禁均匀随机散点。

### T4 · 离线资产管线、真实分层音频与骨骼动作（`tools/art_assets/` & `audio/` & `choreography/`）
- **贴图与数据纹理**：使用 `tools/art_assets/` Python 离线脚本烘焙高质量无缝多通道数据贴图（多尺度 FBM、Worley 裂纹、流体 FlowMap、柔和星辉精灵、衰减 Ramp），配合 `imagegen` 生成关键英雄表面贴图（深层月面纹/高度图、风化岩晶微法线、古奥术蚀刻法线）。
- **资产务实策略**：优先允许精选 CC0 基础资产（基础人形/环境参考或真实物理采样）或离线高质量烘焙与多层 DSP 合成，严禁运行期 20 行正弦波充当完整声效。
- **声学总线与分层混音**：建立 Godot `AudioBusLayout`（室内石殿穹顶混响总线 / 室外干声总线 / 低频重击总线 / 交付预备压低总线），每项演出按**低频主体 + 空气运动 + 材质摩擦 + 冲击瞬态 + 空间混响**分层组织。
- **骨骼动画与非线性力感曲线**：准备带真实 `Skeleton3D`、法杖挂点与披风绑定的测试人形及 `AnimationTree` **6 组核心施法姿态**（重压聚势、双臂展开、迅捷释放、武器挥斩、浮空凝滞、受阻失衡），并建立非线性力感曲线库（`anticipation` 反拉蓄势、`apex_hang` 顶点屏息、`whip_snap` 骤然抽击、`tectonic_drop` 重压砸落、`overshoot_settle` 回弹落定）。

### T5 · 三层更新频率与性能纪律
- **世界逻辑与物理代理**：60 Hz 固定物理步（少量胶囊/分段代理，不把每颗视觉碎屑建成 `RigidBody3D`）；
- **动态构形与骨架控制点**：30–60 Hz 更新并配合渲染插值；
- **GPU 材质、微形变、粒子与光学**：逐帧计算。
- 正式 1080p 60 FPS（P95 ≤ 16.67 ms）与战斗显存 ≤ 2.5 GB 须在高质量资产与正式战斗负载下独立测量验收。

## 三、强制质量否决表与 `ArtLab` 视觉评审闭环

以下任意一条出现即视为本次样本交付无效，必须打回重做：
1. 用 8 边球、标准圆柱、标准方块拼装复杂连续魔法形象；
2. 用整体 `scale` 缩放冒充骨架变形、相位蔓延与形态演化；
3. 用销毁旧特效 + 生成新特效（或简单透明度交叉）冒充脱离、分流与连续状态继承；
4. 用单层均匀透明壳冒充具有光学厚度与边缘散射的体积介质；
5. 用均匀随机散点粒子冒充受空间向量场约束的流动细节；
6. 用同一种加法混合条纹 Shader 换色冒充不同材质光学体系；
7. 用几何方块人物整体倾斜冒充骨骼施法姿态与身体承重；
8. 仅凭自动化单元测试通过宣称“艺术表现已实现”。

**`ArtLab` 强制抓拍与盲审输出**：
- `game/art_lab/workbench.tscn` 与 `capture.gd` 对每个样本自动输出 **6 个关键时点**（起势 / 蓄力 / 形态嬗变 / 爆发交付 / 持续演化 / 余韵）× **3 个机位**（英雄 3/4 视角 / 材质特写 / 废殿远景尺度）+ **分层拆解图**（独立展示核心 / 光学包络 / 流迹 / 粒子）拼合成 **Contact Sheet PNG**；
- 另须检视**侧面、背面、近距离、远距离、室内/室外双光影环境、角色移动转向、中途强打断、双术同屏共存**；
- **串行过审规则**：前一个样本过人工与多模态视觉盲审后，才允许提炼算子并进入下一个样本。

   - **A · 不透明深层月面核心**：高分段球体 + 深度写入 + 多尺度月面纹理、局部吸光与内部明暗；
