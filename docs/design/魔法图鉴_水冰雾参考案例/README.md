# 水冰雾参考案例集（语义魔法宝藏档案）

2026-11-26 · 自原项目迁入的 **21 份核心语义魔法案例**。它们集中体现了“稳定词义 × 语境多义 × 过程承接 × 战后持久改变”的创作方法，现作为 `city-fates-3d` 检验 `SpellDSL` 表达力的**黄金参考样本与压力测试集**。

> **在新 3D 架构中的定位**：
> - 原案例写于 2D 横版时期；在新的 3D 废城框架下，它们摆脱了 2D 纸片束缚（水浪成为真实 3D 立体潮汐、冰闸成为可攀爬可阻挡可碎裂的 3D 刚体、雾幕成为真实遮蔽视线的 3D 体积雾）。
> - 部分偏向繁琐微操或小机关的设计，将在 [02 · 魔法本体论与 DSL 讨论稿](../../02_魔法本体论与DSL讨论稿.md) 中以“大道至简＋四拍仪式感”重新校准；本集**不是**运行时技能白名单。
