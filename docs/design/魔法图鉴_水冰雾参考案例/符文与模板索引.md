## 2. 值得沿着查阅的词义关系

| 符文 | 进入不同职责、连接后的具体区别 |
|---|---|
| 凝固 | [贯刺](条目/M001_凝水贯刺.md)在生成阶段形成冰；[急冻](条目/M006_覆水急冻.md)处理已包覆的水；[霜网](条目/M009_霜狱织网.md)保留已交织的结构；[冰砂](条目/M016_冰砂喷袭.md)凝固分散水滴 |
| 追随 | [悬冰](条目/M002_悬冰连袭.md)保持库存与施法者关系；[霜径](条目/M011_霜径滑行.md)限定生成前端；[重冰](条目/M010_冰河崩落.md)的内部运动跟随指向的悬置位置 |
| 回应 | [伏霜印](条目/M017_伏霜印.md)把载体受压接向待发作用；[感应雾](条目/M015_雾织感应.md)把雾的扰动接向联结反馈 |
| 封存 | [秘壶](条目/M019_盈水秘壶.md)寄存材料，[伏霜印](条目/M017_伏霜印.md)寄存材料与待发作用，[涌泉锚](条目/M020_涌泉锚.md)保存驱动力储备并从另一个实际来源取水 |
| 排斥 | [冰砂](条目/M016_冰砂喷袭.md)推动分散颗粒，[折冲](条目/M013_水幕折冲.md)由气流推动包覆主体，[霜径](条目/M011_霜径滑行.md)作用于冰面与角色的接触关系 |
| 交织 | [护流](条目/M005_旋流卸力环.md)组织围绕角色的错开弧带，[霜网](条目/M009_霜狱织网.md)把水带编入共同受力结构 |
