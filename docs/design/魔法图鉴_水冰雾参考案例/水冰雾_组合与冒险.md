# 水、冰与雾：组合与冒险

2026-11-26 · 围绕核心现象比较打法、成长与相连情境的参考推演。入口见 [案例集索引](README.md)，共同前提见 [共同约定](水冰雾_共同约定.md)。

## 1. 一批法术怎样形成体系

水、冰与雾共享材料、来源和可交接的状态；不同法术分别组织连续流体、集中的贯入、固体结构、弥散与信息，以及载体能力。玩家可以深用其中一种，也可以通过同一对象的改变临场组合。

| 已存在的局面 | 接下来的行动 | 实际改变与选择 |
|---|---|---|
| [护流](条目/M005_旋流卸力环.md)正在偏转箭矢 | 抽出一份水发射[贯刺](条目/M001_凝水贯刺.md) | 攻击消耗现有防护材料；保护弧带当场缩减 |
| [回澜](条目/M004_回澜.md)卷到敌人侧后方 | 保持回卷，或[急冻](条目/M006_覆水急冻.md)其中一段 | 继续推移与释放保留运动的冰段产生不同结果 |
| [水索](条目/M003_引水成索.md)把脚与栏杆连在一起 | 凝固当前水带 | 冰的连接承担束缚，原液态路径成为可破坏的结构 |
| [冰闸](条目/M007_冰闸.md)挡住射线 | 保留、[爆散](条目/M008_裂冰爆散.md)，或[融回](条目/M021_融霜回流.md) | 保有掩体、获得碎块杀伤或回收材料；原通路同时改变 |
| [霜网](条目/M009_霜狱织网.md)已经展开 | 保持液态牵扯、凝固、进一步维持束缚 | 跟随移动、实体承力与额外支撑各有责任 |
| [雾幕](条目/M014_雾幕.md)隔开双方视野 | 借用前缘做[冰砂](条目/M016_冰砂喷袭.md) | 攻击消耗这片雾，打开射线，也可能暴露自己 |
| [悬冰](条目/M002_悬冰连袭.md)已备好 | [滑轨](条目/M011_霜径滑行.md)或[折冲](条目/M013_水幕折冲.md)时逐次出手 | 把形成时间移到此前，抓住移动中短暂的瞄准机会 |
| 载体已建立[伏霜印](条目/M017_伏霜印.md) | 调整载体位置和方向，再投入其他施法 | 准备变成一次条件反击；它仍会被误触、消耗或破坏 |
| [涌泉锚](条目/M020_涌泉锚.md)持续导流 | 去使用其他魔法，或离开处理另一处环境 | 场所承担已确定的工作，来源和储备继续消耗 |

场景提供的是材料、支点、位置、视线、危险与行动机会。这些关系可以继续被新魔法使用，不以固定连招或名称配对触发附加倍率。

## 2. 围绕核心现象形成不同打法

比较场景：废城断桥，下方有积水；对面有持盾敌人，高处走廊有射手，身后有接近者。下列行为依据对应法术表达，不强求每种武器与近战行动都写成纯法师对波：

- **以回卷与牵拉为核心**：从桥下取水，用回澜卷开身后接近者，再抬高位置威胁高台；或用凝固将当前有利局面固定。
- **以交织结构为核心**：先以水带干扰近身敌人并拉向桥柱，再适时收束冻结成连接束缚或临时踏脚。
- **以改变观察与接触距离为核心**：利用雾幕切断射手视线、用雾织感应察觉位置，再贴近以冰砂爆发并顺手撕开视线缺口。
- **以载体准备或直接突破为核心**：在退路预先刻下伏霜印或闸印，正面找破绽直出一记重贯刺击穿防线。

这些方向不规定排他职业。Build 的辨识来自玩家反复驾驭的核心关系、动作习惯、资源分配和愿意承担的风险。

## 3. 完整冒险中的延续

在立体废城探索中，战斗留下的冰桥、积水、破口与载体印记继续影响后续通行、回程与重访，详见 [03 · 世界结构与废城探索](../../03_世界结构与废城探索.md)。

## 4. 成长有多条方向

| 当前核心 | 后期具体目标 | 保留的取舍 |
|---|---|---|
| 简单贯刺 | 短促施放贯穿重甲与一列敌人，射程覆盖长廊；命中先表现贯入与拖拽，再破碎 | 保持简洁、强大的集中攻击；不强制转成储存或场地法术 |
| 回澜 | 驾驭十数米高的厚重怒涛卷过废墟广场，继续回卷、抬升与拍击 | 液态持续作战可以自成核心；规模、局部力与操控有实际投入 |
| 悬冰与霜径 | 在高低建筑间滑行推进，逐次射出重矛 | 出手机会、库存、支撑与留下的材料分别安排 |
| 霜狱织网 | 将废殿石柱、拱门与敌人编入同一巨大结构，凝结从节点蔓延封锁全场 | 大范围协作需要窗口与来源，也会影响自己的通行路径 |
| 冰河崩落 | 在圣堂破顶下唤起遮蔽天光的重冰，压垮重型骑士架势并震碎脆弱构件 | 体量、蓄力风险、撞击与残留一起改变战场 |
| 雾织感应 | 覆盖废城大厅，在浓雾中透出敌人扰动与暗道气流 | 范围、精度与干扰处理分别成长 |
| 载体与导流 | 扩大储量或经营多处水泉节点与封印阵 | 事先准备的战略纵深 |

这些成长围绕尺度、组织深度和词义理解展开（例如理解“回应”后拓展出条件反击与环境感应两类截然不同的构造）。
