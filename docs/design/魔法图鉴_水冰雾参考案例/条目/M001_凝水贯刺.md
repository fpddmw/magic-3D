# M001 · 凝水贯刺

**将水凝成一个集中的冰体，以贯入目标为作用方式。** 短促脱手、持续顶进和组织重矛是同一魔法的三种施法版本。

状态：主体设计提案，待验证。基础符文：水、凝固、凝聚、穿透。组织：瞬发／维持／吟唱。[图鉴](../README.md) · [共同标尺](../水冰雾_共同约定.md)

## 构造与主体

`元素：水 → 生成：凝固 → 形态：凝聚 → 运动：穿透`

默认自生水。借水版本在生成处增加借用，并绑定实际来源；后文组织同一份水，不重复投入组成符文。形态凝聚形成集中、可贯入的整体，穿透规定其对外作用。

这里的凝固、凝聚和穿透共同指向集中贯入的冰体。维持引用已经成立的贯入关系，使它在抵抗中继续施压；吟唱持续组织同一支矛。三者保留同一核心现象，但出手机会、控制与受阻后的行为不同。改变凝聚或穿透的作用范围时，则须重新判断整个魔法，不能只沿用这三种版本的名字。

## 三个版本的实际动作

| 版本 | 动作、控制与结束 | 前期标尺 |
|---|---|---|
| 瞬发贯刺 | 指向后约0.3秒成形脱手，之后可移动或换法术；飞行中不再转向 | 一份水，自生10法力，约12米有效射程 |
| 维持贯刺，别名「贯冰」 | 在施放方向持续贯入；尖端抵住盾面后继续施压，调整指向使整支矛缓慢转动 | 起手约8法力，受力推进时每秒4，主要距离约4米 |
| 吟唱贯刺 | 第一段冰体很快出现并实际占位；继续组织使其增厚、延长，松开时射出当前成果 | 完整组织约2秒，三份水，自生30法力 |

普通贯刺正中普通轻装敌人的躯干足以造成致命伤，能击穿薄木盾，厚重盾牌可以挡下。贯冰能持续顶退持盾者、逼开架势；敌人侧闪、斩断矛身或迫使玩家转身都能解除压力。吟唱重矛能够一击打破普通重盾架势，对重甲造成可靠伤害。

吟唱提前释放交出较小矛体；失衡打断时，尚未发射的冰体失去支撑、落下。贯冰停止支撑后不再追加推进；冰体及既有破坏保留自然后果。矛身折断后的推进与操控细节仍需核对。

## 组合、冒险与成长

贯冰能以同一股有方向的力顶开受阻的门或撑住合拢结构。冰矛可以从[护流](M005_旋流卸力环.md)分出的水形成，原保护随材料减少；扎在盾上的冰可被[裂冰](M008_裂冰爆散.md)处理，效果取决于实际位置与碎块运动。

[悬冰连袭](M002_悬冰连袭.md)将成形与逐次发射进一步拆开，另记为独立组织。[伏霜印](M017_伏霜印.md)把待发贯刺建立为载体能力。

后期保留简单贯刺路线：短促施放贯穿重甲与一列敌人，射程覆盖长廊；先呈现贯入与拖拽，再破碎。三个版本继续分别强化抓机会、持续压迫与集中突破，不预设最后都转成大范围吟唱。

待核对：各版本的完整费用口径、转向范围、破甲阈值及与连射的实际收益，尚无操作和伤害实测。
