# M012 · 激流冲浪

**让脚下的短浪沿地面和水面连续前进，驾着水跨过街道与坡面。**

状态：主体设计提案，待验证。基础符文：水、借用、追随、铺展、排斥。组织：维持。[图鉴](../README.md)

## 构造与动作

`水＋借用；维系：追随脚下实际地面或水面；形态：铺展；运动：排斥`

两份水构成沿表面前进的短浪。起手约6法力，维持每秒2；约半秒加速到普通奔跑两倍左右。转向和刹停经历明显的水流转折，而非瞬间改写速度。

当前版本把水浪依附于实际表面。遇到长缺口，浪沿地形落下；它没有凭空生成悬轨的能力。停止维持后不继续主动追随或推进，水与角色承接当前运动。

## 用法与比较

可沿街道、坡面、水道连续移动，也能携带能够站稳的轻物，适于长距离穿行与运输。与[霜径](M011_霜径滑行.md)相比，它主要循环使用主体水量、少留固体障碍；水的损失仍需真实补充，维持不是自动无限回水。

沿已成立的行进关系移动时，可以在允许的动作窗口发射[悬冰](M002_悬冰连袭.md)，借地形改变出手位置。[水索](M003_引水成索.md)能处理搬移与局部牵扯；若冲浪转向与水索都需要持续精细操控，必须交接当前焦点。冲浪在失去主动指向后继续何种既定行进、如何停止，需要具体输入设计，不默认自主避障。

表现需要让加速、承载和水流转折清楚，角色确实随浪移动。更大浪体、载重与路线尺度可进一步展开，后期参数尚未展开。

待核对：表面跟随、坡面与边缘行为、具体刹停距离、载重、水损失及碰撞力量。
