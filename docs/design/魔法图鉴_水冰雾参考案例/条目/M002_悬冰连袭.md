# M002 · 悬冰连袭

**先在肩后备好几支冰矛，在跳跃和滑行中逐支射出。** 成形时间提前支付，出手时抓住短暂射线。

状态：主体设计提案，待验证。基础符文：水、凝固、凝聚、环绕、追随、穿透。组织：维持＋有限发射支路。[图鉴](../README.md)

## 构造与操作

`水 → 凝固；形态：凝聚＋环绕；维系：追随施法者；发射支路：穿透`

前期三支较细冰矛合计使用一份水，分布在角色周围并随其移动。环绕解释分布，追随解释持续关系；它们不自动绕圈飞行或寻找敌人。

每次攻击输入射出一支，各次发射按当时的指向确定方向；连续输入可快速齐射。发射之后脱离追随关系，按已确定的贯入方向运行。库存用完结束，停止维持时剩余冰矛落下。

## 前期作用与投入

建立约10法力，维持每秒0.5，每次发射再消耗2。单支伤害与穿甲低于普通[贯刺](M001_凝水贯刺.md)，三支齐射可迅速击倒普通敌人，但不具备一支吟唱重矛的集中突破力。

它提供提前准备与分次出手的机会，不自动补充库存。取得新水或改变核心不会补回已发射的一支。

## 组合与表现

[霜径](M011_霜径滑行.md)、[折冲](M013_水幕折冲.md)和普通跳跃使射击位置不断改变。玩家也能留下一支处理突然接近者，或从[雾](M014_雾幕.md)出现的缺口出手。沿高低路线探索时，同样能保留现成攻击处理突发威胁，不另附赠取物或寻敌能力。

画面要明确每支矛的库存、待发与离开。后期可以发展连续移动中的多次射击，或把材料与组织投入少量重矛；两条方向都要重新比较库存、单发力量与维持负担。

待核对：建立动作时长、具体射程、周围冰矛遇到狭窄地形时的避让或碰撞，以及多支齐射的读图与输入节奏。当前不把这些缺项补成无碰撞穿墙跟随。
