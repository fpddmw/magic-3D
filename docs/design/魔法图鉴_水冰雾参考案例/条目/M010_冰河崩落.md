# M010 · 冰河崩落

**把持续投入组织成悬置的重冰，调整落点后向下贯压。**

状态：主体设计提案，待验证。基础符文：水、凝固、汇聚、凝聚、追随、穿透、爆发。组织：吟唱→释放。借水版本增补：借用。[图鉴](../README.md)

## 构造与已经发生的作用

`水 → 凝固 → 积蓄：汇聚；形态：凝聚`

`内部运动：追随玩家指向的悬置位置；外放运动：穿透＋爆发`

前期约两秒半、六份水，在指定位置上方组织一块约一人高的重冰，完整自生投入约44法力。形成中的冰就占据空间并阻挡部分射线，玩家缓慢移动指向可以调整它的位置。

主动释放后，重冰向下贯压，能击倒重装敌人、重创落点附近的普通敌人，并按实际材料、剩余截面与支撑破坏接触到的薄楼板或木结构。伤害、失衡和位移分别结算。敌人看得见其形成，会尝试离开落点或打断施法。

## 空间、结束与取舍

低矮室内限制体量形成；落点必须真实可达。释放后，破碎与残留由撞击决定。未完全破碎的冰会堵路、成为掩体，也会挡住玩家下一次攻击。

前期接近半管法力的集中投入，换取能翻转正面压力的一击。可在[护流](M005_旋流卸力环.md)保护或[印记](M017_伏霜印.md)承担局部反击时组织；不是每次遭遇都必须等待这项法术。

后期目标是数层楼高的重冰，压垮重型敌人架势，并按真实接触与承重改变建筑结构。体量、遮蔽、下落、撞击和残留共同表现力量；坍塌同时改变射线、落脚和敌人路线。后期来源和投入须另行设计，六份前期水量不直接沿用。
