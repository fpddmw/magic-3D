# M009 · 霜狱织网

**一边织出能牵扯目标的水网，一边改变其展开；主动收束时，把当前组织凝成冰。**

状态：主体设计提案，待验证。基础符文：水、借用、汇聚、延展、交织、牵引、凝固、束缚。组织：吟唱→凝固／维持束缚。[图鉴](../README.md)

## 构造与时序

`水＋借用 → 积蓄：汇聚 → 形态：延展＋交织 → 运动：牵引`

`主动收束 → 凝固当前结构 → 维系：束缚`

凝固在此限定主动收束时对当前网的改变，绑定明确的释放输入；短式的箭头同时包含这一实际时序。交织、延展和牵引共同决定液态阶段的组织，束缚限定其后持续施加的关系。后段承接同一张网，不能换成一张与当前接触无关的标准冰网。玩家控制网的前沿与展开方向，不逐条画网格。第一条水带约半秒就能接触、牵扯敌人，其他水带随后与它交错；前沿可以继续向前或抬向平台。

## 前期力量、控制与结束

三份水，约两秒组织出四米宽、两三米高的网。完整塑造与凝固约18法力，自生版本另加12；凝固后继续强化束缚，每秒2。

提前收束会得到一两条绊人、架住缺口的冰带；完整展开后可困住几个普通敌人。改变水带走向再收束，可以把持武器的手与邻近结构连接。大型敌人能挣断较细部分，一处连接被破坏会改变其他部分受力。

织网时前沿占用直接操控焦点，切换至另一项精细操控需按术式收束、转交或中止，具体交接输入待定。失衡打断时，尚未凝固的水落下，不自动补完冻结。主动收束把当前材料、轮廓和有效接触转为冰网，依实体支撑保留；停止附加束缚后，固体结构仍有自然约束，但不继续获得该维系作用的强化。支点破坏同时影响承重、目标约束、通路与画面。

## 接法改变后的分岔

去掉收束处凝固，将液态网交给维持，得到持续牵扯的水网版本，能随目标移动继续缠绕，持续承担供能与受力。该版本尚未单独确定完整消耗。

把凝固放在织网之前，则组织已经坚硬的冰条，适合架设、分隔与封锁；它难以像液态水带那样贴着挣扎者绕进狭处。这些接法说明不同先后产生的实际差别，不当作已完整设计的额外条目。

## 冒险与成长

网可以成为支点之间的通路或临时分隔，也能被[裂冰](M008_裂冰爆散.md)破坏、被[回流](M021_融霜回流.md)回收。后期目标是把建筑支点、平台和空中路线编入同一结构，凝固从交错节点蔓延，分割大群敌人与高低空间。

待核对：支点取得、接触与束缚对象的关系、无实体支撑时如何落下、输入控制，以及液态分支的完整规格。
