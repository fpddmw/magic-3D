# M016 · 冰砂喷袭

**分散水滴在推出时凝成快速冰砂，近处集中、远处散开。**

状态：主体设计提案，待验证。基础符文：水、气、弥散、凝固、铺展、排斥。组织：瞬发。借雾版本增补：借用。[图鉴](../README.md)

## 构造与作用

`水＋气 → 弥散 → 凝固分散水滴；形态：铺展；运动：排斥`

前期约10法力，向三四米内喷出一扇快速冰砂。贴近时大部分集中命中，足以击倒普通轻装敌人；散开后可压制几名接近者，对重盾正面较弱。

推送完成后，冰砂继续碰撞、落下或融化，不保持追踪或凭空再次攻击。具体材料量、颗粒和主要可见碎块的关系尚未确定。

## 现有雾的交接

借用现有[雾幕](M014_雾幕.md)的版本，冻结并推出实际取用的那部分雾。攻击在雾幕中撕开一个可见缺口，可能暴露玩家，也能为[贯刺](M001_凝水贯刺.md)打开射线。

它可与[雾织感应](M015_雾织感应.md)、[水幕折冲](M013_水幕折冲.md)形成判断接近方向、短冲改变距离、近处爆发的打法。冰砂的范围与贯刺的集中贯入形成实际替代。

本例的主要用途是短距杀伤与压制，非战斗作用仍沿真实颗粒冲击与材料变化判断，没有另外附赠开锁、探查等能力。后期粒度、覆盖和穿透的具体发展尚未展开。

待核对：水量、喷射角、近远伤害变化、粒子画面与真实命中的对应，以及借雾时可取用范围。
