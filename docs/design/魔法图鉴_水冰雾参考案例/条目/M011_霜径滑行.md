# M011 · 霜径滑行

**踩着自己延伸的窄冰轨飞掠，把一部分轨迹真实地留在世界中。**

状态：主体设计提案，待验证。基础符文：水、追随、铺展、延展、凝固、排斥。组织：维持。[图鉴](../README.md)

## 构造与操作

`水；生成前端：追随脚下；形态：铺展＋延展 → 凝固`

`运动：排斥作用于冰面与施法者的接触关系`

另有设计目标：维持当前轨段的承托。现有短式尚未明确悬空支撑由什么关系成立，不能仅因选择维持模板就授予悬浮。以下跨空、留轨和负荷均按待补齐该关系的构思描述。

玩家按行进方向连续形成两道窄轨，冰面向前顶送角色。可以沿缓坡升降、跨过断口，也可以在空中接续施放；新的轨段继续支付材料和支撑成本。具体方向输入、曲率和坡度尚未定型。

## 前期尺度与投入

一次预备两份水，可形成约8米轨迹；起动约6法力，每延伸4米再消耗约6，需要托住悬空轨段时另付持续消耗。悬空支撑的语义与具体每秒投入均待确定。

身后约4米当前轨段可由法术托住，超出范围后依地形支撑或失去支撑而落下。停止后角色保留当前移动趋势，需要通过动作、地形或其他魔法减速；停止悬空支撑会产生真实跌落。

## 战斗、通路与成长

滑行中可在允许的动作窗口发射已备好的[悬冰](M002_悬冰连袭.md)，这是有限即时指令；同时精细塑造轨道与操控另一现象则需交接焦点。角色动作控制读取真实轨面、推进和支撑。留下的轨道能被踩踏、阻挡和[击碎](M008_裂冰爆散.md)；让追兵踏上即将失去支撑的轨段，是待补齐支撑关系后可验证的机会。

跨越路线与交战使用同一能力。保留有支撑的冰轨可以帮助回程，[回流](M021_融霜回流.md)撤去轨道时也会撤去承重。与[冲浪](M012_激流冲浪.md)相比，它不断将材料留成固体；主动创造悬空路径的目标仍取决于尚未补齐的支撑语义，引擎具备支撑关系并不自动使该构筑成立。

后期可延长可托住的轨段、增强连续滑行与出手能力；更宽、更稳定的通路属于需要另核材料和负荷的方向。画面要读出当前支撑、留下的冰与正在掉落的轨段。

待核对：支撑关系的完整语义、速度、制动、方向输入、轨道体积、他人负荷及悬空消耗。
