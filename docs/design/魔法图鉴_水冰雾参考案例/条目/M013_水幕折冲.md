# M013 · 水幕折冲

**水衣裹住身体，气流推动一次短冲，尾部散成阻隔追击视线的雾。**

状态：主体设计提案，待验证。基础符文：水、气、包覆、排斥、弥散。组织：瞬发。[图鉴](../README.md)

## 构造与完整动作

`水与气 → 包覆施法者；气的排斥推动包覆主体 → 尾部水衣弥散`

一次约9法力，在约四分之一秒内沿所指方向冲出四米，身后留下两米左右的浓雾尾迹。尾迹来自本次水衣，随后逐渐散开，实际水量与消散时间尚未定值。

身体沿真实路径移动。重物会阻挡冲刺，正面撞上轻敌人可以使其失衡。用来从攻击路径中脱出、跨越短缺口，或从平台边缘切入近身；没有因包覆雾气自动获得身体雾化、穿墙或无敌。

## 组合与性格

[雾织感应](M015_雾织感应.md)提供接近方向的信息，折冲改变接触位置，再用[冰砂](M016_冰砂喷袭.md)近距爆发，或在短暂射线中发出[悬冰](M002_悬冰连袭.md)。尾迹同时影响双方视线，不能自动复制角色或转移敌人的全部判断。

通行与战斗都依靠一次突然的实际位移；它与需要持续经营的[滑行](M011_霜径滑行.md)、[冲浪](M012_激流冲浪.md)形成不同节奏。

画面要看得清出发方向、身体通过的路径、阻挡与尾雾形成，速度感不掩盖真实碰撞。

待核对：水量、起手与结束动作、空中速度承接、撞击代价、尾雾持续及后期发展。当前没有单独设计本体化雾的另一个魔法。
