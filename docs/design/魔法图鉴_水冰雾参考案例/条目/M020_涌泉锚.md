# M020 · 涌泉锚

**将一项确定的导流工作交给有来源、有储备的场所，腾出施法者的动作与注意。**

状态：主体设计提案，待验证。基础符文：水、借用、以太、联结、封存、牵引、延展、铺展、排斥。组织：仪式／附魔。[图鉴](../README.md)

## 构造与责任

`水＋借用；承载：联结指定水源，并以以太封存预付力量`

`外支：牵引水源 → 延展、铺展 → 排斥推出定向水流`

整体构造让场所成为有来源、有驱动的导流节点。联结在此维系水源关系，与感应雾中传回扰动的联结含义相通、实际作用不同；借用针对水，封存的预付力量与实际来水分别处理。出水方向在部署时确定，载体按已经建立的导流能力持续工作，施法者可以离开使用其他魔法。

## 前期标尺与结束

约三秒部署，建立约10法力，再例如投入20法力储备。战斗强度推流约每秒消耗2，形成约五米长流路，推动普通接近者离开原路线并在出口附近积水。在来源足够且负荷符合该标尺时，20储备约能支持10秒该强度推流。

水源断开或储备耗尽，驱动停止；已流到场地上的水继续按地形流动。移动或破坏载体涉及来源联系和已建立方向，不自动转成追随玩家的泉源。具体移动、启停和重设方式仍待设计。

完成后由场所和已绑定来源承担运行，换核心不重释这项能力。离区时按已知来源、流路、容量和储备推进，遇到堵塞或结构变化重新核对；具体简化算法待验证。保存保留载体、库存和材料结果，关闭游戏暂停其工作时间。

## 组合、冒险与成长

它能供给[回澜](M004_回澜.md)的材料，经营一条持续流路，或将积水引出低处、建立运输条件。排水与运输的负荷、输出量尚未给出，不能把战斗时长直接套为所有用途。

后期可以深化工作时间与储备，或通过明确联结建立多个出水位置；完整多点术式尚未展开。玩家的收益来自场所代行工作，取舍是准备、固定位置、来源、储备与保护载体。

待核对：每秒水量、取源距离、扬程与阻挡、载体损坏的结局、启停控制和储备反馈。来源丰富不代表驱动力无限。
