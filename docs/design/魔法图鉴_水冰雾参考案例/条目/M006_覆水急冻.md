# M006 · 覆水急冻

**先认清水实际覆盖和连接了哪里，再把这层水凝固。**

状态：主体设计提案，待验证。基础符文：水、借用、包覆、凝固。组织：瞬发。铺展版本以铺展替换包覆；整体急冻版本省去这两种空间限定。[图鉴](../README.md)

## 语义与施放

`水＋借用 → 形态：包覆 → 凝固作用于已经包覆的水`

前期在约6米内处理可见、可接触的水，一次最多三份，按水量消耗约4–8法力。目标范围由实际水的覆盖和连接确定；水量不足时仍是薄层，不自动长成厚冰。

| 已有条件 | 冻结后的实际结果 |
|---|---|
| 鞋底与地面的水相连 | 脚与地面形成可挣断、拔出或打碎的连接 |
| 身上只有薄水膜 | 薄冰壳短暂妨碍关节动作，容易碎裂 |
| 水带绕住腿并连到栏杆 | 形成明显更强的固体连接 |


包覆版本处理水与所覆对象的表面关系。用铺展替换包覆时，冻结一片相连水面，可形成滑面、封住漏水口或留下受支撑的表面。若要冻结独立水团或一段浪体，则使用省去包覆／铺展限定的整体急冻构造，让凝固直接作用于所借用的当前水体；其选取与费用仍待细化。这些作为同一凝固现象的构造变体记录，不能在施放时无说明地跨越已保存的作用范围。

## 交接与留存

按对应构造范围，[水索](M003_引水成索.md)的包覆连接或独立水带、[回澜](M004_回澜.md)的局部水体可以成为凝固对象。冻结飞来的水团也保留其运动，不能仅凭相变使它停在空中。它们不会因相变得到另一份材料。已经形成的冰依温度、支撑与损伤继续存在，没有统一附赠的禁锢时长或自动悬空。

与[裂冰](M008_裂冰爆散.md)连用时，破坏的仍是实际冰壳或连接；[回流](M021_融霜回流.md)可以将选中残冰重新熔为材料。

待核对：覆盖识别与施放反馈、冻结范围及质量的对应关系、在热环境中形成与融化的尺度。后期更大规模或更精细凝固尚未逐项定参数。
