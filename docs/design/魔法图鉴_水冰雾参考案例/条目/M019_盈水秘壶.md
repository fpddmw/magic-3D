# M019 · 盈水秘壶

**让随身器物收纳、保存并交出有限的水，把此前的准备带进下一处环境。**

状态：主体设计提案，待验证。基础符文：水、借用、以太、吸纳、封存、释放。组织：仪式／附魔。[图鉴](../README.md)

## 构造与使用

`水＋借用；承载：以太、吸纳、封存；外支：释放`

吸纳、封存与释放在此共同使器物获得收纳和交出水的能力。以太参与寄存关系，借用明确被取用的水；它们需要作为整个器物能力理解。具体寄存边界按[共同提案](../水冰雾_共同约定.md)继续设计。前期保存六份水，壶口朝向可达来源收纳；可把水交给已连接的法术，也可直接倒出。收纳与释放付出少量法力，具体费用尚未确定，没有附赠高压喷射。

封存作为载体已获得的性质存在，核心可带走，器物继续持有有限寄存内容；破损会使内容漏失。建立时间、初始耗材、维护和重量关系尚未定稿。

## 资源选择与冒险

六份水能供应六发普通[贯刺](M001_凝水贯刺.md)，或一面完整[冰闸](M007_冰闸.md)；启动四份水的[回澜](M004_回澜.md)后只剩两份。容量分配实际改变之后能做什么。

它可携带水道收来的水、接收[融霜回流](M021_融霜回流.md)的材料，支持进入干燥高层，也可按需要倒出。壶内储存的是材料；塑造、发射、维持仍另付法力。

多种配置都可以使用，依赖现场来源或自生魔法的玩家也有自己的路线，秘壶不被预定为所有流派的必经中期阶段。

## 成长与缺口

更大储量、便捷交接或不同载体是后续方向，具体参数未展开。表现应读出剩余储量、收纳、交出与破损泄失，避免小体积壶的外观造成材料是否存在的误解。

待核对：寄存容量与物理体积、携带重量的关系，实际来源距离、装填速度、各阶段费用，以及其他法术如何调用已建立的壶。
