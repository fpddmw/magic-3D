# M008 · 裂冰爆散

**裂开实际存在的冰体，把主要碎块沿选定方向喷出。** 一次攻击也会撤掉原有结构。

状态：主体设计提案，待验证。基础符文：水、借用、分离、排斥、爆发。组织：瞬发。简称：裂冰。[图鉴](../README.md)

## 构造与动作

`水＋借用已有冰 → 分离其结构 → 运动：排斥；爆发限定这次外放`

冰是现场已有水的固态内容，本次不重新制造或凝固它。前期作用距离约6米；玩家指向冰体及爆散方向，裂纹从选中位置展开，主要碎块随后形成约3米的危险扇区。

小冰体约消耗6法力，整面门宽冰闸约18。近距主碎块足以杀伤轻装敌人，较远处主要造成打断与较轻伤害。大块坚硬冰、冰砂和已有裂损的冰应具有不同的运动与破坏结果。

## 结构与杀伤同时变化

- 爆散敌人身侧的[冰闸](M007_冰闸.md)，产生侧向攻击，同时打开原先堵住的路。
- 裂开扎在盾上的[贯刺](M001_凝水贯刺.md)，碎块可以作用于暴露位置，伤害依据真实接触。
- 破坏[冰轨](M011_霜径滑行.md)或冰梁，会先改变承重，再产生碎块攻击；跌落与碎片分别造成后果。
- 碎冰仍是碎冰，回到可流动水源要经过[融化回收](M021_融霜回流.md)等过程。

清理封路结构、改变通过方向也使用同一项破坏作用，场地中的自身、同伴与物品承接相应危险。它没有自动施加在生物内部的额外伤害，也不按“被冻结”标签固定增伤。

待核对：可处理的连通冰范围、裂纹和碎块的质量分配、方向控制、近远伤害，以及破坏整张网等后期规模。尚未给出通用爆炸半径或多段倍率。
