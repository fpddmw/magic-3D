# M014 · 雾幕

**以弥散的水滴占据一片空间，改变双方看见彼此的条件。**

状态：主体设计提案，待验证。基础符文：水、气、弥散、铺展。组织：瞬发／维持。随行版本增补：追随。[图鉴](../README.md)

## 构造与版本

`水＋气 → 生成：弥散 → 形态：铺展`

弥散限定水与气共同形成的细滴分布，铺展把这种分布组织到空间中；整体现象改变可见性。前期使用少量水、约6法力，在八米以内形成直径约四米的浓雾。

瞬发版一次组织雾团，之后随风、地形和混合渐散。在无明显气流的室内，最初数秒提供可靠遮挡。维持版持续保持指定区域的浓度，基准每秒约1法力，明显吹散时需要额外补充。随行雾幕在维系处加入追随，保持跟随角色的分布关系。

## 世界回应与结束

敌人失去视觉后，依据最后位置、声音和自身行为继续行动。玩家也失去清楚视野，可以撤离、分割敌群、接近危险，但会妨碍自己的瞄准。停止维持后，现有雾按环境继续散开，不整片瞬间删除。

雾由真实的分散水滴形成，覆盖体积不能直接折算为同体积的厚冰。浓度、流动和可见性共同进入世界状态，画面与敌人视线使用同一遮蔽依据。可为玩家自身保留操作轮廓，不能因此显示本应看不见的敌人。抽取雾水同时减少材料与遮蔽。

## 组合、冒险与成长

[雾织感应](M015_雾织感应.md)加入明确的奥术联结与反馈，另记为独立能力。[冰砂喷袭](M016_冰砂喷袭.md)可消耗现有雾的一部分攻击，从而撕开视线缺口。[折冲](M013_水幕折冲.md)的尾雾是其水衣的结果，不等于免费建立一片完整雾幕。

普通雾幕以较简单的组织和投入改变视线，可以长期保留价值；不要求最终全部升级为感知雾。更大范围与更强保持能力需要另核材料、气流和持续费用。

待核对：少量水的具体量、雾浓度与视距、风与遮挡、维持补充，以及玩家看见自身和近处物体的可读性。
