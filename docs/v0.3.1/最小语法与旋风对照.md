# v0.3.1 最小语法 · 有限柱域中的持续力

以下为旋风基线交付时的范围。此后固定/实时瞄点已有[局部 Jolt 记录](aim_pair_jolt.json)，其余语言设计进展见[当前审阅稿](../magic_language/README.md)。

一份配方能否在同一空间内同时表达向内、旋转、向上，并通过只改一个数改变相应的运动？这次试验使用手写配方检验 DSL 的表达力。[20 项现象矩阵](现象表达矩阵.md)

## 机器契约的增量

| 位置 | 写法与约束 |
|---|---|
| `Subjects[].spatial.geometry` | `{"shape":"column","radius_m":3,"height_m":4}`。四载体中的 Region，原点为底面中心，轴为世界 +Y。半径和高度均在 (0,30] 米。|
| `Spatial.distribution` | 柱域可用 `{"radial":"bell","axial":"uniform"}`。径向允许 uniform、linear_falloff、bell；高度允许 uniform、linear_falloff。两个轮廓相乘。 |
| `Processes.nodes[].active[]` | 既有 Drive 类的持续能力 `sustain_force`，目标须为具压力接口的有限柱域。参数 `field_vector` 有且只有 radial、tangential、axial 三个有符号分量，欧氏长度大于零且不超过 1。旧单轴配方保持原有解释。 |

向外的水平单位向量为 R，切向单位向量为世界上轴 × R，轴向单位向量为世界 +Y。正 X 处的正切向指向负 Z。轴心的水平两分量贡献为零。权重相对于支付所得的固定满额力；删除或反转一个分量时，其他分量保持原值，未用份额留空。分布在柱外为零；柱内以 u=水平距离/半径、v=相对高度/柱高采样。linear_falloff 为 1−u 或 1−v，bell 为 (1−u²)²。压力通道读取场景遮挡，空气主体仍需现场空气。

同一时刻，标尺给出有限总力 F。有效对象 i 获得的力为 F × wᵢ / max(1, Σw) × (radial·Rᵢ + tangential·Tᵢ + axial·Y)。每个物体依其质量响应；总交付向量模长之和有上限，空域、遮挡与零分量不会产生额外交付。报价随半径、高度和规模单调变化，三组相同几何、时限与操作使用同一报价。物理账记录每步受检目标上限；空 Expression 的渲染账为零。

## 同一配方的三个结果

场景中有七个质量为 1 kg 的探针。东、西两点从离轴 1.5 m、高 1 m 处静止出发。第三点位于轴心，另四点分别位于柱侧以外、顶面以上、底面以下，以及柱内受遮挡处。施法者在 1.0 s 松手，推演至 1.5 s。每一步都按对象当前位置重算受力，步长最多 1/32 s，遇到释放、打断或供给耗尽即在该时刻结算。下表是松手时东侧探针的世界速度，单位为 m/s。

| 对照 | 相对基础配方的唯一改动 | X | Y（向上） | Z | 所有对象累计获得的冲量模长之和（N·s） |
|---|---|---:|---:|---:|---:|
| 旋风 | 基础分量 (−0.48, +0.64, +0.60) | −0.5793 | +0.6548 | −0.6497 | 3.2731 |
| 去掉上升 | axial 从 +0.60 改为 0 | −0.5793 | 0 | −0.6497 | 1.7462 |
| 反转旋向 | tangential 从 +0.64 改为 −0.64 | −0.5793 | +0.6548 | +0.6497 | 3.2731 |

三组各支付 5.46 魔力建立、5.46 魔力维持一秒，共 10.92。物理账给出持续力上限 4 N，一秒的共享冲量上限是 4 N·s。报价中的 `total_impulse_budget` 专指预蓄后一次释放的冲量，本配方的该项为零。渲染账为零。同一场景下去掉上升保留水平轨迹，因为本例的轴向分布均匀，探针在施力时段都留在柱高以内。若离开柱域或改用高度衰减，位置变化会反馈到后续各向受力。

西侧探针的水平运动与东侧对称，轴心只受轴向力，其他四点均未获冲量。松手后各探针保留速度，直到 1.5 s 均无新增交付或扣费。自动对照另检查双倍质量的首步加速度、径向与高度衰减的乘积、缺空气、提前打断和供给耗尽。法坛用手写候选核验上升锚点，删除上升分量或改为向下均会拒绝。该离线场景只推演质点受力与惯性，遮挡由现场观测给定。游戏能力清单继续使用已经接入引擎的 0.3.0 配方。

### 复现

在仓库根目录执行下列命令。第一条读取唯一的基础配方和现场，打印三个时刻的七组探针数据。第二条运行活动测试集，其中包含已提交观测的逐项比对。

```sh
uv run --isolated --with-requirements tools/magic_dsl_v0_3/requirements.txt python -m tools.magic_dsl_v0_3.field_comparison
uv run --isolated --with-requirements tools/magic_dsl_v0_3/requirements.txt python -m unittest discover -s tests -v
```

输入与输出可分别检查。[基础配方](../../game/data/magic_v0_3/studies/column_field/recipe.json) · [共同现场](../../game/data/magic_v0_3/studies/column_field/scene.json) · [逐时观测](column_field_observations.json) · [对照断言](../../tests/test_column_field.py) · [v0.3.1 Schema](../../game/data/magic_v0_3/magic_dsl_v0_3_1.schema.json)

## 待设计的增量

参考旋风的逐渐成形、柱身收窄、尘屑随流、实体碰撞和体积演出仍是设计。自由符文组合产出这类配方的稳定性及玩家预期吻合度仍需独立实验。

后续共用参照与有限阵列应能分别捕获、跟随并独立退场。动态结构要绑定材料量、前沿、碰撞与支点。寄托、外界冲量和材料转移各有独立来源与单位。艺术轨道需要明确空间绑定、驱动量、可读轮廓和余韵。分海先验证离散水段守恒，分段桥验断点与支撑，复合移动核心验各通道分别退出。
