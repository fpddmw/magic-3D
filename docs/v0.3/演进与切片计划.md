## 二、混合美术生产管线与核心纪律

1. **真实素材先于引擎代码**：采用 **「ImageGen（概念与 2D 纹理）→ 离线通道加工 → Blender Python 3D 载体 → Godot 4.5 封装」** 的混合生产管线（见 [资产总览](../art_assets/README.md)）。
2. **禁止代码 Agent 凭空造美术**：在负责人确认门禁 G1（概念与 2D 纹理）和 G2（无辉光灰模剪影）之前，禁止用 Godot 运行时几何拼装或简单条带 Shader 提前凑特效。
3. **三档尺度授权**：明确区分 **`T1 隐微/小术`**、**`T2 常规战技`**、**`T3 宏大仪轨/天象`**；审美克制在色相与噪点，不许以「克制」为由阉割大尺度魔法的物理力学与空间压迫感。
4. **实验先跑通，架构后升格**：在实验 A–C 验证完成前，接口保持 [薄契约](../art_assets/thin_contract.md) 形态，严禁提前编写大而全通用演出框架。
5. **诚实区分证据口径**：每份文档与记录须明确区分「设计候选」「纸面映射」「待验证合同」「局部后端」「实机观测」「人工审美评议」「模型首答实验」「玩家实测」。
