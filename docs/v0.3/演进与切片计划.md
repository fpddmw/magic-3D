# Magic DSL 演进与切片计划

2026-11-27。当前交付是**完整语言设计的集中审阅稿**。设计问题是玩家编排的现象怎样成立、受控、互相作用、退场后继续影响世界，以及这些差异怎样通过视听读出来。作者先在共同规则上写配方、换条件、手推世界后果。旧切片留下来的证据可以反驳一条新规定，单个切片能执行的字段不能决定语言的上限。[本轮全部审阅材料](../magic_language/README.md)

| 顺序 | 工作和责任 | 何时进入下一步 |
|---|---|---|
| 1 · 语言设计 | 设计者统一存在与参照、过程与责任、舞台与解析。用经典、原创、同符文改锚和跨术复用的手写配方寻找表达缺口。 | 四份规格与样例可互查。集中审阅每个反例、缺口和取舍，确定进入机器契约的范围。 |
| 2 · 表达验证与冻结 | 工程侧将获审语义收口为同一版本的 Schema、注册表、计费、准入、读解与轻量调度器。运行同配方反事实。再在冻结能力子集上做高能力模型的首答与改锚实验。 | 经典结构可表达，原创构筑可复用，合法输入具唯一语义，非法/缺能力可定位。模型生成与人工设计分别记来源，确认后冻结。 |
| 3 · 通用能力施工 | 同一立体废墟庭院按 A 空间驾驭、B 结构材料、C 跨术与导演接入通用 WorldLaw 和 ArtKit。 | 正常游戏入口交付，每模块验一组核心因果差异与未经专门适配的新构筑，另行实机审美评议。 |
| 4 · 产品验收 | 以完整负载测 M6 Metal 与中端独显 Vulkan；在法坛做玩家盲测；用经许可、可回放的数据开展 SFT / RLVR。 | 同配置三批 P95 各 ≤16.67 ms，显存峰值 ≤2.5 GB。分别报告样本量、未准入、首答命中、修正及改锚。80%–90% 是事前预期命中目标。 |

## 旧 P1–P5 如何进入语言设计

| 旧条目 | 本轮必须回答的设计问题 | 审阅位置 |
|---|---|---|
| P1 共享参照与阵列 | 父体转向、成员丢失、派发与脱离时，谁还跟随谁？ | [A](../magic_language/A-space.md)、[B](../magic_language/B-world.md) |
| P2 动态空间与结构 | 前沿遇阻、支点断裂、材料分份以后，哪部分可见、可踩、可再次取得？ | [A](../magic_language/A-space.md)、[D](../magic_language/D-resolution.md) |
| P3 复合力 | 关闭上升、反转旋向或换中心，哪些分量和预算仍然相同？ | [B](../magic_language/B-world.md)、[经典构筑](../magic_language/classic.md) |
| P4 驾驭、储备与干涉 | 玩家松手、器物接责、多个实例争用同一份材料，结果如何确定？ | [B](../magic_language/B-world.md)、[D](../magic_language/D-resolution.md)、[原创构筑](../magic_language/original.md) |
| P5 舞台 | 同一动作有哪些不同速度的轨道，哪些边界和回声由真实事件驱动？ | [C](../magic_language/C-stage.md) |

## 已有证据及后续实机题目

- 旋风的径向、切向、轴向以及固定/实时瞄点已有局部离线数据。固定/实时瞄点也有两个 Jolt 探针的旧观测。这些覆盖有限柱域与对应配置。[旋风数据](../v0.3.1/column_field_observations.json) · [瞄点离线](../v0.3.1/aim_field_offline.json) · [瞄点 Jolt](../v0.3.1/aim_pair_jolt.json)
- Gate 0 已存三次独立启动的 M6 1080p Metal 基线，P95 分别为 18.087、16.189、16.485 ms。两批达到阈值，慢帧归因与优化复测尚缺。产品性能安排在阶段四。[原始记录](evidence/gate0_baseline.json)
- A 以同一份风场分别固定、追随瞄点，观察碎石、角色及受力实体。B 用两次独立施法：第一术借取质量 m 的水，冻结、退出并交还世界。第二术重查现场，在同实体/RID 上融化并回收 m。移走冰段则回收为零，水源、冰段、容器和被移走的一份总量守恒。C 将光学、信息与奥术支撑挂到移动主体上，分别撤去通道，观察世界后果及主次交接。三个题目的完整验收均在阶段三。
- 局部时率、生命更新、独立声学、远端观察、非实体幻象、复杂自主决策、双向空间门、大体量水文各有明确世界依赖。审阅时允许指出缺口，进入工程的范围由能力契约决定。[20 项原始矩阵](../v0.3.1/现象表达矩阵.md) · [研究索引](../magic_language/research.md)
