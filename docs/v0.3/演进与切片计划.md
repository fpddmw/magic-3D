# Magic DSL 演进与五阶段升级总计划

2026-11-28。根据多轮语言审阅与 `game/art_kit/` 实机代码复核，项目将研发主序调整为**“先打穿 Godot 4.5 技术美术实验室 → 提炼参数化动态构造算子 → 反向升级并定型 Magic DSL → 机器契约、立体废墟合流与模型/性能闭环”**。[技术美术实验室与升级计划](../art_research/技术美术实验室与升级计划.md) · [语言集中审阅入口](../magic_language/README.md)

| 阶段 | 核心工作与交付 | 退出门禁 |
|---|---|---|
| **Stage 0 · `ArtLab` 与资产底座** | 拆分 `game/art_kit/` 七个构造模块，建立 `game/art_lab/` 双光影工作台（时间轴/单帧/图层开关/多机位 Contact Sheet 抓拍器）；落地离线数据贴图烘焙、`imagegen` 英雄贴图、分层声学总线与带骨骼测试人形。 | 工作台可用，能导出多时点多机位与分层拆解 Contact Sheet。 |
| **Stage 1 · 五大跨度标杆逐个攻坚** | 严格串行逆向实现并过视觉盲审：`01 天体降临（暗月级光学）` → `02 折天之帷 × 银河垂流（动态扫掠与跨形态嬗变）` → `03 巨型旋风（流场与环境共谋）` → `04 岩晶生长与破碎重组` → `05 隐微光学与静谧异象`。 | 每项过人工与多模态视觉审看且无否决项后，才允许提炼算子并做下一项。 |
| **Stage 2 · 零新代码美学迁移** | 冻结 Stage 1 提炼的 8 大类参数化算子，不新增法术专属 Shader 或网格类，仅靠编排实机完成同力学三风格（锋锐/沉重/空灵）、跨形态新奇观及多视角/移动/打断/并发评审。 | 不写新渲染代码仍具备明显风格跨度与庄严奇幻质感。 |
| **Stage 3 · 反哺升级并定型 DSL** | 将动态形态嬗变、空间相位场、非线性力感曲线、组合重叠与动态容积语义写回 `docs/magic_language/`；划分经典下限 / 原创奇幻 / 技术机制三类语料；完成六维强制变奏与隐名独立盲读。 | 盲读配方能唯一推出世界因果并准确还原主要形态演化、构图与节奏人格。 |
| **Stage 4 · 契约、废墟与产品闭环** | 收口统一 Core Schema、注册表与轻量 `D3` 调度器；开展 20 符文端到端模型盲测（目标 80%–90% 事前预期吻合率）；按三层更新率合流进立体交互废墟庭院；真实负载下压实 1080p P95 ≤ 16.67 ms、显存 ≤ 2.5 GB，并启动 SFT / RLVR。 | 机器回归全绿、废墟庭院四类对象与跨术复用实机通过、真负载稳 60 FPS、盲测达标。 |
