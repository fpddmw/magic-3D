- 16 项新版回归覆盖上述正反对照，也覆盖分支、并行、汇合、定次重复、超时、专注冲突、非法句柄、预付储备重复支取、非法模块、模型自报费用及越权锚点。新工具直接使用活动目录。[测试](../../tests/test_magic_v03.py)

## 设计与实机边界

此次验证了单次施法实例在给定场景观测下的因果、规范化计费、法坛读解和艺术轨道触发。水网探针按离散节点与材料边推进，石廊按观测到的接触和负荷结算。Godot 实时碰撞和跨法术共同结算、全场物理与渲染预算、动作音画品质、实际模型生成质量与延迟均待实测。20 枚是候选设计，18 枚是离线入口配置；时、生、高阶空间及跨实例解魔需要各自的世界通道。80%–90% 的预期命中率留待玩家事前记录与盲测。
