# 魔法形而上学 v0.3

玩家用符文指出希望发生的现象，魔法通过以太为这个现象建立通常缺少的成立条件。形成的光、材料、关系或作用进入同一个世界，能被观察、受力、传递、打断，也会留下后果。法坛上的“固态水”可以是概念，石渠里正在凝固的水则需要已有材料、作用过程和实际相变。

## 模型据以构思的世界

本性决定事物通常怎样存在，性质描述其状态、能力和响应，关系规定哪些端点经何种通道能传递什么，过程组织这些条件随时间怎样改变。意义决定希望成立的内容，以太提供额外成立条件的媒介，魔力支付建立、改变和维持的代价，局部契约指定承担者与终点。

| 五种构思逻辑 | 对一项现象可以提出的构思 |
|---|---|
| 调动已有之物 | 借现场水源、导电路径或已有动量 |
| 改变存在的组织 | 沿现有水带连续转固，保留同一份材料 |
| 独立化性质或作用 | 将火的显明性从原本的燃烧条件中抽出并重新支撑 |
| 赋予性质与能力 | 为光幕建立有承担上限的力学关系 |
| 复合存在与作用 | 把结构承载、照明、观察和器物储备组织到同一现象中 |

这些角度可同时使用。对成品配方分别追问六件事：为何成立、如何诞生、怎样展开、向谁交付、受外界或控制怎样变化、结束时哪些条件失效且哪些后果留下。六问也适用于一瞬间发生的现象。

## 六条因果原则

1. **本性与能力分离。** 火可依托承载结构取得阻隔能力，火的本性仍可参与热作用。
2. **性质有成立依据。** 抽离、赋予、反转都要指出实际所指、媒介、合法通道和边界。
3. **实际内容不免费复制。** 复用知识或引用同一主体不会增殖材料、储备、力量或人格。
4. **共享世界。** 局部作用共同参与因果。反向力可抵消，两个施法者仍分别付费。结构按负荷承载，热按交换结算。
5. **责任明确。** 区分世界许可、充分意义、现场条件与足够责任。可由施法者主动支付、器物或场所的有限储备支付，或经有效连接取用真实外源。
6. **因果留存。** 解除支撑后已结成的冰仍在。打断能截住尚未提交的交付，已经发生的世界变化继续演化。

性质与以太七公理的既有论证继续提供依据。局部干涉只获得对实际作用的许可，既成历史受因果约束；另一项已成立魔法的内容、空间组织、联结、存续或效果可以成为具体对象。显式放入「以太」把构思指向奥术联系、寄托或魔法本身。玩家省略该符文时，模型也可以补全特殊关系，但须在配方写明以太依据、对象、容量与责任，供玩家确认。这是本版对显式媒介要求的修订。[前版公理及决定](../../archive/pre-v0.3/docs/magic_core/世界公理与概念.md)

## 玩家预期与世界作用

玩家明确的核心意向优先。模型可补全尚未指定的组织、形态和演出；额外能力都须可解释、可兑现、有代价并可在法坛读解中看见。广义奥卡姆剃刀要求语义分叉有可观察的作用、因果、控制或责任差异。换色属于艺术选择，单纯提高数值属于规模调整。规模跨过实在的承载阈值，从挡碎石到托住石梁，才会带来新的世界用途。

| 共享世界通道 | 可在战斗和探索中查验的结果 |
|---|---|
| 力学、局部重力 | 运动方向、实际受力、结构负荷与失效 |
| 材料、热 | 同份材料的相态、连通、温度与留存 |
| 电 | 有效导电路径、断路和实际电荷交付 |
| 光学 | 照度、视线透过率和观测条件 |
| 信息 | 来源扰动、传递通路、接收端所获反馈 |
| 奥术 | 实例的支撑、寄托、供给及责任交接 |
| 空间、时间、生命 | 参照已可使用；额外连通、局部时率与活体更新各须独立的能力验证 |

在石廊里摆同一块落石、同一扇窗和同一处扰动。承载光幕只在接触且未过载时承重，遮蔽光幕改变观察条件，警戒光幕把扰动送给接收端。三者可使用相同艺术轨道。这项对照把语义锚定、因果差异与世界用途放在一个现场检验。[配方与现场验收](验收.md)
