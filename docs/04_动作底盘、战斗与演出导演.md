# 04 · 动作底盘、战斗节奏与四拍演出导演

## 一、战斗定位：沉重慢拍动作冒险（不是纯“法师打擂台”）

本作既不是无脑切屏的站桩回合制，也不是轻飘飘飞来飞去的弹幕动作游戏，而是接近 **《艾尔登法环》沉重向近战＋大威严施法** 的生死博弈体验：

1. **扎实的生存与近战底盘**：
   - 角色拥有受物理惯性与耐力/架势约束的移动、翻滚闪避、法杖/佩剑格挡与弹反、轻重近战攻击。
   - 敌我共享**韧性与失衡机制**：重武器斩击、厚浪拍击、重力砸落都可以击溃对手架势，制造处决或安全施法的宝贵窗口。
2. **近战与施法的共生关系**：
   - 短促的“瞬发”小术式可以穿插在近战垫步与格挡间隙中抢节奏、补控制或触发导通；
   - 而“蓄势吟唱”的宏大魔法需要 1.5–3 秒的暴露窗口——**你必须靠走位、利用冰障/石柱掩体、翻滚躲过敌人重劈，或者先用轻法术逼退对手，才能换来抬头唤起天地异象的浪漫时刻。**
3. **伤害、失衡与位移三者分离**：
   - 盾牌格挡可以挡下大部分生命伤害，但挡不住大质量潮汐与引力的强制推退或韧性撕裂；
   - 雾、暗与时间凝滞可以完全不扣血，却彻底改变战场信息、站位优势和出招时机。

## 二、四拍程序化演出导演与 ArtKitArbitrator（让任何 DSL 法术自带电影厚度）

为什么传统程序组合魔法显得廉价？因为它们只有“出球 → 飞过去 → 播爆炸”。
在本作中，Godot 4 渲染与音频系统将内置只读 **`SpellDirector` 与 `ArtKitArbitrator` 仲裁栈**（接口见 [Expression 契约](v0.3/Magic_DSL.md) 和[艺术模块](../game/data/magic_v0_3/registry.json)），依据配方的 Expression 轨道、已绑定状态和实际交付事件驱动视觉与声音，在不干涉物理裁决的前提下，自动调度每一拍的视听压迫感：

| 节拍 | 导演调度内容 | 玩家感受到的戏剧性 |
|---|---|---|
| **第一拍：铺垫（Wind-up）** | 读取 `caster_cue.pose_tag` 压低重心举杖/触地，按 `audio_profile.drone_module` 起势铺底，微弱能量在杖尖或地面阵点亮 | “大的要来了”的起势呼吸感 |
| **第二拍：蓄力异象（Charging Omen）** | 根据 `omen_profile`（经 `ArtKitArbitrator` 仲裁多法术并行上界 `sky_darken <= 0.7`、`peak_point_lights <= 3`）调度**环境共同应和**：压暗天光、体积雾染色、周边碎石失重飘起或积水逆流；即时瞬发法术允许 `omitted_during_instant_cast` 保持爽快出手 | 天地随法师的意志屏息，浪漫感与压迫感的核心来源 |
| **第三拍：降临爆发（Impact & Release）** | 派发前通过可预测的 `pre_delivery_silence_ms`（`0..120ms`）短促收敛声场，爆发命中瞬间仅触发**局部动作/受击顿帧 `hitstop_local_ms`（严禁篡改全局 `Engine.time_scale`）**，紧接 `impact_module` 重击声＋方向性镜头脉冲＋ `Desired vs Realized` 荷载裂纹/火星回馈 | 一锤定音的重量感、打击感与绝对确定性 |
| **第四拍：战后余韵（Aftermath）** | 环境光影按 `aftermath_profile.light_decay_s` 平滑回落；视觉留痕按导演预算消退；**实际冰体、雾滴和导电积水的存续由 WorldLaw 裁定**，继续参与后续交互 | 战斗留痕进入下一拍真实交互，绝非放完即逝的假烟花 |

## 三、高自由度但不做“科学计算”的系统性交互网络

用**成熟 3D 物理（Jolt 3D）＋ 简洁而诚实的系统状态网络**，实现远超普通动作游戏的魔法化学反应：

1. **真实碰撞体生成与破坏**：凝结生成的冰壁、冰桥、石碑全部成为拥有质量与耐久的真实 3D 刚体/静态碰撞体——能挡箭、能站人攀爬、也能被重击打碎。
2. **潮湿、导电与温度状态传播**：水、冰、火、雷不靠昂贵微距网格，而是通过**物体标签状态＋地表面贴花/区域场＋空间导电图（`CONDUCTIVE_GRAPH`）**实时结算——水索缠住湿透的重甲骑士，补一记落雷直接顺着水索与积水连锁暴击。
3. **感知与视线遮挡**：敌人的视觉与锁定射线严格穿过 3D 雾场与暗域检测；雾散、冰墙破、火把灭，敌人就会立刻基于新现场重新寻路或丢失目标。
4. **物理响应分叉**：流体/气团与路径节点遇阻按照受界偏折迭代（`max_deflect_iterations_per_node <= 2`）侧泄绕流，结界平面按 `SPATIAL_BARRIER` 的 `barrier_policy`（`BLOCK | REFLECT | DEFLECT`）真实反弹或切向偏折外部弹道。

## 四、成长哲学（继承自原设计核心）

- **不靠“+10% 伤害”数值成长**：玩家不加攻击力或施法速度属性点。
- **真正的成长维度**：
  1. **词义认知与符文储备**：解开更深奥的符文词条与高阶大道理解（如接触“时”“界”“反转”的深层用法）；
  2. **法坛回路容量与复杂度**：解锁更多自由槽位与契约承接能力，能组织跨领域复合法术；
  3. **魔法尺度与掌控深度**：从前期半人高的水浪与短促冰锥，成长到能覆盖整座废殿的高压引雷、遮天暗月与长期稳固的大型仪式阵。
