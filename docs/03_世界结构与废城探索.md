# 03 · 世界结构与废城探索（3D 立体箱庭）

## 一、空间基调：浓缩、立体、沧桑的魔法废城

我们不做空旷的“王国级大地图”，而要做一座**有限、密集、层次叠压、曾真实运作过的废弃魔法古城**。探索与战斗共有同一套空间规则：

- **外景与苍穹舞台**：破损的高架石桥、断崖钟楼广场、露天蓄水渠遗址、悬空星象台。保留 35%–45% 的天际线视野，让暴雨、云层、远景高塔与从天而降的天雷/暗月拥有真正的史诗压迫感。
- **挑高哥特室内**：破顶大圣堂、多层环形藏书穹顶、沉降的地下蓄水石殿、古旧炼金工坊。室内保持充足挑高与柱廊纵深，**既确保第三人称镜头不会陷入逼仄穿墙，也让火光、冰晶折射、雾海与声学混响在石穹之下产生截然不同的幽闭庄严感**。
- **立体连通而非平面切房**：上下层通过坍塌穹顶缺口、旋转石梯、悬垂铁索、可跨越的断桥和玩家自己用魔法塑出的冰梁/石阶相连，保持“从窗洞望见待会儿要去的高塔、从水渠底抬头看见刚才走过的拱桥”的强空间记忆。

> **彻底退役的旧 2D 负担**：不再存在“0.2m 主截面”“功能后壁与视觉重叠悖论”或“二维格子泄水缝”。所有支撑、遮挡、视线、绕柱与坠落全部由真实 3D 几何自然成立。

## 二、为什么这座废城“活着”：魔法与环境的持久因果

1. **战斗与探索共用同一套系统规则**：
   - 圣堂积水不仅导电、反映月光，更是《引水成索》《霜狱潮》的现成材料来源；
   - 暴雨与狂风不仅烘托气氛，还会实实在在压低火势、扩大雷电传导面、吹散雾幕；
   - 暗域与浓雾同样真实遮挡巡逻骑士的视线——你可以借雾潜行绕背，也可以用圣光/火光撕破黑暗找出机关与伏兵。
2. **有克制的“持久世界改变”**：
   - 玩家在废城里冻出的宏大冰桥、震碎的腐朽石柱、点亮的遗迹火盆、或提前刻在要道上的仪式封印阵，会**进入区域持久状态并在重访时依然保留**。
   - **克制边界**：我们不追求“把整座城每一块砖切碎成百万粒子并保存”——而是让关键可破坏构件（柱、门、木架、脆弱桥段）、玩家亲手建立的魔法构筑物（冰体/石碑/法阵）以及环境状态（积水、燃烧焦痕、照明启用）成为可信赖、可重访的真实历史。

## 三、首座废城区域的结构节奏（远期箱庭蓝本，非当前切片范围）

先确认城市“灾变前原本如何运作”，再让玩家沿着残骸探明因果：

- **外城高架水渠与断桥广场**（外景风暴区）：开阔、高风压、大落差、积水与碎石丰富，适合练习高天象魔法与远程地形拉扯。
- **沉降蓄水穹顶与地下水道**（半封闭幽暗区）：潮湿回响、微弱磷光、多石柱遮挡与暗流，强迫玩家在近距周旋中用光、冰、雷开辟视野与站脚点。
- **破顶星象圣堂与藏书高塔**（核心制高点）：破顶处透入冷冽天光，四周环形回廊与悬空天体仪构成最适合高阶引力/星辉/时空魔法交锋的庄严战场。
