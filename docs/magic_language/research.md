## 从两个老对照检验新稿的含义

**引力向上／向下。** 用同一固定球域和维系时长，`R g = gravity(f,within(f,massive))`，持续 `Drive.gravity(g,up)`。只改 `up` 为 `down`，预测域内每个质量体得到相反的局部加速度，普通石墙不屏蔽它；每个物体的净运动仍要叠加自然引力和支撑。相同符号改动若施在气流冲击关系上，墙后的结果可不同。

**水网断边前／后。** 三段材料边 a→b→c，另有独立导电线跨过 b。`Transform.phase_path(water,a,solid,heatSink,2,1m/s)` 只沿仍相连且有水的边推进。a、b 已冻而前沿未进 c 时断 b→c，c 保持液态；不切断的对照中，足量热汇下 c 随后冻结。先抵达 c 再断边则 c 保留已成冰。电能否越过要另查导电回路。这两条是对新稿的含义检查，未重新执行历史样例。
