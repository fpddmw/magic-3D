# B · 过程、持续驾驭与共享世界

一份构筑要说清楚在什么条件下，谁能把什么作用交付给哪个对象。把光赋予承载能力要有一条可付费的结构关系。观察窗被雾挡住和穿越者扰动了雾面属于两个通道，施法者看不见窗外也可能收到一次有限的警示。[空间与身份](A-space.md) · [确定性调度](D-resolution.md)

## B1 · 配方的局部过程

在同一配方中，各过程各有 enter/tick/on/exit。进入与退出各执行一次，持续段按实付时间积分。一个过程正常退出后，可启动一个或多个后继。互斥条件以书写顺序裁决，外部事件优先级见 D。并行项写 `fork(a,b)`，同时激活且各取独立的契约。`join(all,a,b)` 等待两项成功归还，任一失败则整体失败并回收暂存。`join(any,a,b)` 取先成功者，同步终止同组剩余分支并清算，平手按声明序。相互独立且允许各自继续的后台责任应采用寄托。过程图无回边，`repeat(n,interval,action)` 只在本段活动期间按已缴责任重复，有上限和正间隔，不补发被跳过的次数。`each(group)` 为每个固定槽位建立有限局部实例。

契约记录 payer、owner、盖住哪些句柄、最长时限及可选控制。直接玩家输入只改变预先声明的控制量。同一玩家同时占用一个主动焦点，可并行多个由该焦点或寄托供给的作用。失焦、打断、松手、器物破坏分别有退场语义。`handoff` 在转换边原子转移实体控制/关系/余额及接收者责任。寄托后可另行施法，接收者须有支持端点和实付储备，到期或断联立即结账。默认阶段切换把仍被后继引用的本术句柄移动给唯一后继；fork 的多方只读视图可共享，竞争写者须在进入前分份或指定所有者。结束时按 A4 交还自然物、撤去局部作用，未交付的主动蓄势按合同耗散。

`Control(input,drives,target,limit)` 将 aim、hold、release 或真实姿态事件映射到位置、朝向、阵列排列或交付；目标、变化率、负荷、碰撞策略、失联行为由签名确定。可把一组成员绑定同一个目标，或按已声明的 slot 重排；不能写场景键或改变配方的控制流。位置跟随的场中心与推着有质量物体移动要分开读解。

| motion | 起点、持续输入与终点 |
|---|---|
| static / follow_anchor | 捕获位姿后固定，或使用有效 live 父参照。对有质量实体施控仍受可实现的力与碰撞限制 |
| ballistic | 在脱离点取世界初态，此后由惯性、重力、碰撞共同演化 |
| guided_drift | 每步读取目标，只改变容许速度/加速度内的期望运动，实体受阻时累积负荷 |
| orbit | 相对真实父轴及半径推进相位，按限速及碰撞取得已实现位姿 |
| sweep_arc | 依据真实动作或有界过程的连续弧，按前后两个姿态扫掠已实现体积 |

## B2 · 通道合同

每次申请均提供来源、作用对象或有限查询、空间界限、世界许可、成立依据与供给。具现、调动、重构、赋予、干涉是解释一次世界干预的五种方式，许多过程会组合其中数种。六面声明和七个操作族承载这些语义。例如先以以太关系赋予光刃局部传力条件，再由一次 Drive 把实际冲量交给接触者。通道依据不同，结果可以相交。相同作用在角色、世界物体和其他施法者的实体上走同一个接口。

| 通道 | 查询、传播与同场结算 |
|---|---|
| force / gravity | 力学冲击按有界域、介质/遮挡与可受力接口筛选，按质量、方向、接触传递。局部重力按场域对质量体给出加速度，普通石墙不屏蔽。合力按矢量结算，各个成立的作用各自付款 |
| support | 查询实际相接的有限支点图，静载由可达固定端承担。简化合同按各剩余通路的刚度比分担，通路串联用柔度相加，并联相加；一般有限图以锚点位移为零，沿受力轴按节点力平衡求边反力。无锚的分量自由运动。反力/容量大于 1 的边一轮同时断开，再重算，最多初始边数轮。等于容量仍有效 |
| material | 查相容份额、单位与自然条件。沿带宽有限的实边输送，按当前相态检查可流通性；phase 在同份材料上改变相态，受相变条件及热收支限制。冻结不会造水 |
| thermal | 有效接触/导热边交换热，辐射型签名另查空间可见性。按有界热量与热容更新，包含潜热。抽热需有容纳余热的环境端或付费出口 |
| electric | 从有效源沿导电边、阻抗与容量分流。按电势差及可达回路结算，有向隔离边限制方向；断路可改变其后的交付。供给型端点与回流端要在现场成立 |
| optical | 对真实视线与已实现介质/界面求交，多层沿程透过率相乘，光源再按照度结算。观察者与受观察对象可互换；墙外效果取决于实际光路 |
| information | 只接受登记的可测事件，经具体中继关系到具体接收端。载荷为事件种类、所属端点和采样时刻，可声明粗粒度区段。取得扰动不授予透视、身份或全场坐标 |
| arcane_support | 查询范围内带有可干涉标签的实际关系，校验端点权限、有效媒介、干涉强度与原有承担。压制降低有效容量，解除后仍存在且有效供给的关系可恢复。切断使该边失效，重建要重新支付。不能由引用取得对方财产 |
| spatial | 读取捕获或跟随的坐标与有限边界。跨位置传送实体须另有映射、出入口、占位与动量合同，当前列作能力缺口 |

抽热、取功与制动申请必须写清能量或反力去向。输入与反力若均在同一封闭自由组件内，整组件的质心不能因此加速。持续压力可借周围介质，现场缺空气时该签名失效。局部引力的异常作用和供给独立核算。

每一通道的依据可取自然材料/状态、实际接触或具有缴费责任的异常关系。现场选择器按通道许可、距离、稳定世界键筛选，明确查询上限。`near(kind,r)` 取最近一个；`within(subject,kind)` 取域内合格者的有限集合；`slot(name)` 是场景提供的有类型端口。`support_of(x)` 只查询可干涉的活跃支撑边。对域查询用边的实际暴露段或受支撑端与域相交判定，并按来源许可排除本术的自支撑；施法者站在远处不妨碍其现场关系被查到。若配方要求唯一目标且现场候选为空，该过程得到 missing_target。选集允许为空的域作用得到零交付。

## B3 · 向量场、账户与分流

以柱局部轴 a、从轴向外的单位径向 r、t = a × r 为基。`field(radial,tangential,axial)` 系数平方和 ≤1，各分量乘同一满额力和声明的径向/高度分布，空出的份额不再分配。轴心取 r=t=0，轴向仍有效。分布为 uniform 或 linear_falloff，按归一距离限在 [0,1]，两轴权重相乘。先将实付总量按合格目标的权重份额分摊，再乘局部分布与场系数。权重总和为零时零交付。去掉上升只在目标集合和其余分布未变时保留相同水平受力。切向取反改变旋向，整术预算不变。持续施力上限乘实付时长得到该步冲量上限。

| 槽/额 | 实际记账与可交付量 |
|---|---|
| mana | 由确定性价表换算的真实支付额。作者只写几何、规模、时限及进度比。供给可为施法者、器物储备或已接通的外源。断边窄化可支出额 |
| material | 按份额和组成记录 kg，满度可展示为已占质量/容量。提取从源先扣、到达才入接收端；途中与在途余量均计入守恒 |
| kinetic | 同时记可归属的有向冲量 J（N·s）与可用功 E（J）。捕捉外界冲击时约束承担相反反力，从实际耗散/可回收的碰撞功按效率取得 E。不得把同一事件重复喂给储备。相反冲击可使有向和归零而仍有耗散 |
| split | 同类可分权益或同一可换算能量根按非负权重分别预留，总和 ≤1。异单位交付走有方向、有损耗的登记转换；空余不复制给兄弟通道。已支付魔力承担组织责任，不能充作已经捕获的外来冲击 |

释放 kinetic 时沿合成方向，量不超过已记 J 和接受者在其当前质量、速度下 E 能支付的动能增量，同时按世界合同将反冲量交还锚体/环境。对静止质量 m 的物体，限幅为 min(|J|, √(2mE))。无输入冲击时两项均为零。热/力分流先分别划出可用功，热上限按 J（焦耳）计，冲量还要独立满足受体条件和动量来源。任一账户都须明确来源、上限、余额、退场去向。环路的每段转移均先扣再入，不能凭循环自供。

## B4 · 七族操作在样例中的签名

审阅谱以 `族.接口(有序参数)` 表示一次申请。下表是本册使用的接口，受体、世界条件、失败方式和量纲仍服从前述各表。后继可复用同一接口，能力升级必须可用通用签名说明用途。

| 族 | 审阅谱接口与效果 |
|---|---|
| Establish | `open(x)` 绑定/建立主体、关系或账户，一次性完成依赖建立；`open(group)` 有限展开 |
| Drive | `gravity(r,up/down)` 施加局部有向加速度，`field(r,vector)`、`motion(s,mode,goal)`、`impulse(r,dir)`、`heat(r,sign)`、`optics(r,transmission)`、`charge(r)`。r 是有界关系，方向可取 forward、径向或支点局部轴。离散冲量以每次实际触发为界 |
| Constrain | `support(r)` 承受接触，`lock(r,axis)` 向锚点约束自由度，`suppress(r)` 在预算内削弱支撑，`cut(r)` 对有许可的有效边提交有限切断 |
| Transform | `grow(s,dimension,rate,obstruction,source)`、`phase(s,to,sink)`、`phase_path(s,start,to,sink,max_hops,speed)` 按有效材料边、热汇与真实前沿有限传播、`fracture(s,seam)`、`repair(r,source)`、`detach(s)`、`handoff_world(s)`；相变最后一项为热交换端，冻结排热、融化取热 |
| Transfer | `move(src,dst,limit)` 同质转移，`capture(r,store)` 按实际碰撞入账，`deliver(store,r)` 消费有限余额，`split(store,r@w,...)` 依登记转换分流，`handoff(asset,new_owner)` 原子接责 |
| Couple | `relay(r,event)` 将真实事件传给关系接收端，`link(r)` 依两端实际位置、材料或以太依据建立有效边 |
| Withdraw | `close(x)` 释放局部控制或本术主动关系。关闭借物按 A4 归还，断开外术关系须走受限干涉接口 |

`R r = channel(from,to)` 的缺省均为现场有界、实付、取本性能力与相应自然/奥术条件，可加 `via` 指定通路，`basis=关系键` 指定让原本不具备此能力的端点获得许可的实际支撑。basis 指向的关系须有明确付款端与时限，支撑失效即失去该能力。隐式的首次依赖建立同样计费。`K k = store(type,owner,capacity)` 声明局部有限槽，容量写物理尺度或归一档，价格由规则导出。`small/medium/large` 是规模档。意图无法落到真实签名时应记录最小缺口。

## B5 · 组合条件与局部控制的边界

守候、改向和交接可以引用同一组有类型的读数。条件叶子为有效对象/边 valid(x)、有真实接触 contact(a,b)、通道可达 connected(a,b,channel)、储备满度 ready(k,q)、负荷或实际前沿超过指定归一阈值 at_least(load(x),q) 或 at_least(growth(x),q)。组合只用有限嵌套的 all、any、not，阈值是常量，所有查询受本次配方的范围和硬顶约束。条件只筛选带时间戳的事件。轮询式阈值越过在首次满足时发一次，降回阈值以下才可重新越过。多条件同时成立的互斥边用 D3 的优先序。

例如在 O8 的合拢阶段可检查两个实际接触和修复材料有效性；保留 join 是为了同时收回两方的写权。只检查“两边看起来都在槽旁”不足以消费两个分别由局部过程持有的句柄。另一个简单例子是对已有的电边做定次探测：局部过程写 `tick repeat(3,0.4s,Drive.charge(current))`。第一个脉冲在进入后 0.4 秒到期，其后为 0.8 与 1.2 秒，每次只按当时回路交付。若 0.8 秒的边界同时发生打断，就只有前一次可能付费。12 秒以后再次来电也不会唤醒已结束的过程。

Control 的位置绑定可按限速追逐瞄点；姿态绑定可按角速度限值追逐方向；组织绑定可在配方已声明的有限布局之间换位或按负荷调整间距。三者只改变预先声明的有限目标，接触、阻挡、实际载重和阵列槽的所有权仍须逐步结算。若可操纵实体已经脱离或交给世界，旧 Control 的写权随原责任结束。后术可重新查询、重新取得合法控制并付款。
