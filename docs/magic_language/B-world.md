# B · 过程、持续驾驭与共享世界

一份构筑要说清楚在什么条件下，谁能把什么作用交付给哪个对象。把光赋予承载能力要有一条可付费的结构关系。观察窗被雾挡住和穿越者扰动了雾面属于两个通道，施法者看不见窗外也可能收到一次有限的警示。[空间与身份](A-space.md) · [确定性调度](D-resolution.md)

## B1 · 配方的局部过程

在同一配方中，各过程各有 enter/tick/on/exit。进入与退出各执行一次，持续段按实付时间积分。一个过程正常退出后，可启动一个或多个后继。互斥条件以书写顺序裁决，外部事件优先级见 D。并行项写 `fork(a,b)`，同时激活且各取独立的契约。`join(all,a,b)` 等待两项成功归还，任一失败则整体失败并回收暂存。`join(any,a,b)` 取先成功者，同步终止同组剩余分支并清算，平手按声明序。相互独立且允许各自继续的后台责任应采用寄托。过程图无回边，`repeat(n,interval,action)` 只在本段活动期间按已缴责任重复，有上限和正间隔，不补发被跳过的次数。`each(group)` 为每个固定槽位建立有限局部实例。

契约记录 payer、owner、盖住哪些句柄、最长时限及可选控制。直接玩家输入只改变预先声明的控制量。同一玩家同时占用一个主动焦点，可并行多个由该焦点或寄托供给的作用。失焦、打断、松手、器物破坏分别有退场语义。`handoff` 在转换边原子转移实体控制/关系/余额及接收者责任。寄托后可另行施法，接收者须有支持端点和实付储备，到期或断联立即结账。默认阶段切换把仍被后继引用的本术句柄移动给唯一后继；fork 的多方只读视图可共享，竞争写者须在进入前分份或指定所有者。结束时按 A4 交还自然物、撤去局部作用，未交付的主动蓄势按合同耗散。

`Control(input,drives,target,limit)` 将 aim、hold、release 或真实姿态事件映射到位置、朝向、阵列排列或交付；目标、变化率、负荷、碰撞策略、失联行为由签名确定。可把一组成员绑定同一个目标，或按已声明的 slot 重排；不能写场景键或改变配方的控制流。位置跟随的场中心与推着有质量物体移动要分开读解。

| motion | 起点、持续输入与终点 |
|---|---|
| static / follow_anchor | 捕获位姿后固定，或使用有效 live 父参照。对有质量实体施控仍受可实现的力与碰撞限制 |
| ballistic | 在脱离点取世界初态，此后由惯性、重力、碰撞共同演化 |
| guided_drift | 每步读取目标，只改变容许速度/加速度内的期望运动，实体受阻时累积负荷 |
| orbit | 相对真实父轴及半径推进相位，按限速及碰撞取得已实现位姿 |
| sweep_arc | 依据真实动作或有界过程的连续弧，按前后两个姿态扫掠已实现体积 |

## B2 · 通道合同

每次申请均提供来源、作用对象或有限查询、空间界限、世界许可、成立依据与供给。具现、调动、重构、赋予、干涉是解释一次世界干预的五种方式，许多过程会组合其中数种。六面声明和七个操作族承载这些语义。例如先以以太关系赋予光刃局部传力条件，再由一次 Drive 把实际冲量交给接触者。通道依据不同，结果可以相交。相同作用在角色、世界物体和其他施法者的实体上走同一个接口。

| 通道 | 查询、传播与同场结算 |
|---|---|
| force / gravity | 力学冲击按有界域、介质/遮挡与可受力接口筛选，按质量、方向、接触传递。局部重力按场域对质量体给出加速度，普通石墙不屏蔽。合力按矢量结算，各个成立的作用各自付款 |
| support | 查询实际相接的有限支点图，静载由可达固定端承担。简化合同按各剩余通路的刚度比分担，通路串联用柔度相加，并联相加；一般有限图以锚点位移为零，沿受力轴按节点力平衡求边反力。无锚的分量自由运动。反力/容量大于 1 的边一轮同时断开，再重算，最多初始边数轮。等于容量仍有效 |
| material | 查相容份额、单位与自然条件。沿带宽有限的实边输送，按当前相态检查可流通性；phase 在同份材料上改变相态，受相变条件及热收支限制。冻结不会造水 |
| thermal | 有效接触/导热边交换热，辐射型签名另查空间可见性。按有界热量与热容更新，包含潜热。抽热需有容纳余热的环境端或付费出口 |
| electric | 从有效源沿导电边、阻抗与容量分流。按电势差及可达回路结算，有向隔离边限制方向；断路可改变其后的交付。供给型端点与回流端要在现场成立 |
| optical | 对真实视线与已实现介质/界面求交，多层沿程透过率相乘，光源再按照度结算。观察者与受观察对象可互换；墙外效果取决于实际光路 |
| information | 只接受登记的可测事件，经具体中继关系到具体接收端。载荷为事件种类、所属端点和采样时刻，可声明粗粒度区段。取得扰动不授予透视、身份或全场坐标 |
| arcane_support | 查询范围内带有可干涉标签的实际关系，校验端点权限、有效媒介、干涉强度与原有承担。压制降低有效容量，解除后仍存在且有效供给的关系可恢复。切断使该边失效，重建要重新支付。不能由引用取得对方财产 |
| spatial | 读取捕获或跟随的坐标与有限边界。跨位置传送实体依本文 B6的双端映射、出入口、占位与动量条件，目前仅有设计谱 |

抽热、取功与制动申请必须写清能量或反力去向。输入与反力若均在同一封闭自由组件内，整组件的质心不能因此加速。持续压力可借周围介质，现场缺空气时该签名失效。局部引力的异常作用和供给独立核算。

每一通道的依据可取自然材料/状态、实际接触或具有缴费责任的异常关系。现场选择器按通道许可、距离、稳定世界键筛选，明确查询上限。`near(kind,r)` 取最近一个；`within(subject,kind)` 取域内合格者的有限集合；`slot(name)` 是场景提供的有类型端口。`support_of(x)` 只查询可干涉的活跃支撑边。对域查询用边的实际暴露段或受支撑端与域相交判定，并按来源许可排除本术的自支撑；施法者站在远处不妨碍其现场关系被查到。若配方要求唯一目标且现场候选为空，该过程得到 missing_target。选集允许为空的域作用得到零交付。

## B3 · 向量场、账户与分流

以柱局部轴 a、从轴向外的单位径向 r、t = a × r 为基。`field(radial,tangential,axial)` 系数平方和 ≤1，各分量乘同一满额力和声明的径向/高度分布，空出的份额不再分配。轴心取 r=t=0，轴向仍有效。分布为 uniform 或 linear_falloff，按归一距离限在 [0,1]，两轴权重相乘。先将实付总量按合格目标的权重份额分摊，再乘局部分布与场系数。权重总和为零时零交付。去掉上升只在目标集合和其余分布未变时保留相同水平受力。切向取反改变旋向，整术预算不变。持续施力上限乘实付时长得到该步冲量上限。

| 槽/额 | 实际记账与可交付量 |
|---|---|
| mana | 由确定性价表换算的真实支付额。作者只写几何、规模、时限及进度比。供给可为施法者、器物储备或已接通的外源。断边窄化可支出额 |
| material | 按份额和组成记录 kg，满度可展示为已占质量/容量。提取从源先扣、到达才入接收端；途中与在途余量均计入守恒 |
| kinetic | 同时记可归属的有向冲量 J（N·s）与可用功 E（J）。捕捉外界冲击时约束承担相反反力，从实际耗散/可回收的碰撞功按效率取得 E。不得把同一事件重复喂给储备。相反冲击可使有向和归零而仍有耗散 |
| split | 同类可分权益或同一可换算能量根按非负权重分别预留，总和 ≤1。异单位交付走有方向、有损耗的登记转换；空余不复制给兄弟通道。已支付魔力承担组织责任，不能充作已经捕获的外来冲击 |

释放 kinetic 时沿合成方向，量不超过已记 J 和接受者在其当前质量、速度下 E 能支付的动能增量，同时按世界合同将反冲量交还锚体/环境。对静止质量 m 的物体，限幅为 min(|J|, √(2mE))。无输入冲击时两项均为零。热/力分流先分别划出可用功，热上限按 J（焦耳）计，冲量还要独立满足受体条件和动量来源。任一账户都须明确来源、上限、余额、退场去向。环路的每段转移均先扣再入，不能凭循环自供。

## B4 · 七族操作在样例中的签名

审阅谱以 `族.接口(有序参数)` 表示一次申请。下表是本册使用的接口，受体、世界条件、失败方式和量纲仍服从前述各表。后继可复用同一接口，能力升级必须可用通用签名说明用途。

| 族 | 审阅谱接口与效果 |
|---|---|
| Establish | `open(x)` 绑定/建立主体、关系或账户，一次性完成依赖建立；`open(group)` 有限展开 |
| Drive | `gravity(r,up/down)` 施加局部有向加速度，`field(r,vector)`、`motion(s,mode,goal)`、`impulse(r,dir)`、`heat(r,sign)`、`optics(r,transmission)`、`charge(r)`。r 是有界关系，方向可取 forward、径向或支点局部轴。离散冲量以每次实际触发为界 |
| Constrain | `support(r)` 承受接触，`lock(r,axis)` 向锚点约束自由度，`suppress(r)` 在预算内削弱支撑，`cut(r)` 对有许可的有效边提交有限切断 |
| Transform | `grow(s,dimension,rate,obstruction,source)`、`phase(s,to,sink)`、`phase_path(s,start,to,sink,max_hops,speed)` 按有效材料边、热汇与真实前沿有限传播、`fracture(s,seam)`、`repair(r,source)`、`detach(s)`、`handoff_world(s)`；相变最后一项为热交换端，冻结排热、融化取热 |
| Transfer | `move(src,dst,limit)` 同质转移，`capture(r,store)` 按实际碰撞入账，`deliver(store,r)` 消费有限余额，`split(store,r@w,...)` 依登记转换分流，`handoff(asset,new_owner)` 原子接责 |
| Couple | `relay(r,event)` 将真实事件传给关系接收端，`link(r)` 依两端实际位置、材料或以太依据建立有效边 |
| Withdraw | `close(x)` 释放局部控制或本术主动关系。关闭借物按 A4 归还，断开外术关系须走受限干涉接口 |

`R r = channel(from,to)` 的缺省均为现场有界、实付、取本性能力与相应自然/奥术条件，可加 `via` 指定通路，`basis=关系键` 指定让原本不具备此能力的端点获得许可的实际支撑。basis 指向的关系须有明确付款端与时限，支撑失效即失去该能力。隐式的首次依赖建立同样计费。`K k = store(type,owner,capacity)` 声明局部有限槽，容量写物理尺度或归一档，价格由规则导出。`small/medium/large` 是规模档。意图无法落到真实签名时应记录最小缺口。

## B5 · 组合条件与局部控制的边界

守候、改向和交接可以引用同一组有类型的读数。条件叶子为有效对象/边 valid(x)、有真实接触 contact(a,b)、通道可达 connected(a,b,channel)、储备满度 ready(k,q)、负荷或实际前沿超过指定归一阈值 at_least(load(x),q) 或 at_least(growth(x),q)。组合只用有限嵌套的 all、any、not，阈值是常量，所有查询受本次配方的范围和硬顶约束。条件只筛选带时间戳的事件。轮询式阈值越过在首次满足时发一次，降回阈值以下才可重新越过。多条件同时成立的互斥边用 D3 的优先序。

例如在 O8 的合拢阶段可检查两个实际接触和修复材料有效性；保留 join 是为了同时收回两方的写权。只检查“两边看起来都在槽旁”不足以消费两个分别由局部过程持有的句柄。另一个简单例子是对已有的电边做定次探测：局部过程写 `tick repeat(3,0.4s,Drive.charge(current))`。第一个脉冲在进入后 0.4 秒到期，其后为 0.8 与 1.2 秒，每次只按当时回路交付。若 0.8 秒的边界同时发生打断，就只有前一次可能付费。12 秒以后再次来电也不会唤醒已结束的过程。

Control 的位置绑定可按限速追逐瞄点；姿态绑定可按角速度限值追逐方向；组织绑定可在配方已声明的有限布局之间换位或按负荷调整间距。三者只改变预先声明的有限目标，接触、阻挡、实际载重和阵列槽的所有权仍须逐步结算。若可操纵实体已经脱离或交给世界，旧 Control 的写权随原责任结束。后术可重新查询、重新取得合法控制并付款。

## B6 · 局部选择、协调及领域端口
**段与端口。** `part(g,i)` 固定材料段键；`liquid_connected(g,port)` 只沿当前液态材料边取从端口可达的部分；`component(g,seed,channel)` 类推。它们是每步重新求值的视图，不创造新主体。分段相变可限在选中的真实份额。已提交的固段保留身份，撤销流态运动控制，按真实支撑承担接触。`pivot(g,root)` 取当前受控分量上最近的有效固定边界，否则取合法来源参照；引用支点只提供位姿，不能输送物质或自动继承下游控制。`supply`、`flow`、`control`、`support`、`conduct` 独立判通。断供时已付的寄托才可维持孤立端。缺路径后的自由份额、端点在途余额与有限几何仍由世界持有。

**协调分配。** `match(workers,jobs,policy)` 是只读的有界一对一分配。workers 来自实际成员，jobs 来自真实传感数据（如有限时间内可能和保护面相交的轨迹）或有限的操作目标。用相对位置/速度和当前通路求接触时间上界、转向/到达耗时。没有足够时长、负荷、视线、权限或碰撞通路的候选边剔除。先保留人工指令占用的成员，再在可行边中最大化完成数；同数最早危险优先，再比较总到达耗时，最后按稳定键打破平局。分配只是目标意图。`goal(plan,self)` 无任务时退回自己的阵列槽；有任务时是要求赶到的真实相交位姿。碰撞体到位前不会拦截。认领绑定任务与槽的代际号，手动接管、成员破坏或任务失效先撤销旧认领，同一快照对剩余集合重新匹配。手动控制只占一个焦点，其他槽继续有限自主行动。同样规则可给搬运器件分配工作点。

**运动与连接。** `Drive.motion` 沿限定运动模式请求位移/朝向；支撑与运动都要说明反力端。`Constrain.bind(r)` 只在真实接触或合法媒介与容量条件满足时建立约束，可用于黏附、抓持、局部固定、主动约束边界。容量不足先滑移，超过断裂阈值释放该边；自然接缝按材料与接合姿态裁决。`Couple.link(r)` 只在端点真实相容时连边，`Withdraw.close(r)` 断开本术的主动边。自然黏性、受压、导电率、刚度与可燃性属于版本化材料属性；热损伤降低实体边的有效截面与容量，重新传递负荷。`Drive.shape(s,目标几何,归一驱动)` 只在初态与显式上限之间插值，固定构形可写 small/large 两端。生长需料，纯域改变范围需付费；实际推进受阻，碰撞、查询与表现都读取同一成形结果。

`Transfer.route(r,rate)` 请求沿当前有效边运送同类型份额。总量取本步带宽、源余额、容器余量和实付责任的最小值。`Couple.switch(old,new)` 在一个事务内验证新边端点、介质与权限后，切换本术的输送方向；失败保持原路。已出发的包锁定原边及接收端，旧边自然毁坏则在最后可实现位置结清。材料、热、电、信息各用自己单位、耗散与载荷，不能因为共用一个几何图就共用余额。`store(thermal,host,cap)` 以 J 计实际吸收热量并受热容/温区限制。阈值事件 `full(k)`、`empty(source)` 在提交后送出。

`hydraulic` 端口为有限水单元，具有真实底高、截面积、容量、质量和有向边。水位由材料体积/面积确定。每个固定世界步中各边按旧水头差、导通量及最大流量申请转移，先合计源支出并限于现有量，再合计目的余容并等比裁剪，所有扣入同时提交。端墙或有界维持的压力约束可以降低特定边流量；外源流入或重力回填消耗实际水量。判断能否通过读取实际水深、净空及占位。波涌可以用若干相连单元的有限时序释放，旋涡可叠加切向力。连续海洋的全域模拟与这些局部语义没有依赖关系。

`thermal` 写明供、受两端；`Drive.heat(r,forward)` 的热沿边流动，冷作用从目标向热汇流。达到材料的相变阈值还须支付潜热。可燃物达到点燃条件后，由世界依据可用燃料、氧化环境和散热继续演化，耗尽会熄灭。`magnetic` 仅查询具有相应材料响应的主体；牵引有距离、力矩、负荷和阻挡约束。普通实物与符合接口的外术实体适用相同规则。

`Couple.sample(r,format)` 从真实端点按时隙读取、经 r 送达。`Couple.relay(r,event_kind)` 转发已提交事件。每包有来源、采样步、接收权限、去重键和有效期；断联、越界或超时不重播。格式是有限的 `sector_event`（区段＋扰动边沿）、`light_frame`（视锥内被遮挡后的一帧有限光样本）、`sound_frame`（该位置的有限声学频带），或实际任务标记。接收者只读格式许可的字段。`disturbance` 来自介质的实际形变/动量交换，静止不反复上报，风、物件和人都可能触发。拆除信息线不影响光学。

`acoustic` 有声源、介质、空间边界和听者。在声明的有限路径及传播时间内，按频带衰减、边界交段、绕行与听觉阈值提交听者读数。`Drive.gain(r,q)` 对本关系上的源辐射、传播或某个过程速率施加有界无量纲系数，签名指定作用量。串行衰减相乘，声音的多路径能量相加后判听者阈值；游戏内听觉和玩家对此世界声源的混音读同一结果。排除界面音与配乐。远端观测的两个输出独立扣带宽，朦胧的画面无权补足被墙挡住的细节。

`Drive.emit(r,pattern)` 从有位姿的有限非实体光学端口发出可被真实视线采样的图样。形象跟随已有实体或姿态样本，接受公开的有限事件换样；实体碰撞、质量、听觉、奥术签名要各自有成立条件。观察者按自己的视线、照度与感知接口得到内容，发现「见形但接触落空」保存为该观察者的矛盾证据。识破可改变该观察者的判断，其他人须实际收到消息才知道。作者不能直接写全体观察者的信念。

有限自主沿用有界 P、真实感应、工作匹配、受限导航和真实抓持。`waypoint(s,goal)` 在声明可通行的有限图与演员尺寸上取下一可达点，平手按稳定键；阻断后重算，无路则等到下一次有效事件或超时。器物只执行绑定过程，不能读隐藏目标、编写新策略或自动取得借物权。

`R gate = spatial(a,b,…)` 两端为实际定向有限面。`Transfer.cross(gate,event.subject)` 要求进入方向、通行类别、整体包络、映射许可、真实出口扫掠净空和支撑责任均成立。用出口框架 × 局部半转 × 入口框架的逆变换映射交点、朝向及相对速度；移动入口先减去入口该点速度，出口加回出口点速度。质量、内部状态、材料键与世界键保留，新增动能须由运动端及付款承担。失败保持源侧的最后合法状态，不复制或部分穿越，事件标记为已处理。成功后同实体清出出口面并再次实际穿入才能重触发。双向使用反变换并共享每步一次的穿越戳；多物争用同一出口按 D 的空间预留裁决。保留出口法线方向的小净空只用于几何容差。

`R clock = temporal(source,process_port)` 只选已登记可局部变速的过程。`Drive.gain(clock,0..1)` 按世界时步积分局部进度；0 暂停进度，恢复时从原进度继续，已经提交的事件不撤销。候选合同中魔力账、世界硬时限、外界碰撞与边界通行都按世界时。待交付事项记录为有界的一次性权益；到达局部阈值才交付，同时检查世界目标与供给仍有效。离域不补发，多个局部倍率相乘后裁到登记域。不得通过反复进出增殖进度或重写历史。

`R bio = life(source,plant,via=environment)` 只选已有活体的登记更新端。`Transform.advance(r,limit)` 请求有界正向组织进展：分配最多可用水、环境底物与本次作用责任，在有限空间建立可支撑的新组织和覆盖，原子扣除形成所用材料。空间受阻或任何必需来源耗尽时减小增量，实际为零则暂停。受损或无活性组织不能因几何可增长而获得生命。撤术后新组织留在原植株，由自然条件继续更新。此处只给奇幻游戏中的离散世界合同。

## B7 · 查询、选择、现场来源与责任

`select(type, within=空间, where=有限谓词, up_to=n | exact=n, order=distance_key, at=边界)` 返回快照里互异的稳定键。先按类型、空间、材料相态、观察/访问资格筛选，才按距离和稳定键排序；可指定已登记的到达时刻或路径次序，最终平手仍按键。默认在入段采一次；明确要求逐步查询时只得到当前读视图。up_to 可少取，零个时空 each 成功结束且没有交付；声明必须有来源的 borrow 在零个时报告 missing_source。exact 在不足 n 时整组不建立。遇到多术竞争实际借材，先按 D 预留：up_to 从仍可获得的有序候选取，exact 先试全组，否则释放本次预留。查询本身可被多处只读；持有者/可转权者提交才给写权。借材不足不自动开启具现。

| 用途 | 一般世界解析 | 失败、例外与读解 |
|---|---|---|
| 热汇/热源 | `resolve(thermal_sink,at=receiver,policy=ambient)` 在可达接触媒介按温差、容量和传热速率报价 | `ambient_then_paid` 须有明写的奥术换能关系、接收端与付款许可。需抽 5 J、环境只收 2 J：连续项交 2 J；若已付转换可再收 3 J，潜热阈值达到才结相；原子相变缺额就不提交该操作。 |
| 牵引反力 | `resolve(reaction,at=caster,policy=contact)` 取有效接地或宿主支承 | 离地会失去此依据。明写以施法者反坐或有限以太惯性承担时才可用替代反力端。 |
| 材料、媒介 | `select(material,…), resolve(medium,along=path)` 查询实际余量、相态、连续性、使用权 | 只有显式 `borrow_then_manifest`、允许本性、具现资格、预算与独立新份额才能补齐；只付钱不能取得他人物权。有界路上断媒质按各通道合同处理。 |
| 目标/父参照 | 玩家输入交点、可观察对象、指定场所端口、合法定位关系分别解析 | 失去 live 参照按 A3，默认不以地图真值续追。特殊石扣、固定墩、器物接线仍需真实现场端。 |
| 责任与终止 | 主动过程由施法者；寄托需有可接责端和实付有限储备；自然材料交世界 | resolve 只展开能力签名里的有序候选，先检查成立与容量，再按所用份额付款；终止释放未用预留。付费转换还须写明产物/耗散去向。 |

`slot(heatSink/ground/air)` 可作为上述通用解析的**测试绑定**，可显式指定唯一端口以保留原题反例。未写付款许可时，拿掉测试热汇不能凭空解锁付费换能；可用环境不足与版本缺换能能力有不同诊断。报价、强度、规模和持续上限由规则版本确定。

**控制形状。** `bind(scope,input,drives,target,rate,on_loss)` 中 input 可为 pose、方向、枚举、触发边沿、有界指向线或经授权的成员键。`pick(group,input,mode=first_intersection)` 用可观测、实际成形且可达的部位限定候选，按沿指向线距离、键排序；`mode=front` 在付费行进的有界前沿首次经过时取实际相交者；`mode=key` 只在允许精选且仍可观测时保留有效键。离开、无交点或失权使选择为空，不用上次隐藏位置补点。`release_for` 接一次已声明整组或定向释放，最多每个合格成员各一通知。群阵整体改变的是公共目标参照，单员接管只撤该员旧任务。自动匹配使用已观察的接近与可达性；赶到和拦截须分别确认。手控中的主体仍受动作承诺、打断、负荷和碰撞限制。

**一体多域。** 关系可各写 `extent=geometry, distribution=profile, payer=account, until=event`，不写则取已实现主体范围、该通道的缺省分布、当前过程付款和退出边界。同一移动中心上的光域半径 2 m、热域半径 0.8 m 可以独立失效。分段权重、径向/轴向 falloff、局部零权重与总预算分别解析；移除一个分支不自动把余额转送另一支。真实通道效果和不同观察者的采样在同一 WorldLaw 中分别结算。

四项本轮世界权限默认与扩展入口见[权限表](corpus/decisions.md)。领域能力都要列出端口、单位、消耗、可读事件及当前是否开放。液体转移、声学采样、活体生长、局部时率各有独立合同，仍可在同一组几何和事件上组合。

### 有界局部状态与读回执

`bounded_set(keys,initial=empty)`、`bounded_count(n)` 是过程有限状态的简记。`unused(键)/mark_used(键)` 分别读取和在成功事务中占用对应位置；只有一个该类型本地状态时可省略容器名。后继保留本实例该状态，失主按 K 结清。`packet(q)` 作搬运实参需要整包可用和整包接收容量；同种多份按确定的稳定键依次提取，连续路由可以部分交付。`apportion` 对可分同单位量按比例和硬顶分配；对明确逐件保留身份的集合，`unit=…` 要求按稳定键一对一匹配整件，不可削取多个碎片冒充一块。`identity_of_assigned_lot` 在分份提交时捕获 material/world 键，此后容器满度变化不会改写旧物身份。

`receipt(op,recipient)` 是已提交操作的带类型回执，可按操作、关系、稳定主体与受体筛选。`phase(medium) caused_by=receipt(r)` 仅订阅同一份额的材料更新，并要求它的变化记录包含 r 的实际贡献；自然材料也可能被多项作用共同改变。多个合格原因命中同一结果只播放一次。`joined(r,endpoint)` 必须收到真实接合通知；`signal(wire).position` 只给收信端自己的位置，消息内容限于已许可的格式。领域主动边的通知可跨局部转发，观察资格与负载不能扩大。

有参照的移动探头取得真实传感器的已实现位姿。它可以读 `water_height` 或 `local_immersion` 并在阈值从下方越过时发一次 `rising_event`；两端相对运动决定后者。针对指定水份的材料探头用 material 接触资格筛选连通水体。设备夹持材料、介质在图上转移、宿主向外部端口存入资源分别需要可达和有权。`deposit_only` 只授予有限同类存入，不产生提取权或外术调度权。
