# Magic DSL 语言设计 · 集中审阅稿

**本轮要决定的是这门语言能否表达足够多、足够不同的魔法，并让它们在同一个世界里有确定的后果。** 请先读一个构筑，再回看它依赖的条文。最快的路径是读[月刃 C2](classic.md)、[冰阶 O2 与双叶闸盖 O8](original.md)。它们分别检验脱离瞬间、施法之间和并行过程之间的语义。

## 先用三个问题验读

1. **月牙已经离开，施法者立即转身。** 在动作交付点，角色仍持剑，wave 已采样 edge 的位姿、继承该点速度并脱离；其后由 travel 单独支付。墙在月牙路径上才会得到实际冲量。当月牙消失，0.3 秒尾光仍依最后一段几何衰减。若打断恰好与交付同刻，新的波和尾随它的命中都不成立。
2. **第二施法者从另一端取水。** 第一术结束前后的材料份、实体和自然支撑可逐项核对；第二术只凭自己现场查到的对象取得新句柄。移走原冰后得零和场内另有相似冰是两个不同反例。新配方能否获得水与第一位施法者是否在线无关。
3. **两个半盖中一个到了，另一个卡住。** 先到的有物理存在与托管责任；汇合还没成功。超时清算后，碎石材料仍在、已发生的位移仍在、接缝还没修好。换成两边到位但补料不足，能从同一份配方得出另一条失败原因。

## 给 Gemini、GPT 和项目负责人的同一组审阅题

建议第一遍只看构筑意向和谱，遮住推演结论，分别写出“谁取得什么、何时改变控制、失败后留下什么、玩家看到什么”。第二遍对照 A–D，指出导致不同解释的最短片段，并给出能区分两解的现场。两位审阅者可以各自从规则或玩家视角先读，均以同一题和同一份文本作答。

| 重点取舍 | 请尝试推翻的规定 | 如果不成立，要改哪一层 |
|---|---|---|
| 实体身份与权利 | 分份、世界交还、外术切断以后，能否偷取排他权或重复使用同一 kg？ | A 的身份/接缝，B 的账户，D 的原子提交 |
| 成立条件与玩家预期 | 用 O3 同图改锚，两种「守」能否分别从操作读出？有没有一个符文只在名字里出现？ | 构思证据或通道签名 |
| 同刻行为与守恒 | 打断与松手同刻、两术争同源、相互压制，能否只用换遍历顺序改变结果？ | D 的边界、所有权与仲裁 |
| 舞台的诚实与美学 | 将 C5 的远景轨移给 O3，把 C2 的尾声延长；能否凭演出偷得感知、射程或持续伤害？去掉重特效是否还读得出主作用？ | C 的空间锚、时钟、降档或可读性 |
| 复用与表达成本 | 任选一项现场需求，只改变参照、责任或连接，用同一套通道写出不同用途。哪些部分不得不靠作者在谱外解释？ | 补通用默认、世界接口或明确边界 |
| 世界作用深度 | 从 20＋18 中抽一项标为部分覆盖的现象。它缺的究竟是配方语法、独立世界规律，还是一种尚未制作的资产？ | 有明确反例再扩大相应规格 |

## 证据与待定项

- **本轮交付**为四份规格、16 组作者亲编的构筑及其反事实、38 项逐行覆盖索引。O2 跨两份独立配方，O3 另有同谱改锚替换式。提交的谱是集中审阅材料。对照所得结论标为纸面推演。
- **沿用的运行证据**覆盖旧版有限柱域的旋向与上升、固定/实时瞄点的局部对照、雨殿中一部分承载、留存与通道行为。以上各项都有自己的配方和现场。[离线旋风](../v0.3.1/最小语法与旋风对照.md) · [瞄点实机数据](../v0.3.1/aim_pair_jolt.json) · [雨殿记录](../v0.3/雨殿切片.md)
- **待审的设计取舍**包括确定性快照隔步通知、冲量与可回收功双记账、材料按份额追踪、汇合失败保留已经发生的自然后果、同一镜头的焦点仲裁。文中的尺寸、时间窗与质量用于推演对应题目。通道系数、量化精度、能力上限与材质档位在机器契约或实机阶段按版本定标。当前没有新稿的程序准入、实机画面、模型首答或玩家匹配率结论。
- **审阅之后**由项目负责人裁决争议，以认可的条文编制统一 Schema、注册表和轻量推演器。届时可把文内反事实直接转成输入与预期，再开始模型试构。
