# Magic DSL · 活动创作语言与集中审阅

**可以先审一个问题：拆掉法术名，只读配方，换掉其中一项以后，世界里究竟有什么不同？** 从[三块石、两条亮线和一条真水路](corpus/recombinations.md#r1)开始。在同一阵列中，石头是实物，线可以只是一笔勾边；换成可输水的边，还要有真实截面、足量水、有效端口和供给。同样，暗月可以有与实际热域不同宽的艺术环，一个声部也可以独立于视觉构图结束。

[联合总计划](../v0.3/演进与切片计划.md)规定 A–D 与世界、艺术和编译知识在每轮共同修订。本轮待审的[B4 径向重力、C5 时空构图及 D3 回执语义差分](../art_research/studies/01_revised/mapping.md)与[配方](../art_research/studies/01_revised/recipe.json)同版。

本页是活动设计入口。六面配方、四种空间载体和七族操作承接本轮新写法。正在运行的程序版本及其证据见[v0.3 机器基线](../v0.3/Magic_DSL.md)和[既有离线验收](../v0.3/验收.md)。

### 给负责人、Gemini 和 GPT 的集中审阅

1. 遮住 R1a 的推演：取 2 m 长、半径 2 cm 的真管，现场只有 1 kg 水，碗能否进水？若换为亮线，哪些六面声明一起消失？再用两块石对照 [D 的展开](D-resolution.md#d6)，检查一份局部发射能否误扣另一份。
2. 读 [T03 世界谱](corpus/focus.md#t03)及[舞台谱](corpus/stage-scores.md#t03)。仅拿掉热汇、仅拿掉石扣、仅剪断下游控制线，分别写出 b 的相态、c–d 能否受控、会有哪一次声响。可以看到几何，但光靠一个艺术标记不能得知隐藏端的状态。
3. 读 [R3 的两种替换](corpus/recombinations.md#r3)。用同一块温铜、一个钟和同一观察者，区分「外观保留、热换成声音」与「世界作用保留、壳换成门楣」。用 [J05 的暗月](corpus/stage-scores.md#j05)再检验同一组三道偏环能否跨作品使用。
4. 读[井壁上的凸痕](corpus/recombinations.md#new)，只改变中间卡槽能否接实。后来者离场再回来摸到的最高一档能证明什么？若结论依赖谱外特判，请指出缺的端口、依据或组织规则。

### 本轮证据及待评议的取舍

| 性质 | 已有依据与余下问题 |
|---|---|
| 语言表达 | 手写谱和单条件反事实给出了成形、分配、控制、失效、跨术留存与舞台后果；38 题可逐题追到活动写法。局部组合、曲线、选择与展开仍属候选语法。需要复核复杂配方是否自然、是否存在同谱两读，以及有无必须增设的新原语。 |
| 世界能力 | 有限水文、声学多路径、任务匹配、局部时率和门户净空等有端口合同。精度、交换量、碰撞与接合能否兑现取决于能力施工和实测。 |
| 玩家输入 | 普通施法可用整阵、指向或实际前沿，探索可精确选段。阵形自动分配的可读性、指错段的频率、改锚是否符合预期要交实际玩家检验。 |
| 舞台与资产 | 六份谱指定空间、异步节奏、实际反馈、室内/低档取舍和退场。需要美术评议构图，并实际制作几何适配、音色、曲线与混音后看组合的品质。 |
| 工程证据 | 旧旋风和瞄点已有各自版本的[离线数据](../v0.3.1/最小语法与旋风对照.md)及[实机探针](../v0.3.1/aim_pair_jolt.json)。本轮提交的是纸面设计和文档核对，尚无新语法的 Schema、执行、模型、实机、审美或玩家命中率证据。 |

**集中审阅保留两个创作问题。** 目前失去阵员默认留空，作者可以显式重排；多层嵌套都要求重排时，是否需要一个共享重排操作，仍值得用新构筑检验。另一处是组合后的可读性：暗月的外壳可以越过真实热域，法坛能准确解释这种差异，但普通玩家能否凭活动边界和接触反馈辨出，纸面无法定论。两处各有现行默认，审阅可直接指出需要改变的具体谱段。

第一轮[八种经典构筑](classic.md)与[八组原创构筑](original.md)保留研究历史。后续选题与规范化条件见[联合研发总计划](../v0.3/演进与切片计划.md)第 8–10 节。
