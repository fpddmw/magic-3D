# A · 存在、动态空间与拓扑

问题从一把剑开始。剑光贴着剑刃挥动，月牙离手后继续掠过石柱，尾光最后消散。这里有三个不同的存续条件。若把它们都挂在一个随角色转身的节点下，玩家松手后仍能凭转身使已经放出的月牙拐弯。以下规则供[过程](B-world.md)、[舞台](C-stage.md)和[调度](D-resolution.md)共同使用。本文与配方均属设计稿。

## A1 · 什么获得身份

`Concepts` 记录本性、知识和性质来源。`Subjects` 声明本次施法要引用或建立的具体材料、场或世界对象。材料可以跨过程、跨施法继续存在。关系、过程、储备各有自己的身份和有效期。一个面可以是冰面、光学界面或压力边界，分别需要可支撑材料、光学作用或能支付的力学关系。

| 来源简记 | 建立当时的效果 | 撤去最后一项主动责任 |
|---|---|---|
| `manifest(nature,geometry,ref)` | 付建立成本，创建有限的材料或作用域。具现材料同时登记新质量与付款依据 | 已经能自然存在的材料交世界，纯作用域失效 |
| `borrow(nature,selector)` | 查询一个实际匹配物，获所需用权。空集使依赖它的建立失败 | 归还原物，保留位姿、温度、损伤、动量与有效连边 |
| `ref(selector)` | 只读地认出外物或位置；可作通道端点 | 解除本地引用，外物继续存在 |
| `derived(parent,geometry,ref)` | 派生有限的作用域或从父材料划出已记账份额。沿用的性质须有依据 | 区分局部作用终止、分份材料留存与所有权交还 |

实体键 `world_id` 在世界内稳定。材料的每一可计量份有 `lot_id`、组成、质量和父份额。施法的控制权另用 `(cast_id, local_handle, generation)`。同一物体可有多个观察引用，同时只能有一个排他的写权。普通施力通过非排他通道。对材料同相原位变形和整体相变保留实体键、份额键及引擎承载实体。物理拆分时保留父账和去向，产生有唯一键的子份；合并记录各来源比例。抢到别人的只读引用不构成取走权。derived 的材料几何初建为空种子，只有显式 move、grow 或声明划份的提交才扣源；禁止建立时先隐扣一次、转移时再扣一次。物体保持整体而改变相态时，仍须以原世界键承接其既有引用。

## A2 · 几何声明与可达空间

几何参数以米为单位，计数为正整数。四载体各承担一种可查询的空间职责，复杂构图可把不同职责接在一起。

| 载体 | 本稿使用的构造子 | 如何演化，怎样参与世界 |
|---|---|---|
| Body | `body(r)`，半径 r 的有界实体包络，实际碰撞依本性和形态 | 位姿、体量、有限成员或独立运动。借用的物体沿用现场形体 |
| PathGraph | `path(n,length,width)`，有限节点与最大总长、截面直径；可挂有向分支边 | 只沿当前有效边传播，可附着于真实表面。断边后只保留可达分量 |
| SurfacePatch | `patch(n,length,width,bend)`，沿长度分 n 段，宽度与总弯角 | 每段有材料份、接触面和邻接。弧面入口连续，碰撞和承重只覆盖已成形段 |
| Region | `sphere(r) / column(base,top,height) / cone(length,half_angle)` | 由局部坐标裁边，直柱两半径相等，锥柱沿轴线性插值。边界内还要通过通道查询 |

普通右手坐标，上轴 +Y，长度单位 m，角度带 deg。柱的原点在底面中心，`t=height_fraction` 取 [0,1]。几何外的查询终止，分布只调节域内强度。`occupied_space` 是能接触或阻挡的实际几何，`influence_space[channel]` 是该通道的候选区域。湿雾域可消光却不能充作站台。分段增长从 0 起时，作者须声明目标几何及真实初始种子。占位、作用域和艺术前沿同时随已提交的增长推进。

## A3 · 参照树与运动

`capture(anchor)` 在本主体成功建立时取样一次。`live(anchor)` 随父参照读取，默认全位姿，`position` 只继承平移；`cast(anchor)` 在本次施法入口捕获。可叠加有限本地偏移 `offset(ref,xyz)`。根可为 world、caster、hand、weapon、aim、target 或由签名提供的现场槽。子参照可以指命名主体、稳定成员或附着点。参照图须无环。父体先于子体取得本步位姿；物理承载体的位姿由可实现的运动决定。瞄点移动不能让实物越过墙。

`detach` 以交付边界的实际世界位姿脱离父体，继承该点的线速度（包含父体角速度在偏心处的贡献）和当前角速度；随后单独计算本次有预算的推进。无额外推进时采用继承速度。脱离事务同时解除对旧参照的存续依赖；仅有局部作用枝独立存续时，要在后继上落实供给。失去 live 父项时，纯场默认撤销，实体解除控制转交世界。设计者可在建术时选 `on_loss=capture_last` 让已取得的有限域在最后已知位姿继续付费到期。首次就缺少父项时建立失败。角色转身、父项退场、查询范围出界是三类不同事件。

`formation(count,layout,dispatch)` 展开固定数量的成员键，布局可为 arc/ring/line/scatter，派发可同时、按有限间隔错开或逐个受真实事件触发。散列定位按配方版本、施法种子与成员键确定，回放保留种子。布局尺寸由几何/显式间距决定。成员离阵保留身份，其余成员保留既有槽位；重排需要显式控制。`each(group)` 为每个成员展开一份有界局部过程，其 `self`、感知、付款额度与退场各自独立。计费及主体上限按完全展开的最坏同时数计算。

## A4 · 生长、断裂、修复与归还

1. `Transform.grow` 指定轴向、径向、沿路径或沿段列的目标、速率上限、可用材料、遇阻响应。每步申请的增量同时受材料密度、来源容量、付款和可占空间约束。`halt` 在首次阻挡处终止，`truncate` 本步裁短并可在后来清障后继续，`slide` 把余量投影到真实表面切平面，`deflect` 从声明的有限备选方向中取第一个可行方向。无可行方向则前沿停下。拒绝零成本分支复制。
2. 连接类型至少区分 `adjacent`（相邻）、`material`（有连续材料）、`support`（可传负荷）、`conduct`（可导电）与 `arcane_support`（异常性质的支撑）。相邻的两段依本性、接触及有效关系可同时取得多个通道；断掉以太供给不会自动切断实体铜线。
3. `structural_chain` 按当前支点、段间有效承重边和材料容量计算负载。超过容量的边按[B 的结构合同](B-world.md)失效，失去通路的一组进入自由运动。修复需端点仍在接合公差内、可恢复的边、足量相容材料和新的作用责任。旧裂纹、此前的位移与已经脱落的材料都要继续记账。
4. `Transform.fracture` 只沿预先有界的接缝拆成若干部分。重组按可到达的端点、实有份额与新连接组合。一次分合前后的材料组成与质量可逐份对账。`handoff_world` 在原位结束控制，世界接过同一实体及仍有效的自然连接。创建新实体再销毁原物会丢失历史，无法满足此合同。

## A5 · 共享快照

| `SpatialState` 字段 | 调度提交的可读内容 |
|---|---|
| reference | 父键、采样方式、本地与已实现世界位姿、线角速度、有效性 |
| realized_geometry | 四载体种类、已成形段/节点、前沿、当前尺寸与取向 |
| material_distribution | 各段/成员材料份、相态、质量、温度及出处 |
| connectivity | 有方向与容量的各通道边、失效原因、支点可达性 |
| occupied_space | 实际占位与可接触面，供碰撞及贴表演出查询 |
| influence_space | 按通道分开的范围、分布和传播资格，供命中与边界预示查询 |

共同现场示意：目标桥长 3 m，端部前方 1.6 m 是石墙，材料充足且选 `truncate`。第一步若只够形成 1 m，玩家只能踩到 1 m；下一步最多到 1.6 m。清障后才可继续。在已形成端失去唯一支点时，冰面仍占空间并开始坠落。三步的前沿、接触位置、镜面边线读同一份提交结果。若场景改为双端仍有有效承重链，是否坠落要重新求负荷。这是设计推演。

## A6 · 在同一几何里写出分支和局部变化

PathGraph 可在 Subjects 的几何附项中声明有界的节点、边与入口。节点用相对父参照的米制向量或已声明实体的附着点；每条边有稳定键、两个端点、方向和截面。姿态采样改变端点位置，不能自动接通两条相近的边。SurfacePatch 按同一原则声明局部缝、支点槽与已实现段索引。集合查询使用稳定成员键或可达分量，图上重复抵达同一材料份只处理一次。

```text
path(4,3m,0.04m)
  nodes a=(0,0,0), b=(1,0,0), c=(2,0,0), d=(1,0,1)
  edges ab=(a,b), bc=(b,c), bd=(b,d)
  entry a
```

以上三个 1 m 的分段组成一进两出的水带。几何上的 ab、bc、bd 不随同一材质自动共享一笔流量；在 b 分叉，每笔实际物质/热/电按本通道的有效容量或声明份额分配。发出后接收端才断边，要区别在途物质、未交付份额和已经到达的材料。默认材料搬运按到达边界原子扣源入账；显式有传播时间的储运将已扣份额挂在边的在途账。断边时，已脱源份额落在边上最后可实现的位置并交世界，尚待提取份额留在源。冻结等作用前沿只对到达且相变条件充分的段提交，未达段保留原态。两个支路绝不能各取完整的一份水。

阵列位置也有几何依据。line 按索引沿局部 X 排列并居中，ring 从局部 +X 沿正切向均分一周，arc 默认在朝向前方的半圆内等角取样，scatter 在给定包络内用施法种子和成员键取有限位置。单成员取本地原点。构形位置是目标位置，有质量对象只有在真实控制与空间允许时才能占据。若把两块有限分段放到同一支点、跨术共享位置参照，仍须分别检查每块的接合状态和支点的总负荷。
