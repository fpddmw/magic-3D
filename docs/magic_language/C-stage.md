# C · 多轨舞台与视听编排

观众应能从桥下辨认哪一跨正在受力，也应能在暗月掠过时感到整座废城的光变冷。这两种信息有不同的空间尺度、节拍与真假条件。`Expression` 从已提交的过程、几何和世界事件读取状态。读表现轨的人可以解释气氛；读配方的人可以独立指出真正危险或可踩的位置。[空间足迹](A-space.md) · [调度边界](D-resolution.md)

## C1 · 一条轨如何写

`X process.role @subject.anchor = form/material/motion <- driver[lo..hi]:curve + cue ~tail`。这是六面配方中 Expression 的紧凑写法。各字段按签名组合，轨道声明顺序仅用于同优先级仲裁。方括号为相对驱动窗口，tail 以秒计。省略窗口取 [0,1]，曲线 linear，cue 取 none，tail 为 0。`all` 可以绑定实例整个存续期。`impact` 等脉冲事件在本步直接触发一次。已结束阶段的事件用提交记录中的过程键匹配。每个锚都经所属过程与受体筛选：front 可读实际几何生长、相变或修复前沿，只有对应作用存在才有样本；静态场一般使用 boundary。

| 维度 | 本稿的封闭词汇（具体模块以评审后的登记为准） | 绑定条件 |
|---|---|---|
| 角色 | hero、secondary、omen、director | 主体重心、伴随读数、远观预兆、声场/镜头/动作调度 |
| 形象构图 | mass（体块）、array（离散群）、ribbon（连续流线）、skin（面）、core（中心场）、horizon（远景）、none | array 读成员，ribbon 读路径、扫掠历史或场流向，skin 读已成形轮廓 |
| 材质光学 | slate、crystal、water、mist、ember、dark、etch、none | 标识外观意图，可按载体调适。对世界的透明、导电、刚性另由 B 裁决 |
| 运动形变 | still、gather、turn、advance、strain、shed、fade | turn 的手性、strain 的强弱和 advance 的运动方向读实际值 |
| 空间异象/锚 | realized、front、boundary、aura、sky | 前三者依实际几何、前沿或单一作用通道，后两者是环境呈现。多通道主体用 `boundary(channel)` 消歧 |
| 视听/动作导演 | none、breath、rumble、ring、crack、hush、echo、brace、reframe | 音高、力度和衰减可随驱动变化。hush 需要确有交付预备窗口，brace/reframe 只用现有动作或可用镜头自由度 |

独立的视觉构图、材质、运动、空间和视听五维可按需缺省。音轨可用 none/none/still，不必捏造一个发声的发光体。实机资产分四层视觉/四层音频混音，语言里的四种角色描述叙事职责；一条导演轨可驱动多个已登记混音层。

## C2 · 载体与材质的适配

每个单元描述一个可由美术独立制作或降档的表现。相同材质能在不同构筑中复用。空缺适配回退到保留真实轮廓的低档材质，并在审阅/准入记录标明，缺失玩法可读轮廓时不准发行。

| 材质 | Body | PathGraph | SurfacePatch | Region |
|---|---|---|---|---|
| slate | 湿石硬面与崩口 | 节理石脊 | 分段层理、接缝受压变亮 | 以悬尘外壳读域，实石另由实体给出 |
| crystal | 棱角与内折光 | 沿线晶脊 | 薄片透射、受力裂纹 | 边缘结晶微粒勾出截面 |
| water | 厚水透射轮廓 | 沿实际截面流动的亮线 | 薄水膜与水沿 | 折射密度随已实现分布衰减 |
| mist | 低对比轮廓 | 沿流线稀疏条带 | 掠面雾帘 | 前后层密度与衰减 |
| ember | 暗壳内小面积热核 | 沿线余烬 | 传热前沿窄亮边 | 密度渐隐、热点受限 |
| dark | 吞光剪影与背光边 | 局部遮光梢 | 已实现界面的暗边 | 真实光路的渐隐边界 |
| etch | 物体刻痕 | 有向端点脉纹 | 表面窄带刻线 | 有界弧线提示域向 |

空间构图可以跨阶段变换。月牙从剑刃的窄面转为脱离的弧面；退场后让柱面的反光缓收，声音在拱顶多留半拍。晶片暗处的薄透射和受压开裂依同一已实现段渲染，靠近镜头也不应像贴在空中的一层塑料。

## C3 · 多速节拍、重心与余韵

- `progress` 是当前过程在有限时限内的归一时间，`fill` 是付费账户满度，`growth` 是真实成形比，`load` 是反力/可承受负荷，`velocity` 取速度/相应登记上限，`transmission` 取实时透过率。事件型 `impact / overload / signal / release / break / pose_release` 只在真实事件提交后驱动。连续驱动先裁到窗口，再归一并套 linear、ease_in、ease_out 或 smooth 曲线。窗口前权重为零，窗口后保持端点值直到阶段终止。受力卸去可以使 load 倒行。事件可读有向冲量、应变段或真实位置。艺术时钟无法生成世界事件。
- 在同一释放过程中，前半拍可让轮廓随 growth 稳步长出，内部亮度由 fill 的 [0.55,1] 迟起，岩屑在 load 的 [0.75,1] 才有摩擦声。音画共享真实事件时间戳；起势、反弹和室内反射可按登记包络各走各速。不可预知的玩家松手没有可提前播放的静默窗。真实预备时间短于模块要求时跳过 hush，输入在原步提交。
- 主重心以每镜头同一时刻为单位。各术可提名 hero，全场按玩家近期可交互危险、当前操控焦点、合法范围内的近度、稳定键仲裁。阶段切换用有限交叉淡变，旧新权重之和≤1，轮廓主位以同一个裁决键交接。次要危险仍有准确足迹。不同观察者可有不同重心，世界状态相同。
- 废城大面积保持冷暗低饱和，局部高亮优先留给核心、锋面、受力裂口。约 9% 是材质初始标尺，整帧效果由场景评审。大型长蓄力的 omen 才能申请 sky，室内转到穹顶可见面或取消。远景变色没有命中、遮蔽、通电或感知效力。
- 付费或控制结束后，tail 只保留最后提交的几何样本/声源位姿和有上限的衰减时钟。零尾长的危险提示在危险终止时结束。余韵可以沿最后水痕逐渐收暗，不得继续跟踪消失对象以泄露位置。低档先去体积扭曲与大面积透明，再减伴随轨和远景，保留真实边界、方向、失效提示和同步节拍。

## C4 · 同一过程如何分镜（设计推演）

| 世界时点 | 主体与伴随 | 可推翻的画面判断 |
|---|---|---|
| 月刃建立，武器尚未挥出 | 剑锋的薄片轮廓居主位。内折光由实际姿态驱动，室内声床轻起 | 此时场中若已有向远处移动的伤害边界，演出提前声明了交付 |
| 真实 `pose_release` 到来 | 已实现的弧面捕获位姿。重心从剑转向月牙，运动束线读新速度，挥击与离刃声共享事件点 | 玩家立即转身时，已脱离的弧面及其远处接触点继续原方向 |
| 月牙碰柱或自然到期 | 碰柱只在真实 impact 时给一次石廊回响。未命中时仅衰减。尾光沿最后路径停留 0.3 s | 若尾光还能造成第二次推力，表现已越权 |

这份规格定义编排的因果与美术接口。曲线、色板分寸、材质档位及异步节拍能否在不同组合里显得凝聚，仍需实机艺术评审。
