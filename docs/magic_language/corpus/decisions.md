# 留给项目负责人和 Chat 的四项决定

38 道题都已用表内的明确假设写完，可以直接提出反例。以下选择会改变玩家真正获得的权力，甚至改变同一份符文图应怎样读解。纸面推演暂取的值不会自动成为开放能力。

| 决定 | 本稿采用的候选规则 | 另一种结果及会改动的题 |
|---|---|---|
| 谁能成为远观的定位锚？ | J18 要求已知且可用的地点/端点。可看可听的范围由该端的真实视听条件决定。 | 若允许凭认识某人把视点附在其身上，即便不知道其所在也可能跟踪。需要单列取得定位、目标抵抗、阻断及暴露观察端的条件。会改 J18 的建立资格，并影响 T14 的观测权限。 |
| 幻象能让观察者相信到什么程度？ | T14 选择共享世界中的非实体光学形象。每名观察者独立看见或发现矛盾，普通 NPC 只能使用自己的证据。 | 若可以直接改变某个观察者的知觉/信念，即使旁人看不见、光路被挡也可能成立。这是另一种权限，要另定受体、抵抗、证据冲突与记忆留存。由此决定法坛如何区分两种锚。 |
| 门对他人的通行权如何取得？ | J19 假定实物及自愿角色可过，T17 假定单向口只认自由水份。整体包络、占位和身份规则在两题相同。 | 若无同意的活体也可被强制送过，拿盾推人入门将成为一种新用法；须确定通行类别、抗拒和入口关闭时点。允许该玩法后，拒绝穿越的反例要改为权限或约束实际胜出的现场。 |
| 「时」能指向哪些真实过程？ | T18 只干涉暴露了局部时钟的过程。施法者的供给、世界硬时限和外界碰撞照常，恢复时不补历史。 | 若普通燃烧、受力积分或生命更新也可被单独选中，必须规定跨域交换怎样结清。把入域前已经发生的结果倒写回去仍与既有公理冲突。 |

本轮对「生」只需兑现已有植物消耗环境资源后长出新组织的原题。水量、水带控制权、群盾平局、雾中消息字段、能量账与通道失效顺序已有可证伪的候选规则，可在规格审阅中直接修改。精确数值与玩家开放波次留在各自阶段。
