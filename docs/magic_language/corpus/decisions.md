# 四项世界权限 · 第二轮默认

这些值用于本次设计谱和反事实。权限、可表达的配方与已实现的能力分别登记。下列扩展若要向玩家开放，需要另订签名和验证。四个默认均可在集中审阅时提出反例。

| 默认 | 可区分的现场 | 扩展所需的设计 |
|---|---|---|
| **远观依赖实际定位。** 已知地点、可用观察端或合法取得且仍有效的定位关系均可作锚。能看见什么由观察端视听条件和信息带宽决定。 | J18：知道对方姓名无法取得所在；曾给对方附加合法标记，断联后也只能保留获准的最后样本。 | 持续追踪须写建立、抵抗、通知、暴露和失联合同。 |
| **幻象首先进共享光路与声路。** 各观察者按实际视线、听觉和自己的证据判断。 | T14：一人绕到屏幕后见到矛盾，旁人须收到有来源的消息才获得这一证据。只有光学端时没有世界脚步声。 | 对个体信念、知觉或记忆的干预另设受体、权限、抗性和保留期限。 |
| **开放门接纳实际完整通过的合格实体。** 自行移动或被推都可跨面；须有已开放的两端、整体净空和实体通行资格。 | J19：人被推过开放面且出口空，保持身份出门；同一人抵住门框、外力不足，或出口被堵就留在原侧。T17 只允许自由水，装水的人或壶不能跟过。 | 隔空直接转移、选择性或超远门户分别需身份资格、抵抗、反力及落点合同。 |
| **局部时率先作用于已登记的过程。** 既成历史保留，世界时供给、硬时限和外部碰撞按自身合同推进。 | T18：局部进度尚未达阈值就到世界截止时，不会补送一次旧交付。 | 热交换、燃烧、生命、运动可逐项设计局部变速，先规定两时间域交界的量与事件如何结算。 |
