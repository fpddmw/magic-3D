# 38 道原题 · 完整配方与反事实

这是一套供人复核的 Magic DSL 语言设计稿。题序与用户提供的两份 Chat 讨论相同。第一轮检验“怎样形成一种现象”，第二轮检验“同一现象能怎样被驾驭、继承和另作他用”。每一项都有独立配方、现场输入、正例与反例，结果由人工依规则推演。

**优先验读三题**　[群盾的分配与实际拦截](focus.md#t01) · [水带冻结后的控制与质量](focus.md#t03) · [真实雾中可获得的信息](focus.md#t13)。先读谱，遮住结果，从相同检查点只换一个条件，再读分步表。

**配套规格**　[通用语义、读谱词表及调度增补](semantics.md) · [需负责人和 Chat 决定的四项权限](decisions.md) · [A–D 总入口](../README.md)。有限水单元、观察端、空间门、局部时钟与活体更新仍需相应的 WorldLaw 后端。形色、手感与模型首答要在各自阶段验证。

## 审阅依据

第一轮取样依照原讨论，包括《艾尔登法环》的 J01–06、《龙之信条 2》的 J07–08、《旷野之息》的 J12、J16 以及 D&D 的其余题。第二轮保留了原来的三组问题：结构、运动与操控，传递、保存与世界因果，感知、生命及抽象规律。原研究的既有证据见[基线矩阵](../../v0.3.1/现象表达矩阵.md)。

对每个反例分别查操作目标、资格、状态变更和存续责任。标题、着色模块和场景端口都不参与按法术名分派。
