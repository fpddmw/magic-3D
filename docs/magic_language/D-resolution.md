# D · 统一解析、调度与证据

设计目标是两位读者面对同一份配方、同一份世界快照和同一串输入时，可以独立写出相同的对象身份、作用方向、资源去向与退场结果。引擎接触数据、能力实现和艺术评议需分别留证。

## D1 · 一门配方的六面简记

审阅谱省略 JSON 标点和登记可推导的字段。每个块可以逐项归入 v0.3 六面，后续由同一版本的机器契约承接。下文两册中的每个代码框是一份独立配方。两次独立施法写成两个代码框。配方外的现场条件、探针和反事实不是运行时指令。

```text
C 本性或性质依据
S 主体名 = 来源(...)
R 关系名 = 通道(来源,受体[,via=有限媒介])
P 过程名 <时限,付款端> : enter 操作 | tick 操作 | on 事件 -> 后继 | exit 操作
K 账户或契约名 = 声明(...)
X 过程.角色 @主体.空间锚 = 形象/材质/运动 <- 驱动[起..止]:曲线 + 提示 ~尾秒
```

- C 为 Concepts。符文图、情境、可选锚定属于构筑输入，随配方列在正文。共同组织用 `{…}`，局部有关联用 `→`，因果接续用 `▷`。二者相遇时花括号标出作用域。每个例子的正文把关键字组落到实名的主体、过程或关系。书写者须标明哪些是明确意向、哪些是依据世界知识补全。语义锚检查可观察差异，外观读不出关系类型时法坛仍须说清。
- S/R/P/K/X 对应 Subjects/Relations/Processes/Contracts/Expression。声明顺序不是时间顺序。局部 ID 唯一，含 self 的声明在各自成员作用域中实例化。选择器、数字、向量、枚举和已声明的键才可作参数。只读样本中的 `all` 作转移量时表示现场可用量与本次容量二者较小者。没有自由算式、脚本调用或法术名查表。
- 省略版本代表本设计稿，缺省规模 medium，正文标明 large 的用 large。缺省有一个入口，即首个 P。控制者为施法者，付款端与最长时限写在 P；`world` 只指自然续存，不能支付异常作用。过程未写 `on` 时持续到时限或打断并结束；`end` 成功终止。`ready` 指 enter 已成功并提交，`timeout` 指时限届满，`release` 为实在输入。`contact(s) / proximity(s) / signal(s) / overload(s) / break(s)` 要有合格现场通道、对象及正阈值。`on … if ready(k,q)` 只读已入账户满度是否 ≥q。`pose_release` 来自既有动作交付帧。
- `,` 在操作列表中按声明序组合成一个事务。位置参数的顺序见 [A](A-space.md)、[B](B-world.md)、[C](C-stage.md)。`on e -> [操作] next` 的方括号是获选转换边上一次性交付；先读离场前已实现状态，成功后转权并进入后继。`end` 可以带交接。`P p each(g)` 展开 B1 的有限槽位。`P p join(all,a,b)` 是显式汇合点；前驱成功到达才登记，失败由汇合规则清算。
- `K control = bind(process,input,drives,subject,limit)` 是 Control 的谱记；`K group = formation(subject,count,layout,dispatch,spacing)` 声明主体的阵列槽位，布局半径/间距带 m。`K … = store(type,owner,capacity)` 只创建空槽。`K structural = chain(subject,anchors,capacity)` 在已成形的相邻段建受力边并在实际接触处接支点。`slot` 由现场提供，名字无执行分派作用。`ambient` 是可查询的局部热环境，有有限供吸热能力。`caster/aim/hand/weapon/target/world` 是外部有类型端口。
- `Establish.open` 只在依赖初次实际使用时展开未建立的 S/R/K，上层持有共享只读引用；样例可以显式开主体而在第一次通道操作时才绑定关系。先检查所有先决条件再一起提交。一个过程同时新增依赖时按引用图求序。`tick` 次次申请作用，不能重复创建或重复消费同一事件。物理量必须有单位；`fill` 等归一量限在 [0,1]。能力登记可给出非零默认速率、作用容量和查询硬顶，均由版本与档位确定且可被读解。
- 裸枚举 `forward` 是作用源实际朝向；`self` 是当前阵列成员；`contact` 和 `proximity` 的默认来源分别为真实接触与有界、通过光学可见性检查的近距查询。现场声明给出传感距离。未指定的维系条件均默认局部关系在域内有效且付款端可支付。符号缺省不得暗中产生新的通道。
- 谱中 `v(r,t,a)` 为 B3 三分量，`hit(s)` 取带接触序号的初触对象，`sensed(s)` 取刚刚通过该槽可见性及距离检查的对象，`toward(x)` 在交付边界捕获指向 x 的单位方向。`contact(a,b)` 限定一对端点，`piece(parent,i)` 取已提交分割记录中的稳定子份，最多取登记接缝数加一份。`abort` 为失败出口，按 B1 通知汇合并归还暂存。普通 end 为成功。释放事件上的最低满度条件不满足时，按契约结束蓄势、清算余额，不触发阈值交付。`along_velocity(s)` 取实际运动方向，速度为零则本方向交付为零。同一对接触在分离前只允许一次同用途冲量。激发物自身的推动还要向维系它的施法媒介交付反冲。每个 each 槽的后继继承本槽绑定。
- `K name = owner(subject,process)` 在并行入口选定主控，其他分支对同一实体只取读引用或申请本地通道。素材可给出相容介面，派生另一本性的材料必须独立声明来源。在自然物现场注册的器件可以做有界转换，例如绳轮将输入轴映射到输出轴并使固定端承担反力，灯将实际电功率转成有限照度。转换效率、端点、量纲与来源在版本化能力表登记。
- 世界通知 `beam_break / delivery / break` 分别来自真实光路的遮断边沿、合格通道的一次实际交付、指定结构边失效。信息转发只读上一提交的通知，按源事件键去重。运动、增长、热作用、冲量及起反应的相变均可产出带受体与通道的交付回执；舞台的 impact 仅绑定有资格的回执。
- `growth` 从指定变形或相变任务已完成份额读出，瞬时完成时可直接跳至 1。`fill` 必须唯一对应其主体的储备或有限容器；有多个槽须写 `fill(槽名)`。`load` 可通过有权读取的现场自然承载接口取得。

## D2 · 从锚定到准入

1. 固定符文图与接续、施法情境、知识、世界法则/能力/计费/艺术版本，及明确锚定的对象、方向、来源、过程和责任。保留禁配意向。`分` 可以指实际材料分份，也可指断开奥术支撑；已锚定的受体决定哪些候选合法。默认首答给一份最自然配方，有实质因果分叉才附最多两个改锚。
2. 按本性、现场来源、四载体、实体/控制/关系/储备身份及量纲解析引用。拒绝参照循环、超界展开、悬空后继、无归宿的线性句柄、跨维度分流、读表现写世界、无穷循环。对所有可达分支分析所有权与并发责任。高级字段被省略时只取确定默认。
3. 检查世界许可、意义证据、现场所需条件、承担上限，分别给出诊断。合法但当前能力未登记，例如局部时率，返回 capability_gap；试图重写既成因果返回 world_denied；声称“承载”却仅有光学关系返回 anchor_mismatch。施法地点缺水是合法配方在该处的 missing_source。账户不足可截短持续区间，原子离散交付缺所需最低责任则整次拒付。
4. 法坛读解从准入配方依序给出「来源和形成 → 对象与范围 → 何时及如何操控 → 供给及释放 → 终止与留存」及锚点的局部证据。对明确反向补全拒收，对颜色和措辞无因果差异的两解合并。审美与默认解释是否符合玩家预期单列。机器契约冻结后才测模型能否写出这份配方。

## D3 · 一个世界步的边界

把相同时间戳的输入/断供/现场变化收在同一批。为避免“同一步先写者决定物理”，采用**一个旧快照、一个候选运动快照、一次共享提交**。连续量结算到事件边界，边界后的作用才服从该时刻新输入。时间、种子、能力版本、空间查询样本和物理步配置属于回放输入。

| 次序 | 可读 | 产物与可见时刻 |
|---|---|---|
| 1 封存 | 前一提交 Sₙ，已发生的接触/断边与本步输入 | 旧状态只读，结清截至边界已发生的持续费用和交付。销毁源、断供、失效关系在新时间区间不可用 |
| 2 动作与空间 | 旧状态、合法控制、参照树、已采样动作 | 自父及子求候选运动 M，实体限速并受已知碰撞，建立/脱离读取 M 的实际位姿。此时不发布新材料或命中 |
| 3 过程 | 旧状态及 M 中的现有对象、可用事件和付款端 | 各过程生成意图，先取消或选边再提交本步申请。处理优先级为强制中断/失主 > 超时 > 动作交付及松手 > 世界通知 > ready/定次脉冲。同级按声明序。超时有显式后继才走该边 |
| 4 WorldLaw | M、有限查询、依赖和资源预留 | 同一通道汇总，同一消耗先仲裁，同步热、相变、结构断裂和力学响应按下面的依赖顺序结算 |
| 5 提交 | 本步确定的实际增量、成功转换与交还 | 原子发布 Sₙ₊₁、所有者和有来源的事件。新主体可在本事务内初始化，其他过程查询它要等下一步。世界新事件只供下步逻辑消费一次 |
| 6 舞台 | 已提交的快照、轨道与事件戳 | Director 对每个观察者仲裁可见性、拍点和尾声。可在两次提交间插值已知状态，不能反馈控制或因果 |

过程在边界退出时，原 tick 不会再为新区间申请作用。因同一步的句柄建立、转移、扣款与切换按事务提交，任一必需申请失败都不产生这次转换的部分效果。此前步已提交的世界后果保留。对相互独立的并行过程分别提交。新阶段的 enter 在转换事务内建立并持有资源；新阶段从下一次调度作持续申请。零时逻辑接续可按无环图在同一事务准备句柄（例如刚从剑锋派生的波可直接取父项已实现位姿后脱离），仍只有一次世界提交，新生物不能触发同一步无限事件链。连续位移和施力采用固定步长，事件截断用相同子步规则。设计确定的是合同；不同物理后端的浮点轨迹一致性须单独测量。

**世界内部先后。** 先验证端点、计划所有权、预留供给与材料份额，再解算现有主动支撑间的有限干涉；用仍有效的边传播材料、热、电和信息，用取得的热量推进相变与实际几何，然后求接触、结构负荷和合力。支撑干涉以步初合格关系为目标，各申请先预留且同时结算。单边把所有合法压制量求和，从实付容量扣至最低零；永久切断只有达到该边抗断阈值才提交。互相压制的实例在这次裁决使用步初的权利与额度，衍生失能在下一次干涉查询体现。支撑抑制在本步影响依赖该边的后续作用；新凝结的形体可承受本步接触，但本步新导通的边要在下步传播。反馈环借助提交边界推进。纯读引用可并存；同物排他所有权同刻冲突，按既有持权者、稳定申请键依序准入并记录失败者。可分同类源按各合法申请量比例分份，计量最小单位的余量依稳定键分配。离散事务若不能达到声明下限则释放整笔。若多笔同时低于下限，每轮只撤稳定优先序最末的一笔，再为其余合格请求重新分配；已经受理的事务只提交一次。稳定键由世界实例与局部声明序派生，与容器遍历及渲染帧率无关。

## D4 · 三本账与可证伪的推演

| 账 | 静态上界 | 动态扣减与失败 |
|---|---|---|
| 魔力与责任 | 以规模、有限时空几何、并发边与账户、最坏有效次数报价；互斥取最大，并行求和。扩范围/延时/增并行不得降低相应报价 | 离散工作按建成/交付计，持续按实际时间和能力签名计。多方对消仍分别付费。未使用的物理份额不能换回额外储备 |
| 物理配额 | 展开阵列、拓扑、冲量/能量上限、并发查询与责任时长。数值硬顶取能力版本 | 越界可在准入阶段拒绝。现场容量不足按通道缩减，保持材料守恒和句柄唯一 |
| 渲染配额 | 可见载体×材质、重透明/体积、光源、混音与尾声的最大同时数 | 按 C3 渐退昂贵轨，保持作用覆盖、危险提示和必要事件。渲染降档不改变任何世界余额 |

以下是一组有明确结果的**纸面调度题**，未来机器实现可直接用作反例。

| 同一边界上的输入 | 应得结果 |
|---|---|
| 武器姿态交付与强制打断同刻 | 已经完成的挥击接触保留，新月牙建立与单次交付均为零 |
| 可分水源 3 kg，两个合格的 2 kg 请求各可部分完成 | 各入账 1.5 kg，源剩 0。若一个有 2 kg 的最低整笔要求，剔除该笔，另一笔得 2 kg，源剩 1 kg |
| 一物受方向相反的同额力，另有一术切断其中一项维系 | 切断前该轴净力为零，两术都付费；成功切断后只计仍成立的一项。此前速度保留 |
| 本步一条水边断开，冻结前沿尚未通过；同场一条铜旁路仍有效 | 水的传播止于断点，电仍可走铜。此前已经冻结的段保留 |
| 过载已提交，角色随后撤术，画面还有混响 | 断口及落体继续演化，旧作用失去写权，声音可在声明尾时内衰减 |
| 一个关系本步生成 signal，其订阅者也会生成同种 signal | 消费者最早在下步获得带序号的事件。每次有来源、域、预算和剩余次数限制 |

## D5 · 用同一时间线验四份规格

取 C2 月刃，下面是供人手推的输入与预期。动作实际交付时刻为 0.40 s，角色之后 0.10 s 转身，波会先于 1 s 的寿命上限碰到一根立柱。视图内只有此术。

| 边界 | 处理什么 | 世界提交 | 舞台可读 |
|---|---|---|---|
| 0.39 s | 武器已开始扫掠，尚无离刃事件 | edge 随武器，wave 尚无世界身份 | 剑锋可以明亮，远处无波也无命中 |
| 0.40 s | 采到 pose_release，从 edge 派生 wave、脱离、实付一次起动 | wave 有独立位姿与速度，travel 接责。旧参照的退出不会撤销 wave | 主位从剑锋转到弧面，音画共享事件戳 |
| 0.50 s | 角色转向，现有 wave 继续弹道 | 波仍沿交付初态演化，可以撞别的实体 | 演出读取波自己的当前位置 |
| 初次碰柱及下一逻辑步 | 物理初触提交回执，travel 在随后边界消费一次，做附加的有界冲量后结束 | 自然碰撞与配方的附加交付各记其来源，柱获得的动量依真实结算 | 初触音依其真实事件；附加交付音只认本过程相应的实际回执。尾时结束不回滚世界 |

分别改两个条件：若 0.40 s 同时收到强制打断，wave 从未建立。若移走立柱且途中再无接触，wave 会建立并在时限届满时退出，实际命中回声为零。一次对照只改一个条件；这两条反事实可分别揭露“强行播放整套魔法”和“未接触也交付”的错误。
