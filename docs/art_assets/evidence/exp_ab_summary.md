## 复用入口与验收边界

- [F03 三份配方](../../../game/art_kit/families/F03_arc_blade/recipes/)的宽度依次为 3.8 / 5.8 / 4.1 m，斜斩角为 +26° / +19° / −23°。材质、倾角、开弧角、速度、曲线及退出时长可在[参数契约](../../../game/art_kit/families/F03_arc_blade/spec.json)中核对。[A4 配方](../../../game/art_kit/families/F04_wave/recipes/a4.json)可从大殿法术列表切入。
- [B1 大殿场景](../../../game/art_lab/experiments/CrownHall.tscn)中按空格提拉、F 逐件派发、X 撤法。三次只改场地宿主或数量，[阵列配方](../../../game/art_kit/families/F10_array/b1.json) SHA-256 均为 `d5b8e0250b1afd9eb903ba6bcfb12fd85dfc7d3e350a4113e30504a32e1edb3a`。落回后对象身份和基础材质均一致，卸载后槽位全空。
- B02/B05/B07/B08 使用披风角色骨骼程序姿态，S09 与木梁声为离线合成。X03 在曾支撑宿主的静态石面留下短时裂纹，随尘屑消退；三次大殿日志分别记录 8、8、32 个支撑点。F04-03/04 按本次范围延期。Movie Maker 固定帧率录制，实时 60 FPS 与显存预算尚未测量。

干净检出的 Python 回归 32/32 通过，大殿运行回归 30/30 通过。原工作区另有未跟踪的 `aim_transfer/admitted.json`，在该工作区直接运行全套 Python 测试时，目录封存一致性检查会多读入这一条。
