# 原子资产族与薄编排契约总览

> 当前状态：**设计规范与研究基线（v1.1 校准版）**。本目录资产与管线尚未经过实机批量验证，任何标注为「待设计/制作」的条目均不得宣告为已成立能力。

## 一、核心定位：DSL 是语义与演出的桥梁，不是 3D 引擎

1. **世界法则保留不变**：继续沿用 [魔法形而上学 v0.3](../v0.3/魔法形而上学.md) 与 [20 枚符文与编译契约](../v0.3/符文与编译契约.md) 中的五面世界语义（`Concepts / Subjects / Relations / Processes / Contracts`），真实物理、资源预算、因果留存与合法边界只归 `WorldLaw`。
2. **重置 `Expression` 抽象层级**：DSL 不再直接拼装球体、条带宽度、粒子数量或底层着色器数学，而是作为**「世界状态信号 ↔ 预制高质量资产族编排」**的中间契约层。
3. **丰富资产 + 简单稳定运行时**：允许美术资产库逐步积累到上百个制作单位，但引擎侧的加载、绑定与调度接口必须保持薄而稳定，不随单个魔法扩写脚本。

## 二、三类平起平坐的演出载体

| 载体类别 | 目录代号 | 职责与核心纪律 |
|---|---|---|
| **具现主体资产族** | `F01–F09`, `F11–F18` | 经过专业视觉设计的持续存在形象（弧刃、波前、幕面、流带、凝聚核等）。**网格与骨骼/BlendShape 形变动画严格在资产族内部复用**，不跨拓扑强行共用同一形变数据。 |
| **现实世界宿主** | `H01–H05` | 直接作用于场景中真实存在的刚体、建筑表面、水冰燃料、活体与持有武器。保留原物身份、轮廓与碰撞，严禁用假石头或假武器替代真实宿主。 |
| **非实体关系/场域/感知** | `H06–H08` | 服务抑制、连接、信息传递、沉默、反魔法与纯粹场域异常。**不强制生成实体球或发光环**，允许仅以合法关系脉息、边界提示、声学与局部光影成立。 |

> **全局复用 vs 族内复用**：跨族全局复用的是「语义意图（如沿刃展锋/收束）、共享时间曲线（`C01–C12`）、运动控制模式（`M01–M20`）、跨族伴随演出（`X`）及薄状态契约」；几何形变本身留给各自资产族内部实现。

## 三、三档尺度授权（阻止庄严克制再度缩水）

审美上的「克制」指色相、纯度与噪点克制，**不是尺度畏缩或物理阉割**。导演与表达层按授权档位区分演出强度：

- **`T1 隐微/小术`**：低幅度手势（`B16`）、最小声光提示、不惊动全局光照与镜头，服务侦测、沉默、刻印待发与细腻干涉。
- **`T2 常规战技`**：清晰可辨的立体剪影与正侧背轮廓、局部光影应和、明确真实接触反馈与合理物理力度。
- **`T3 宏大仪轨/天象`**：允许申请大尺度空间反差、局部环境压暗与色温偏移（`D01/D02`）、混音低通压场（`S13`）、以及明显压过重力的真实 Jolt 冲击，仅在交付/接触瞬间精准爆发并留下清晰世界后果。

## 四、混合美术资产生产管线与团队分工

采用**「ImageGen 原创概念与 2D 视觉素材 + Blender Python 离线 3D 载体 + Godot 4.5 技术美术封装」**的混合生产路线，外部商用/开源资源仅在确实存在瓶颈或 ImageGen 不适用的类别引入：

| 参与方 | 明确职责 |
|---|---|
| **GPT / Gemini** | 魔法创意、艺术设计、生命周期拆解、素材拆解与审美批判分析 |
| **ImageGen** | 魔法概念图、四关键帧分镜、主体能量纹理、灰度侵蚀 Mask、奥术纹样、火花/碎屑贴图、表面变化参考 |
| **Astra + Blender (Python 离线)** | 2D 贴图离线通道加工（去底、灰度归一化、无缝/边界清理；**绝不将未验证生图直接冒充精确法线或 Flowmap**）；离线生成带规范 `UV0/UV1` 与 `Shape Keys` 的可动画化 `.glb` 载体 |
| **Astra + Godot 4.5** | 资产族 `PackedScene` 封装、共享时间曲线与着色器绑定、`WorldLaw` 只读信号接入、薄配方加载与多机位实机录屏 |
| **外部资源（按需补充）** | 通用岩石/建筑 PBR 材质优先选用 Poly Haven；角色骨骼动作优先参考 Mixamo 并重定向至 `astronomer.glb`；撞击/摩擦/环境音优先选用 Sonniss GDC / Freesound 实录音效，配合必要的声音合成层 |
| **负责人（项目主导）** | 艺术方向定调、概念图与无辉光灰模剪影一票否决、最终实机视听质量裁决（在 Blender 检查模型与动画旋转，在 Godot 审阅多机位与参数表现） |

## 五、Godot 4.5 技术实施铁律

1. **禁止滥用 `instance uniform`**：Godot 4.5 的 `instance uniform` 不支持纹理与数组、单着色器存在约 16 个槽位上限，且不可用于粒子、雾和天空 Shader。按资产需求混用实例参数、共享材质资源、独立材质实例与数据纹理。
2. **明确 `material_overlay` 边界**：`material_overlay` 适合附魔、薄霜、受压裂纹等局部表面反馈，**不能独立完成积水化冰墙、刚体碎裂或物理属性修改**；多通道叠层（如冻结与灼烧并存）须有主次分层，真实材料与碰撞变更归 `WorldLaw`。
3. **禁止用动画关键帧驱动玩法结算**：通过外部 `Curve` 采样或重定时控制动画进度时，`AnimationPlayer.seek()` 与 `AnimationTree TimeSeek` 不作确定性玩法事件调度；伤害、受力、资源消耗与提交回执**只由 `WorldLaw` 发出**，演出层只读响应。
4. **严禁机械拼装与假消失**：除纯光学消隐外，禁止「基础几何体 + 统一缩放 + 线性 `alpha` 淡出」冒充解体；真实被控物体在退场后必须交还世界，继续按物理规律运动或留存。
5. **在实验 A–C 通过前，禁止提前编写大而全通用框架**：先以 [Pilot 01 · F03 开口弧刃](pilot_F03_arc_blade.md) 跑通全链路，再依据真实复用经验将 [薄编排契约](thin_contract.md) 升格为正式规范。
