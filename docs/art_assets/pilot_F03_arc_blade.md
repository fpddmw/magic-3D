# Pilot 01 · `F03 开口弧刃` 垂直切片开工任务书

## Stage 1 · 概念定调与 2D 视觉素材（负责人 + GPT/Gemini + ImageGen）

- **交付目录**：[F03 原始素材目录](../../game/assets/vfx_source/F03_arc_blade/README.md)（`game/assets/vfx_source/F03_arc_blade/`）
- **必须产出的 5 份原始素材**：
  1. `concept_sheet.png` — 庄严废城光影下的 `F03 开口弧刃` 主视觉定调：窄锋厚腹、内弧留白、外弧拉锋，体现冷银刃光与压暗空间反差（拒绝霓虹塑料感）。
  2. `storyboard_4frames.png` — 四格生命周期关键形态：`① 沿刃展锋起势` → `② 完整展开挥扫` → `③ 离体稳定掠行` → `④ 沿锋分段溃散`。
  3. `energy_flow.png` — 主体能量流纹贴图：沿横向长轴具有清晰流速与层次，头尾收敛、边缘不规则有机。
  4. `erosion_mask.png` — 高对比黑白侵蚀图：用于驱动分段断裂与边缘瓦解（禁止均匀规则噪点）。
  5. `accent_sparks.png` — 伴随锋切光屑/余迹贴图（黑底或透明底）。
- **门禁 G1（视觉定调验收）**：负责人确认 `concept_sheet.png` 符合期望的魔法气质、且 3 张贴图具备足够细节层次后，才移交 Astra 启动 Stage 2。

## Stage 2 · 纹理加工与 Blender Python 3D 载体（Astra + Blender）

- **离线加工脚本**：`tools/asset_pipeline/process_f03_textures.py`
  - 将 Stage 1 图像裁剪对齐、规范分辨率（如 `1024×1024` / `2048×1024`）、提取纯灰度侵蚀/流动通道、清理黑底溢出与边界锯齿，输出至 `game/art_kit/families/F03_arc_blade/textures/`。
  - **严禁**：直接把未经校验的 AI 生图当精确法线图或 Flowmap 使用。
- **Blender 离线 3D 建模与形变脚本**：`tools/asset_pipeline/build_f03_mesh.py` → 导出 `game/art_kit/families/F03_arc_blade/F03_arc_blade.glb`
  - 提供至少 **`narrow_edge`（窄刃）** 与 **`wide_crescent`（宽月腹）** 两种轮廓变体；必须有立体的锋脊截面与双端收尖（不是平直等宽矩形带）。
  - 规范 `UV0`（流动与侵蚀采样）和 `UV1`（`s ∈ [0,1]` 沿弧长展锋、`v ∈ [0,1]` 横跨刃宽）。
  - 制作相容 `Shape Keys`：`unfold_root_to_tip`（沿刃展锋）、`arc_open`（跨度微调，限制在 `45°–160°`，严禁拉成闭环）、`sweep_bend`（挥扫偏转弯曲）、`edge_retract`（沿根回卷收锋）。
- **门禁 G2（无辉光灰模剪影验收）**：负责人在 Blender 或 Godot 中关闭发光与特效贴图，只看灰模旋转视角并拖动 `Shape Keys`。轮廓必须锋利、自然、无折痕自交，方可通过。

## Stage 3 · Godot 4.5 资产族封装与最小世界接入（Astra + Godot）

- **工程封装范围（严格保持极薄，禁止写全量通用框架）**：
  - `game/art_kit/families/F03_arc_blade/F03_arc_blade.tscn`：挂载 Blender 导出的 `.glb`、侵蚀与弧长显形 Shader、尾部微粒 `GPUParticles3D`、接触点闪击钩子与音频播放器；
  - 支持两套表现配置：`P01 冷银刃光`（Shader 材质 + `energy_flow` + `erosion_mask`）与 `P04/P03 暗蚀折光`（深度安全屏幕折射 + 暗缘）；
  - 外部 `Curve` 资源：`C01 迅疾显形`、`C02 迟起渐强`、`C03 稳定推进`、`C05 顶点停顿`（`.tres`），内部纹理流动走独立 `art_clock`；
  - **最小 `WorldLaw` 与 ArtLab 接入**：接入现有大殿与露台场景，读取施法者手/杖朝向、`RealizedExtent` 实得推进前沿以及 Jolt 射线/扫掠碰撞 `ReceiptEvent`；**伤害与命中仅由世界步提交，动画重定时禁止触发碰撞事件**；未命中敌人/墙体时走自然分段溃散，绝不补发爆炸和重击音。
  - **音效**：优先采集或裁剪高质量实录空气切割（`S05`）、低频聚势（`S01`）、瞬间释放（`S03`）与石面接触（`S04/S09`），如暂用合成层须显式标明并在后续替换。

## Stage 4 · 零代码三变奏可塑性验收（门禁 G3）

在不修改任何一行 `.gd` 或 `.gdshader` 代码的前提下，**仅编写 3 份纯 JSON 实验配方**，在 Godot 实时第三人称窗口录制带声连续视频（`mp4`）与关键帧对照图：

| 变奏配方 | 核心曲线与表现 | 预期演出节奏与世界行为 | 重点检验 |
|---|---|---|---|
| **V1 · 瞬发锋锐剑波** | `C01`（`0.15s`）+ `P01` 冷银 + `narrow_edge` + `T2` | 短促蓄起 → `B07` 挥斩离刃 → 高速平掠 → 撞柱触发 `X06/S04` 并由真实边界溃散；空放则自然散尽 | 瞬发凌厉度；未命中不假爆 |
| **V2 · 沉重蓄势大弧斩** | `C02`（`2.2s`）+ `C05`（`0.2s` 顶点停顿）+ `wide_crescent` + `D01/D04` + `T3` | `B02` 错步聚势、局部环境微压暗与低频聚势 → 顶点瞬间停顿凝滞 → 宽厚大跨度弧刃斩出 → 沿锋分段侵蚀解体 | 同一资产能否演出沉重仪式与强压迫感 |
| **V3 · 缓行折光空间断缘** | `C03` 稳定推进 + `P04/P03` 暗蚀折光 + 末尾 `edge_retract` + `T2` | 原位缓慢聚弧 → 贴地/低空平稳推进折射背后石柱 → 撤法后沿原根线回卷收锋 | 非亮光类折光表现；非破坏性退出 |

### 一票否决线（命中任一项即判不通过）

1. 任何变奏出现「整体缩放 + 线性 `alpha` 淡出」替代局部侵蚀溃散或沿根收锋；
2. 三个变奏在实机录像里肉眼看上去像「同一个亮片改了颜色和速度」；
3. 灰阶无辉光剪影不可读，或侧面/背面出现明显纸片穿帮与自交黑斑；
4. 动画还没实际推进到墙柱时提前在空气里触发撞击闪光或音效，或无视墙体穿模直过。
