# 原子资产双账目录（v1.1 校准候选）

> 来源与口径：本目录基于《Magic 3D｜魔法演出原子资产总盘 v1》（249 项原始清点 + 70 题意向映射 + 20 项控制模式）进行工程/美学去水校准形成。**所有条目均为待设计/制作或待验证候选，不宣称已实机完成。**  
> 机读筛选与排期唯一入口见 [机读制作台账](ledger.csv)，接口与命名契约见 [薄编排契约](thin_contract.md)。

## 一、v1 → v1.1 的五项关键校准

1. **双账分离（杜绝重工美术与轻量脚本混算工期）**：将原始清点拆为 **账本 A（真实美术与视听制作单位，203 项）** 与 **账本 B（薄运行时协议、曲线与导演组件，63 项）**。
2. **去重合并（249 项原始条目 → 246 项去重 + 20 项控制模式 = 266 行台账）**：
   - 将 `P07 流体·薄膜` 合并进 `P06 流体·厚浪`（作为厚度/透射变体）；
   - 将 `P08 流体·液滴雾化` 合并进 `X08 飞沫溅射`；
   - 将 `P17 电性·细密残弧` 合并进 `X12 残余电弧`；
   - 在核心表现包（`P03 / P06 / P09 / P11 / P12` 等）中统一标配 **Surface Decal 表面持久印记槽位**。
3. **修正批次错配**：将 `F01-05 内陷闭合` 从 `P1 / C` 调升至 **`P0 / B`**，确保 `F01 凝聚核` 在制作当批即具备完整的非爆炸退出路径。
4. **动作与声音结构化澄清**：`B01–B16` 为高层动作意图单位，实际在 Godot `AnimationTree` 中须按 **`Enter / Loop / Release / Recovery`** 四段切分并区分「站桩仪轨」与「上下半身分离移步」；`S01–S16`（除 `S14` 归入音频总线配置外）为 15 个核心声学单位，正式扩产时将按主要物理媒介分层扩充，不以 15 个单音频覆盖全魔法。
5. **诚实标出映射缺口**：原 70 题纸面映射主要覆盖了 `F / H / P / TR / M`，而 **`X / C / B / S / D` 共有 74 项在台账中 `paper_refs = 0`**——这说明伴随效果、曲线、角色动作与声音尚未经过逐题压力测试，将在 Pilot 01 及实验 A–C 推进中补齐真实引用。

## 三、核心艺术投资方向（滚动推进顺序，非一揽子开工）

不一次性全面制作 A 批全部条目，而是通过 Pilot 01 及实验 A–C 逐组滚动点亮：

1. **Pilot 01（当前唯一启动）· 锋面试验田**：`F03 开口弧刃` 完整垂直切片（见 [pilot_F03_arc_blade.md](pilot_F03_arc_blade.md)）。
2. **实验 A 补全 · 闭合波前**：`F04 闭合波前` + `P15 气压折光` + `X07 重压尘环`，完成锋面与环潮可塑性验证。
3. **实验 B · 现实刚体与共享世界**：`H01 真实刚体宿主` + `F10 阵列控制器` + `B05 提拉` + `S09 石材声` + 真 Jolt 强力学，验证大殿真实碎石与跨物件复用。
4. **实验 C · 冻结盲测迁移**：冻结上述接口与资产，仅凭知识卡编排 2 个未见意向，通过后再升格为 `Magic DSL v0.4`。
5. **后续滚动小包**：
   - 包 1（可驾驭界面）：`F08 开放幕面` + `P19 辉光薄幕` + `X13 承载裂纹`；
   - 包 2（天体雪耻 · T3 尺度）：`F01 凝聚核`（含 `F01-05`）+ `P03 幽暗吸光` + `H07` + `D01/S13`；
   - 包 3（非元素核心）：`F13 分支网络` + `F16 刻印` + `H06 外术宿主`。

## 四、70 项意向覆盖边界与关键反例纪律

- **70 题纸面分布**：`10` 项一般纸面组合（如岩石球、辉剑圆阵、暗月 J05、古龙雷击、巨型旋风、浮岩护盾等）；`57` 项明确标出 **WorldLaw 领域能力前提**（水文守恒、热传导与相变、导电回路、结构承重接合、声学通道、空间门净空、局部时率等）；`3` 项明确边界不支持（`N30` 完整生物变形、`N31` 强行改写记忆信念、`N32` 复活/无限造物/时间倒流）。
- **六条不可违背的反例红线**：
  1. 不把 `F03 沿刃展锋` 动画数据强套给 `F11 晶柱`（全局复用意图，族内实现形变）；
  2. 同一向外排斥换成水/电表现时，世界侧必须显式具备真实水量或导电回路，不靠换皮肤伪造作用；
  3. 承重幕与遮光幕必须依赖 `ReceiptEvent.load_ratio` 区别显现，遮光幕绝不冒出承载裂纹；
  4. 真实浮岩离地后被打断，只退控制装饰，实物继续按惯性与重力落回世界，绝不随魔法淡出；
  5. 水带中段凝固时只局部相变（`TR04`），不得整条水带重播冰墙开场动画；
  6. 远观失联后只按最后合法样本收束（`H08-02`），严禁绘制未观测坐标。
