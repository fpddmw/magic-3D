# 05 · Godot 4 技术架构与验证切片计划

2026-11-26 · 明确面向 **Apple M6 (32GB) 开发机** 与 **普通玩家中端显卡** 的工程架构与“生死垂直切片”验证路线。

---

## 一、引擎选型与关键技术栈

| 模块 | 选型 | 选择理由 |
|---|---|---|
| **主引擎与语言** | **Godot 4.x（推荐 4.4+）** + **GDScript**（性能热点按需局部 C++/GDExtension） | macOS Apple Silicon 原生 Metal 极流畅；纯文本 `.tscn` / `.gdshader` / `.gd` 对 AI 协助编写与审阅极其友好；轻量开源、中端硬件负担极低 |
| **渲染管线** | **Forward+**（macOS Metal / Windows Vulkan） | 原生自带高质量 **Volumetric Fog（体积雾）**、ACES Tonemap、SDFGI/VoxelGI 可选光影、Decal 地面留痕与多光源阴影，天然适配阴沉废城氛围 |
| **3D 物理后端** | **Jolt Physics 3D** | 稳定性、刚体堆叠与破碎响应远优于 Godot 旧默认物理，且已在 Godot 4.4 起原生内置 |
| **动画与镜头** | `AnimationTree` + 轻量 `SpringArm3D` / 自定义 `SpellDirector` 插值相机 | 保证自由第三人称（A）移动顺滑、防室内穿墙，同时蓄力/爆发秒切导演偏移与顿帧 |
| **构筑期语义编译** | **确定性语义引擎 ＋ 本地轻量小模型（3B–4B Q4，如 `llama.cpp` JSON Grammar 约束）** | **铁律：仅在“法坛构筑暂停界面”运行**，编译产出静态 `SpellDSL` JSON 后释放模型算力；**进入 3D 战斗时 0 模型开销** |

## 二、普通玩家硬件预算与“降维高质”资产纪律

1. **战斗期资源预算**：目标中端独显（如 RTX 3060 / 4060 或 M 系列集成 GPU）1080p 稳定 **60 FPS**，战斗显存占用控制在 **1.5–2.5 GB** 以内，绝不让游戏和本地模型同时争抢显卡资源。
2. **审美靠光影与剪影，不靠堆碎块**：
   - **环境**：少数精心打磨的模块化哥特废城石构（高柱、残拱、断桥、石阶、铁栅、火盆）＋ 统一低饱和湿润岩石 PBR 材质 ＋ 浓密体积雾 ＋ 雨幕粒子，远景与天际线由大气散射和剪影支撑。
   - **角色**：兜帽长披风法师主角（利用布料摆动提升灵动度、遮掩局部动作瑕疵）＋ 沉重慢拍石甲/锈铁废墟守卫。
   - **魔法演出**：靠 `0D / 1D / 2D / 3D` 程序化动态网格 ＋ 领域专属 Shader（折射水、棱面晶冰、熔岩亮缝、分形电弧、负光暗域、时停去色圈）＋ 导演光影/音频，绝不依赖百万粒子硬算。

## 三、Godot 工程目录组织（`game/`）

```text
game/
├── project.godot                # Forward+ 3D 配置、输入映射
├── scenes/
│   ├── main.tscn                # 启动入口与废城氛围占位大厅
│   ├── world/                   # 模块化废城场景（外景断桥、挑高圣堂、水渠）
│   ├── characters/              # 玩家动作控制器与废墟敌人
│   └── magic/                   # 程序化拓扑载体与环境异象节点
├── scripts/
│   ├── dsl/                     # SpellDSL / Contract / Manifold / Essence / FourBeat 资源类
│   ├── director/                # SpellDirector（相机、光影、顿帧、4层音频调度）
│   ├── combat/                  # 动作状态机、韧性/失衡、碰撞与状态传递
│   └── semantic/                # 构筑期词义回路校验器与离线 DSL 编译接口
├── shaders/                     # 6 大领域程序化材质与天地异象全屏后处理
├── data/spells/                 # DSL JSON 样例与预设构筑
└── assets/                      # 模型、贴图、骨骼动画与多层次音效素材
```

## 四、“生死垂直切片”实施路线（DSL 定稿后立即启动）

严格按四步走，每一步都必须过 **“直观画面与手感审美检查”**，不达标就停下重调，绝不带着廉价原型硬往下铺：

| 步序 | 目标 | 必过验货标准（Go / No-Go） |
|---|---|---|
| **Step 0（已完成）** | 仓库重构、资产清理与 Godot 4 底座起盘 | 新仓库干净独立、DSL 讨论稿就位、工程可打开 |
| **Step 1（紧随 DSL v1.0 定稿）** | **废城氛围与慢拍动作底盘切片** | 1 座“暴雨断桥 → 无缝步入挑高哥特石殿”的废城；玩家操作沉重扎实，1 名废墟骑士可锁定格挡周旋。**哪怕不放魔法，画面氛围与操作分量也立得住** |
