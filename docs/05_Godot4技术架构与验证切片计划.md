## 一、引擎选型与关键技术栈

| 模块 | 选型 | 选择理由 |
|---|---|---|
| **主引擎与语言** | **Godot 4.x（推荐 4.4+）** + **GDScript**（热点节点按需局部 C++/GDExtension） | macOS Apple Silicon 原生 Metal 极流畅；纯文本 `.tscn` / `.gdshader` / `.gd` 对 AI 协助编写与审阅极其友好；轻量开源、中端硬件负担极低 |
| **渲染管线** | **Forward+**（macOS Metal / Windows Vulkan） | 原生自带高质量 **Volumetric Fog（体积雾）**、ACES Tonemap、Decal 地面留痕与多光源阴影，天然适配阴沉废城氛围 |
| **3D 物理后端** | **Jolt Physics 3D** | 稳定性、刚体堆叠与破碎响应远优于 Godot 旧默认物理，且已在 Godot 4.4 起原生内置 |
| **动画与镜头** | `AnimationTree` + `SpringArm3D` / 导演偏置插值相机 | 保证自由第三人称（A）移动顺滑、防室内穿墙，同时蓄力/爆发融合微弱镜头张力 |
| **构筑期语义编译** | **确定性展开器 ＋ 暂停期本地轻量小模型（3B–4B Q4，受 `semantic_intent_v0_2.schema.json` 约束）** | **铁律：仅在“法坛构筑暂停界面”运行**，输出 `SemanticIntent` 后由确定性编译器降低并静态校验为 `CompiledSpellDSL`；**战斗时 0 模型开销** |

## 二、普通玩家硬件预算与“降维高质”资产纪律

1. **战斗期资源预算**：目标中端独显与 Apple M6 1080p 稳定 **60 FPS**，战斗显存占用控制在 **1.5–2.5 GB** 以内，绝不让游戏和本地模型同时争抢显卡资源。
2. **审美靠光影、剪影与四层视听复合栈**：
   - **环境**：少数精心打磨的模块化哥特废城石构（高柱、残拱、断桥、石阶、铁栅、火盆）＋ 统一低饱和湿润岩石 PBR 材质 ＋ 浓密体积雾 ＋ 雨幕粒子，远景与天际线由大气散射和剪影支撑。
   - **角色**：兜帽长披风法师主角（利用布料摆动提升灵动度、遮掩局部动作瑕疵）＋ 沉重慢拍石甲/锈铁废墟守卫。
   - **魔法表现**：严格按 [02 · Magic DSL v0.2 规范](02_Magic_DSL_v0.2_正式语法与语义规范.md) 第 8 节落实 `ArtKit` 四层视觉栈＋四层音频栈，绝不靠百万粒子或“单网格+单颜色”糊弄。
