# 01 · 设计哲学与总纲

2026-11-26 · 本文件规定废城、美学与动作体验目标。魔法公理、词义与干预权限以 [Magic Core](magic_core/README.md) 为准。

---

## 一、核心定位：我们在做一款什么游戏？

在**有限、密集、庄严而苍凉的 3D 奇幻废城**中，玩家作为追寻魔法奥秘的探索者，以**沉重、讲究架势与破绽的慢拍动作**周旋求生，搏出施法窗口，并以**一门基于真实词义的活体魔法语言**构筑并亲手释放具有**铺垫、天地异象、轰然降临与战后余韵**的宏大魔法。

一句话校准气质：**《艾尔登法环》式的废墟神圣感与厚重战斗节奏 × 高自由度的世界因果交互 × 从底层就具备“大道至简”美感的语义构筑魔法。**

---

## 二、五条不可动摇的设计宪章

### 1. 废城气质：浓缩箱庭，外景苍穹与挑高室内并行
- **不做王国级大开放世界**，专注于有限但密度极高的立体废城箱庭（圣堂、钟楼、高架水渠、断桥广场、地下蓄水穹顶与藏书废殿）。
- **室外与室内同等重要**：外景靠暴雨、雷云、升月、断垣与 35%–45% 的天际线撑开史诗视野；室内靠**宏大的哥特挑高尺度**、火光冷雾的反差、石柱回响承接近距压迫感，绝不把战斗压扁在逼仄小黑屋里。

### 2. 镜头哲学：自由第三人称（A）为主，导演引导（B）兜底
- 常态采用低机位自由第三人称跟随＋目标锁定，玩家拥有亲手仰望苍穹与巨构的自由感。
- 遇到狭窄走廊、悬崖窄桥或长蓄力大招时，相机无缝融合弹性防穿墙收镜与微幅导演构图（压低仰角、略微拉远纳入天象、爆发微顿帧与震动），兼得漫游感与电影张力。

### 3. 战斗定位：多元厚重的动作冒险底盘 ＋ 魔法为统治核心
- 坚决不做只能站桩对轰的“法师打擂台”。角色具备**沉重的移动惯性、翻滚闪避、盾/杖格挡与架招、轻重近战攻击、韧性与失衡处决**。
- 动作系统与魔法系统不是两张皮，而是**互相成全**：近战与闪避周旋用来试探、破招、换取那 1.5–3 秒的生死施法空档；而魔法则以其庞大的体量、地形改写力与压倒性视觉奇观成为玩家最核心的辨识度与统治力来源。

### 4. 魔法美学：“大道至简”与四拍仪式，拒绝小聪明
- 魔法是对宏大世界法则的唤起——无论是水潮、重冰、天雷、熔岩，还是引力、暗月、光暗、虚空裂隙、时间凝滞，都讲究**直截了当的庄严感、重量感与浪漫气息**。
- 拒绝桌游式、轻小说式的“繁琐条件机关”（例如过分刻意的多步套娃判据）。
- 引擎将 **「1. 铺垫起势 → 2. 蓄力天地异象 → 3. 降临爆发 → 4. 战后持久余韵」** 写为魔法 DSL 的铁律：不靠廉价粒子堆叠，而是靠**发力前摇、全场光影压暗与反差、声音抽空与低频重击、以及真实的地形留存**立住力量感。

### 5. 工程现实主义：成熟 3D 引擎 ＋ 兼顾普通玩家 ＋ 实机验货
- 采用 **Godot 4.x（Forward+ / Jolt 3D）**，把有限精力 100% 砸在玩法、DSL、材质 Shader、导演镜头与废城体验上。
- 兼顾普通玩家中端显卡（战斗期稳跑 60 FPS）；语义编译小模型只在“法坛构筑（世界暂停）”运行并立刻卸载/休眠，**进战斗 0 模型损耗**。
- 一切构思必须尽快交由 **Godot 3D 单场景实机切片**检验画面与手感；达不到“让自己起鸡皮疙瘩”的质感标准，绝不盲目铺量。

## 三、明确的“不做清单”（防跑偏护栏）

以下方向经过先前教训已正式证伪或排除，后续任何迭代不得擅自引入：

- **不做 2D 像素风或 2D 横版**：不以“以为像素省事”为由退回 2D；旋转锯齿、后壁悖论与天际线缺失与本作气质根本冲突。
- **不做从零造底层图形/物理引擎**：不手写 C++/Vulkan 渲染器，不追求 $10^{-16}$ 级流体力学守恒或七组材料全耦合偏微分方程。
- **不做逐帧 AI 生图/生代码**：大模型只负责构筑期把玩家词义回路翻译为严格校验后的静态 `CompiledSpellDSL`，绝不在战斗中实时调模型或生成任意脚本。
- **不做海量换皮词条数值肉鸽**：拒绝“+15% 冰伤 / 投射物 +2”的词条加法器，也拒绝为了凑技能数量硬塞廉价特效。
- **不做超大规模空旷开放世界**：地图规模严格收束为少数精心组织、立体连通、重访有新意的废城区块。
