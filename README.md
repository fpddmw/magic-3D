# Magic 3D · 废城中的语义魔法

玩家用符文说清希望发生什么，魔法在同一个世界里留下可被他人继续利用的后果。两道外形相同的光幕，一道接住落石并可能压裂，另一道遮住视线，石块仍会穿过。区别写在配方的作用、成立条件和责任里。

**当前工作是 Magic DSL 的语言设计与集中审阅。** 从[审阅入口](docs/magic_language/README.md)进入四份规格、经典与原创构筑和逐步推演。已发布的 v0.3.0 / v0.3.1 是可回放的工程基线，新设计的证据等级单列。[四阶段总计划](docs/v0.3/演进与切片计划.md)
