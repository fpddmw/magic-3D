# City Fates 3D（暂名）

**一座《艾尔登法环》式庄严奇幻废城中的 3D 动作冒险游戏——以沉重慢拍的动作周旋搏出生死窗口，以“大道至简”的语义魔法语言构筑并亲手释放极具铺垫、蓄力异象与力量感的宏大魔法。**

> **当前阶段（2026-11-26）**：完成旧仓库资产清点与全面重构起盘。当前核心引擎已切换至 **Godot 4.x（Forward+ / Metal & Vulkan + Jolt 3D）**。**下一核心任务**：基于 [魔法本体论与 DSL 讨论稿](docs/02_魔法本体论与DSL讨论稿.md) 与 GPT 共同定稿不可拆分的 `SpellDSL` 规格，定稿后直接进入废墟大厅单切片实机验货。

---

## 核心优先级

1. **语义魔法构筑与大道至简 DSL（最核心辨识度）**：真实词义、语境多义、回路组织，配合底层不可拆分的四层 `SpellDSL`，在“不靠穷举预设”的前提下保证任意合理构筑都具备清晰区分度与高级质感。
2. **四拍仪式感演出与沉重动作冒险底盘**：`铺垫 → 蓄力天地异象 → 降临爆发 → 战后余韵` 的四拍演出；配合走位、翻滚、格挡、基础近战与韧性破绽系统，让宏大魔法的蓄力成为高风险高浪漫的博弈选择。
3. **高自由度世界交互逻辑**：水、冰、火、雷、风、引力、星辉、光暗与时空凝滞共同参与战场地形、视野、导电与遮蔽改写，并保留持久环境留存。
