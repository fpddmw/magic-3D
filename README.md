# Magic 3D / City Fates 3D（暂名）

**一座《艾尔登法环》式庄严奇幻废城中的 3D 动作冒险游戏——以沉重慢拍的动作周旋搏出生死窗口，以“大道至简”的语义魔法语言构筑并亲手释放具有真实因果与震撼视听质感的宏大魔法。**

> **当前阶段（2026-11-26）**：已完成针对 GPT 首轮审计全部 P0/P1 问题的技术收口，落盘 **`Magic DSL v0.2.1`（Semantic & Execution Contract Revision）**、**4 阶段离线验证器（7 份基准法术 + 12+ 项负向测试通过）** 及 **Wave 0 → 1A → 1B → 2 → 3 无环施工蓝图**。当前核心动作：**提交 GPT 与 Claude 联合交叉复审，确认 5 项合同终审问题后即刻启动 Wave 1A**。

---

## 核心优先级

1. **魔法生成空间与三层原语架构**：`Semantic Primitives（语义构筑）` → `Magic DSL v0.2（现象构造原语）` → `Runtime Kernels（四大空间载体＋三共享库）`，让复杂魔法成为基本规律在空间、结构、关系与时间上的自然组织结果。
2. **震撼视听质感与沉重动作冒险底盘**：通过 `ArtKit` 4 层复合渲染＋4 层动态音频＋物理冲量同源演出，配合走位、翻滚、格挡、近战与韧性破绽系统，让高风险施法拥有极高的戏剧张力与操作重量感。
3. **高自由度且诚实自洽的世界规律（`WorldLaw`）**：力学四分离（HP/削韧/冲量/行动限制）、热与相变、导电连结、视线遮蔽与持久环境留存共同参与每一次交锋。
